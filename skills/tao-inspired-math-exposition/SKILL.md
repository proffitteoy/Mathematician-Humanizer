# 数学表达：有来源、有条件、有实测

先读 [数据范围与限度](references/corpus-guide.md) 和 [体裁写作卡](references/genre-playbook.md)。需要统计支持时读取 `references/development-profiles.json`，不要把整份大表塞进正文。该表来自官方博客公开快照，不代表Tao所有论文、书籍或全部表达；它没有证明这些特征是Tao独有的。

## 选择模式

- 数学说明：解释一个结果、技巧或对象；给出目标与机制，读者应能跟上关键转折。
- 课程讲义：在已有知识上系统推进；定义、证明和练习应互相支撑。不要把公告写成讲义，也不要给每篇短说明机械加入练习。
- 学习札记：围绕一个具体理解缺口记录问题、尝试、失败所得与检查方法。含大量正式数学的札记可借用数学说明的结构；一般学习/职业建议与正式证明文不是同一体裁。

沿用用户的读者、篇幅、观点和数学事实。未给出时，只有缺失信息会实质改变论证才询问。用户当前要求优先，不为了追近参考分布改变任务。

## 组织正文

1. 确定读者为什么要关心当前对象，以及要解决的具体问题。开头可直接陈述结果、回顾定义或说明目标；不要强制问句开场。
2. 用能暴露关键机制的例子、特殊情形或已有弱结论搭桥。例子有用才放；不能拿模型中成立代替一般证明。
3. 在关键操作前解释它解决什么障碍：消去哪项、利用哪种不变性、把哪个量变得可控。已经标准且读者熟悉的步骤可压缩；陌生的决定性步骤应展开。
4. 写清对象、条件、量词顺序和结论。把启发、猜测、数值试验和证明区分开。引用工具时核对其假设；不要把作者熟悉等同于读者熟悉。
5. 将结果放回例子或应用，指出方法保留与丢失的信息。条件在证明中被使用，不等于该条件已被证明必要；声称必要时需要反例或另外的论证。
6. 以本次实际建立的认识收束。可以留下有明确检验方式的问题，不凭空编造个人经历、研究贡献或未来承诺。

学习札记应产出可检查的东西，例如重建关键步骤、构造反例、比较两个证明的适用范围。允许记录失败及其提供的信息，不把每次尝试都写成成功故事。

## 统计如何参与写作

### 英语

按体裁和英文词数段选参考；同时查看年代差异和公式负担。以文章为单位看分布与差异，不让最长文章支配平均值。词性、句长、依存跨度和语用提示词只负责提示应回看哪里，不是文笔总分。

将原创正文保存为纯文本，数学使用明确的美元定界LaTeX，保留原文件，再运行：

`python scripts/measure_english_candidate.py draft.txt --models "$EN_STANZA_MODELS" --contract references/english-measurement-contract.json --profile references/development-profiles.json --genre math_exposition --out draft.measurement.json`

使用与参考一致的本地运行环境和模型；脚本核对版本、权重并禁用网络。普通金额不当公式处理，公式占位不进入词项分母。短段落过滤与源语料一致，过滤项单独报告。不同解释口径不能混成一个分数。

核验后回看重要偏离：是题材、读者层次、数学公式还是确实有表达问题？只在具体问题支持时修订，再对新稿重测。不要为了凑名词率增加空洞名词化，也不要为降低句长拆坏条件或指代。边际区间内不等于联合分布相似、数学正确或作者身份成立。

### 中文

用自然中文写，不翻译式复制英语长句，不把英文POS/句长阈值搬过来。迁移的是可解释的组织、论证衔接与读者引导；不要称测得了“Tao中文声纹”。

使用 [中文统计核验](references/chinese-checks.md) 中的固定仪器：

`python instruments/zh/scripts/measure_text.py draft.txt --source web --python "$STYLE_PYTHON" --models "$STYLE_MODELS" --output draft.zh-measurement.json`

web参考是一般中文语料，不是Tao中文样本。检查解析覆盖与具体量纲；偏离只触发回看。公式多时保留完整原稿和可追踪的敏感性投影。用“公式”替换符号会人为提高名词率、降低词汇多样性，不能把投影当成无偏文风。

没有匹配环境或模型时，明确报告统计未运行；不估填数字，不把旧稿回执复用为新稿结果。

## 内容与交付自查

- 复算关键等式，检查量词、定义域、退化情形和反例。
- 检查每段在论证中的作用，删去无内容的姿态词；保留必要的限定。
- 确认引用属于Tao本人正文，客座、评论、第三方引文不当作他的句子。
- 将实际正文SHA、统计回执与内容审核绑定；修改正文后重核。
- 若采用 `scripts/audit.py`，依 [证据合同](references/audit-contract.md) 填写审核。它仅核对证据和指纹，不能替代语言量测或数学审核。

给用户的是原创成品、必要的审核结论和来源。不要长段复制博客，不输出假相似度分数；不要声称原作者写过本次成品。
