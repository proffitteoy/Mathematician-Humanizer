# 可运行候选交付，2026-10-03

## 现在能做什么

用真实语料的 TRAIN 配对观测学习差异卡，在 DEV 检查方向，再让现有宿主语言模型据此检查具体写法、产生候选。脚本独立检查内容约束、记录实际语义审阅、比较前后测量并保留失败与原文。

可直接使用的入口是本目录上一级的 SKILL.md。它不是训练好的文本生成器；学习到的是八项观测对比与参考分布，没有把数字序列预测器冒充改写模型。这里也没有调用那13份数值预测权重。

## 真实数据得到什么

使用已有暴露的 TRAIN 1816对、DEV 591对，均为同题 HUMAN/CHATGPT 配对。TRAIN 按1771个硬谱系组件等权计算差异；这是本次探索性估计对象，不冒称此前的题目家族加权预注册分析。只读取冻结结构统计导出，没有读取原始语料，也没有打开 TEST 或留出生成器。

八项坐标全部保留。F013句长中位数、F014句长IQR、F015句长p90、F024相邻句长变化、F025滞后相关，通过本次预设的探索性跨域方向筛查。F002段落密度在DEV总体方向反转；F003单句段落比例跨域不一致；F016归一化MAD区间跨过零。未通过的项没有被隐藏或用于编辑依据。

值得注意的是，本语料 HUMAN 标签文本的句长中位数和p90更长。它不支持“把句子一律缩短就更像人”的规则。另一方面，这可能含长度、来源版式、任务和收集差异；尤其物理行不是经验证的修辞段落。八项仍是未验证仪器输出，没有人类写作质量概率，也没有编辑因果效应。五张可检查卡不等于五条已验证改写规律。

## 实际输入输出与失败

完整文本见 BEFORE_AFTER.md，机器可读记录见 DEVELOPMENT_RESULTS.json 和两个 *.result.json。两个新输入都是人工构造的中文开发演示，不是自然DEV文本、人类参考或盲测材料。

共保留六个候选版本：三个通过记录的独立模型语义审阅，三个失败。缓存例的首个轻改版把“可以跳过查询”写成“会跳过查询”，独立审阅判定承诺被加强；失败版保留，修复版另审。故意加入的“已证明因果”和“全部项靠近极限”也被拒绝。

缓存最终选中 evidence_inspected，是查看真实差异卡之后写出的新版本；它保留机制与未测命中率之间的原始逻辑联系，再经过独立逐项审阅。其他初稿早于这些卡，不能把事后测量当作由卡带来的改进证据。选择web只是对新的合成技术/数学文本使用参考的探索性假设，未证明从来源集合到新体裁的可迁移性。

实测缓存选中版：句长中位数32→23字，p90为41.9→42.3字，相邻长度变化0.323→0.691；数学选中版中位数30→22字。对TRAIN人类中位参考的距离有的变近、有的变远。没有把这些变化合成“更像人”分数，也没有用它们覆盖语义失败。读起来是否更自然仍须实际用户/盲评判断。

## 复现

从技能目录运行，使用Python 3.12 / Unicode 15.0.0，与包含的测量配置一致：

    python -m unittest discover -s tests -v
    python scripts/run_fidelity_regressions.py
    python scripts/run_development.py --evidence references/paired-surface-evidence.json --output reports

这三个命令不访问语料、训练模型、下载依赖或调用付费API。开发重放复用已经实际审阅、文本绑定的候选，不把它伪装成每次重新生成。新输入用SKILL.md的prepare→宿主模型生成和独立审阅→evaluate流程。

33项独立可移植软件测试通过，覆盖TRAIN/DEV隔离、组件泄漏、空值、域和仪器身份、卡片绑定、语义失败优先于风格变化等。额外20组对抗/保持样例中，机械保护阻止17种错误中的7种，3个忠实对照均保留；另10种错误仍依赖真正的语义审阅。伪造“通过”的审阅记录可以绕过这条人为信任边界；哈希不是语义证明或审阅身份认证。

## 还没达到什么

没有盲评自然度收益、未知主题迁移验证、学习型干预效用、训练好的生成器或最终人类不可区分性结论。初始样例与研究调整存在开发适配，不能作为独立确认性测试。当前只交付可检查、可运行且证据边界明确的候选；没有达到个人模仿启动条件，也没有读取个人文章。最终验收仍由项目所有者判断。
