# 固定版本、保留缺口的表层测量适配器

2026-10-01。**已实现测量机制和原创合成测试；未运行自然语料测量、拟合或验证。**

这是独立研究模块，不改动 `src/style_compiler` 的八指标提取器、公共 JSON Schema、命令行或总体模型。结果版本为 `research-surface-bundle/0.1.0`，不得冒充 `measurement-bundle/1.0.0` 输入到基线拟合器，也没有接入 learned prototype。代码只用标准库和已有字符/分段算子，没有网络、文件读写或导入时执行。

依据是[冻结样本的版本与单位契约](../annotation/wikiconv-2017/README.zh.md)及其后续独立 AI 边界试审的汇总结论：签名可能含句子形座右铭，正文也可能出现在签名之后。**本模块不识别或删除签名，不截取第一个日期之前的文字，不清理模板、不解释引用归属，也不把来源记录、署名块和历史轮次等同。**

## 运行

从仓库根目录：

```sh
PYTHONPATH=src:. python -m unittest discover -s research/surface -p 'test_*.py' -v
PYTHONPATH=src python -m unittest discover -s tests -v
```

入口是 `research.surface.adapter.measure(observation, projection, profile=...)`。合成测试提供完整的调用样例。调用方需显式构造如下不可变数据类；不接受松散 JSON 对象、可变列表或自动猜测的版本。

## 输入契约

### 1. 不可变来源视图

`SourceView` 包含：

- 固定档案 SHA-256、成员名、零起点 `record_index`、原始记录字节偏移
- 原扫描器版本、零起点视图序号、记录内准确 RFC 6901 JSON Pointer、来源角色
- 未改动正文按 UTF-8 编码的 SHA-256 和 Unicode 码点数
- `immutable-source-view/0.1.0` 契约版本

`SourceObservation` 另存不可变源文本，不在测量结果中回显原文。创建及提取边界均核对文本哈希与长度。CRLF→LF、NFC/NFKC、空格改动和无效 Unicode 的替代解码均不许可；不可编码的孤立 surrogate 直接报错。

投影内绑定完整同一 `SourceView`。**正文完全相同也不能代替来源版本相同**：档案、成员、记录位置、扫描器、视图序号、Pointer、角色任一不同即拒绝连接。文本 hash 不是账号、自然作者、版权或历史事件身份。模块可验证契约内部相符，不能证明调用方给出的档案定位真实；提取私有来源时仍须用原档案复核。

### 2. 目标区间和可见排除语境

`Projection` 绑定来源视图、`source-span-projection/0.1.0`、有名称的标注 profile 与标注状态。状态只能为 `synthetic_fixture`、`provisional`、`reviewed`；后者是外部复核声明，不是程序认证。

- `targets` 是按原文顺序排列、互不重叠、非空、半开 `[start,end)` 码点区间的 tuple。不得使用字节偏移、UTF-16 下标、词编号或 grapheme 下标
- 不接受越界、负数、浮点、布尔、反向、重复、乱序或重叠范围。整个目标可以是空集
- 接触的区间允许，并仅为计算其并集合成连续分量。例如 `[0,3)`、`[3,5)` 之间没有缺口；人为标注切分不能破坏原有邻接
- `excluded_context` 是独立的、保留原位置的 `ContextRegion` tuple，可附多个并存候选角色标签。所有目标和语境区域必须恰好分割全文，既不遗漏，也不重叠
- `make_projection(...)` 可把整个补集保留为 `unclassified_excluded`。它不猜测角色。直接构造 `Projection` 可给出更细的标签或更细的排除区间
- 语境文字仍在 `SourceObservation.text`，以原区间读取；它不计入目标字符分母，也不被拼接进目标。结果只携带位置/角色，任何正文副本都不是必要输出

这是一层互斥的测量包含/排除分割，不是把所有语义标注强制变成平面分割。一个语境区域可有多个角色候选；未来动作节点、嵌套谓述、引用层或声音图应另有契约，不应用本分割强迫它们互斥。

### 3. 冻结测量 profile 和联合观察键

`MeasurementProfile` 固定：适配器 `source-units-gap-safe/0.1.0`、原字符特征版本、原标点分段器版本、运行时 Unicode 数据版本、码点单位、无归一化、先原文分段的单位策略及缺口安全的配对策略。任一不支持的版本/策略都拒绝，不做隐式迁移。

输出有完整源视图、profile、投影及各自 SHA-256，还提供同时覆盖三者的 `observation_key_sha256`。将来多分支若消费这些观察，必须共享这一联合键；不能只按正文 hash 或来源 ID 连接。跨 Python Unicode 数据库版本需显式复核，不应默认为同一个测量环境。

`target_component_text_sha256` 对**按原序的连续目标分量字符串数组**做规范 UTF-8 JSON 编码再 SHA-256。数组框定保证 `["甲","乙"]` 与 `["甲乙"]` 不混淆。它只是保留缺口拓扑的文字指纹；不同来源可得到同一个指纹，仍须保留原视图到投影的映射。它不是去重/作者合并授权。接触区间的切分方式不改变该文字指纹，但会改变完整投影指纹。

## 分段与可计算边界

先对**未改动的完整源文本**运行已有 `punctuation-lines/1.0.0`，再按目标区间并集选取源句/源段。绝不拼接目标片段再分句；也不在每个片段开头或结尾重新运行句界规则。

源句/源段的已修剪字符区间全部包含在目标并集中，才是完整目标单位；有任何字符相交但未完整包含则为 clipped 单位。完整源句仍只是原标点算法得到的操作单位，并未升级成语言学句子、完整语用行动或一个声音。符号、组合附加符号和 emoji 不计入 L/N 字符数，但仍占码点和区间；标点被切去也算单位不完整。

保守规则是：

- 目标触及任何不完整源段时，F002/F003 对该目标投影不适用
- 目标触及任何不完整源句时，F013/F014/F015/F016/F024/F025 对整个目标投影不适用。完整子集仍列出来供诊断，但不悄悄删除难例后计算分布
- 句子完整而原物理行只保留部分时，句长量可用而段落量不可用
- 排除一个完整来源句/段是声明的目标选择，不等于单位漏标；但这个选择改变观察对象，不能假称对整个来源总体无偏

因此，正文没有句号而紧接署名时，人工正文区间即使合理，已有源句也可能被切断，适配器会拒绝给句长量。这是本 profile 的明确限制。需要投影自身的新分段规则时，应另立版本并验证边界，不能把它悄悄塞入既有指标定义。

## 八个操作量、机会分母与缺失

只沿用 F002、F003、F013、F014、F015、F016、F024、F025 这八个已有量。区间数、覆盖字符、剪裁数、机会数及指纹是审计元数据，**不计为新风格通道**。

设 C 为目标并集中的 Unicode L/N 码点数，P 为完整目标源段数，L 为按来源顺序的完整目标源句正长度，n 为其数量。分位数沿用 `(n−1)q` 线性插值。

| ID | 计算 | 机会计数/分母 | 额外不适用或缺失 |
|---|---|---|---|
| F002 | 1000 P / C | 目标 L/N 码点 C | 段被切断；C=0 |
| F003 | 只含一个源句的完整目标源段数 / P | 完整目标源段 P | 段被切断；P=0 |
| F013 | median(L) | 完整目标源句 n | 句被切断；n=0 |
| F014 | Q.75(L)−Q.25(L) | 同上 | 同上 |
| F015 | Q.90(L) | 同上 | 同上 |
| F016 | median(abs(L−median(L))) / median(L) | 同上；代数分母另存 median | 同上 |
| F024 | 有效相邻对的平均绝对长度差 / median(L) | 有效对数；代数分母另存 median | 句被切断；没有有效对 |
| F025 | 有效对的左右长度向量 Spearman 相关，平均并列秩 | 有效对数；秩协方差及尺度另存 | 句被切断；少于3对；常量秩向量 |

有效对须同时满足：两个完整目标源句在**原完整来源句序列中相邻**，并且从左句起点到右句终点全部位于同一个目标连续分量。跨段转移沿用基线定义，但前提是段间的换行、空白等也在目标内。哪怕只排除一个空格或换行，也不越过那个缺口形成新配对。删除一个完整中间句后，两侧句不会变成新的相邻句。

F024/F025 可汇合多个连续分量内部的真实原文相邻对，但不跨分量连边。F024 的 median 使用全部完整目标源句；F025 在汇合后的**有效对**左右向量上排名。这是显式命名的缺口限制观察对象，不是把各分量相关系数平均，也不是对 flatten 后的句序列做 lag-1。全目标范围的八个数值与原提取器一致；有删选的结果不能与原无条件基线当作同一个观测总体比较。

每项含数值状态、适用性、机器可读缺失原因、机会单位和数量、剪裁机会数、代数分子/分母（有意义时）。机会计数与代数分母分开：例如分位数有 n 个观察机会而非一个比例分母。无内容、没有相邻对、常量向量造成的缺失都返回 null；观察到的零变异保留为 `zero_observed`。整体不适用时不继续暴露一个看似可用的代数结果。所有比较资格恒为 false，误差区间及参考统计恒为 null；原工程样本量阈值没有被冒充本投影的验证阈值。

结果另列全部来源相邻对、两端完整纳入的候选对、被排除间隙阻断的对、端点未完整纳入的对以及实际有效对，可以检查机会账目。保留原句/段索引和原码点位置，不压缩重编号来暗示假邻接。

## 原始观察和目标观察分开

每次调用同时返回：

- `raw_source`：完整来源文本上的八项原操作量
- `target_projection`：在显式版本与目标/语境分割上的保守观察

这两者是不同观察对象，名称不能互换，也不自动取差值当成编辑、作者或模板的因果作用。源签名、模板标记和引文的表面字符属于 raw；是否进入 target 由明确区间声明决定，角色正确性仍需外部复核。

## 验证、隐私与下一步

当前测试覆盖原八项数值一致性、精确来源和版本拒绝、各输入不可变性、完整补集、重叠/越界/乱序范围、接触区间、gap 阻断、删去中间句、常量/短序列/空输入、CRLF、组合字符、emoji、补充平面汉字、无重分段、句形签名、署名后正文以及未断句正文与署名相接的弃权。全部文本为本次原创合成夹具；测试数量不代表经验样本量或测量可靠性。

**真实资料输出不可直接公开**：虽不回显原文，它仍包含来源定位、hash、逐条跨度和可重建映射。若在已授权冻结包上运行，完整结果只可留在仓库外受控位置，公开文件只可有跨视图/跨组汇总，不包含原句、ID、账号、逐条特征表或重建映射。此实现没有启动该运行。

安全的下一步是：

1. 在既有冻结视图上预先固定边界 profile/目标及完整补集，先复核准确来源定位，不新增下载、样本或个人文本
2. 对既有候选投影运行该适配器，先报每项可用/剪裁/零机会的覆盖账目及 raw/target 汇总差异。保留签名后正文、句形署名、未闭合模板和不确定引用层，不能为了可计算而删除难例
3. 独立复核本 profile 是否系统性拒绝某类正文；若需新的正文投影分段，预先定义其边界、缺口和比较对象，再以独立单位发现及误差验证扩展。不能把覆盖率当作句法正确率
4. 对自然文本的可靠性、任务分层、抽样权重与新冻结留出组做独立设计；当前规范已经受到既有24组的启发，不能把它们称为未见泛化集

没有人工金标、自然作者核验、真实历史会话转移、H_G 准入、拟合或“人类风格”结论。WikiConv 来源文本内的序列只描述所选版本的字面顺序；多个声音仍可能在同一目标内。
