# Independent natural-role limitation, frozen v0.1

Independent post-run review verified the exact diagnostic identities, terminal seal, source mappings and complete partitions. It also found a substantive role limitation: a table-adjacent annotation had been emitted with the structural `list_prose_candidate` role.

Therefore, the aggregate “one structurally projected diagnostic” must not be described as one clean, author-original or role-qualified prose record. Exact provenance and gap reconstruction passed; semantic/structural role qualification did not receive a clean pass. No item is admitted.

The original v0.1 implementation, execution manifest, smoke outputs, marker, receipt, seal and result report remain unchanged. This addendum preserves the limitation instead of silently patching the tested version or rerunning its source texts. No additional source bodies were read by the implementation worker after the one-shot smoke.

A separately authorized future revision should treat ambiguous table-adjacent notes, lists, captions and continuations as hard non-prose/unresolved-content barriers. The CommonMark AST identifies a list syntactically but does not decide whether that list is a table annotation or independent body prose. Synthetic revision work cannot erase this v0.1 finding; any natural validation of a revised version requires a new explicit GO.
