# 一般人类研究语料：47 篇正式纳入

版本：`human-publications-20261002.1`，2026-10-02。

## 决定与范围

这批 **47 篇已纳入一般人类研究语料 H_G**，采用 `operational-human-publication/1.0.0`。依据是具名人类作者／记者、文章署名、原发布机构与可核对的来源记录。2022 年只是先前选材时的历史背景，**不是录入截止线**；没有前 2022 年的不可变网页快照，也不构成拒收理由。日期、抓取时间、更新情况与历史版本确定性仍作为独立元数据保留。

本次不是把候选目录换一个名字：`REGISTRY.json` 指定了不可变的录入版本和目录哈希，`loader.py` 能从获准的本地缓存实际读入、校验并输出 47 个 `document/1.0.0` 兼容研究输入。入口不调用旧的“必须 unassisted”拟合筛选器，也不要求日期早于任何年份。

- 芭樂人類學：40 篇单独署名文章，10 位作者每人 4 篇
- 芭樂人類學：另有 1 篇四人合著文章，纳入一般人类语料，不进入单作者样本
- 環境資訊中心：6 篇记者署名报道，2 位记者每人 3 篇
- 合计：47 篇一般人类文章；其中 46 篇具备单一文章署名，形成 12 条重复作者轨迹

合著文章 [6907](https://guavanthropology.tw/index.php/article/6907) 的文章署名是蔡侑霖、傅偉哲、鄧家洋、莊雅仲。记录保留四人的共同署名单元，`individual_author_id` 为 null；不会因为它出现在莊雅仲索引下，就把整篇算作莊雅仲个人文章，也不把另外三人算成三条已建立的重复作者轨迹。

## 人类来源与辅助生产状态分开

47 篇的 `assistance_status` 都保留为 `unknown`。这不是“无法使用”，也不是“已证明零辅助”。默认操作性研究人群允许这些具有人类署名和出版证据的作品进入特征分析；后续若要研究严格的“确认无辅助”人群，可显式选择另一政策 `confirmed-unassisted/1.0.0`，本批在该政策下为 0 篇。

旧 `style_compiler.model` 的严格拟合条件未被暗中放宽。它仍对应另一种更严格的筛选目标，不是这批语料的录入条件。此次没有执行拟合、提取文体特征、改变旧结果标签或把新材料塞入正在运行的实验。

## 段落、引文与内容角色

保留 182,610 个完整正文 Unicode 码点和 1,136 个原生结构块。原 HTML、正文 HTML／DraftJS 结构、正文文本都逐项记录 SHA-256。加载器保留正文原样，并提供带有原文起止偏移、顺序与角色的 `source_units`；所有单位拼接后必须逐字符还原完整正文。

结构块不一律等于自然段，也不保证其中每句话都由署名者写出。明确标记的引文、图注、标题、列表与原子媒体占位符保留各自角色；行内引语、借文、参考资料及说话人归属仍未完成金标准标注。单作者的 46 篇是**文章署名资格**，不是 46 篇已清除全部他人语言的纯作者文本。

三篇 HTML 在旧叶节点视图之外还含有 855 个码点（其中 800 个非空白码点）。此次通过 `unmapped_source_text` 原位保留，未删去、拼接或伪装成已分类段落。6 个长块的文章不会被人为拆成更多段，div 承载的正文也不会因为不是 p 标签而被排除。

**旧核心提取器按物理行切段，不能直接当作这些网页的原生段落提取器。** 独立检查发现 16 篇 Guava 文章的非空原生块数与物理行数不同。入口因此默认 `source_units` 边界模式，并拒绝旧物理行模式；仅与段落无关的全文字符分析可显式选 `full_text_character_only`。`document/1.0.0` 兼容性不等于已实现原生结构感知的全部下游文体特征。后续段落／序列算法应消费 `source_units`，并按预先声明的内容角色处理规则分析，不能忽略这些元数据直接沿用旧段落结果。

## 来源、语言、体裁与权利

所有记录保留来源机构、文章 URL、作者页、署名和记者／其他贡献角色、原始正文哈希、发表日期声明、抓取时间与更新字段。主要语言变体标为台湾繁体中文出版语境，不能把地区／字形差异直接解释为作者风格。

本批包括：公共／社会评论 15 篇、田野／旅行随笔 12 篇、书影／表演评论 8 篇、个人／研究反思 6 篇、环境新闻报道 6 篇。体裁标签为暂定内容分类，不是独立验证过的金标准。保留已知转载、跨刊、译者后记与同一田野系列关系；跨旧语料的近重复检查尚未完成，所以没有新分配 TRAIN／DEV／TEST。

权利依据保持原样：Guava 文章级 CC BY-NC-ND 3.0 Taiwan；環境資訊中心为有例外的站点默认 CC BY-NC-ND 4.0。范围是已审查来源的受限本地非商业研究，须保留署名、NC／ND 约束和第三方内容例外。录入不构成商业训练许可、派生文本发布许可或全量正文再分发许可；更广泛用途仍需按具体用途审查。隐私与敏感内容的逐段审查要求继续保留。

仓库只包含代码、模式、公开来源元数据和汇总验证，不包含正文、HTML、私有样本或词句级测试输出。未经许可的报导者来源仍不纳入，也没有访问个人博客。

## 与现有登记和冻结实验的关系

仓库中的 `research/source-registry.json` 已通过替换件更新：旧 11 条来源记录完整保留，追加 Guava、einfo 两条及新的操作性录入政策。`research/corpus-registry.json` 索引本次明确录入版本；它不冒充所有旧来源的重新清点，也不重新分类此前结果。

验证对照了原有 M4 与自然文本实验的 87 个冻结相关文件，内容哈希全部未变。47 篇新记录的 `experiment_id`、`split` 均为 null，`fit_authorized` 为 false。以后若为它们启动新研究，应显式选择语料版本、确定用途、完成必要的角色／隐私及跨来源近重复处理，再建立新的分组划分。

## 本地复现

只校验公开登记（标准库）：

```sh
python loader.py REGISTRY.json
```

校验获准的本地缓存并进入实际研究输入，不输出正文：

```sh
python loader.py REGISTRY.json --source-root /path/to/historical-author-expansion-20261002
python -m unittest discover -s . -p test_loader.py -v
```

程序入口：

```python
from loader import iter_feature_analysis_inputs
inputs = iter_feature_analysis_inputs("REGISTRY.json", source_root)
# 逐条消费 input["source_units"] 与 input["document"]；对象包含正文，只能留在本地
author_inputs = iter_feature_analysis_inputs("REGISTRY.json", source_root, cohort="single_author")
```

完整模式／仓库契约检验使用 `jsonschema`，并读取已有仓库的契约模块，不启动提取器或拟合器：

```sh
python verify_admission.py --source-root /path/to/source-cache --core-repo /path/to/style-compiler
```

`build_admission.py` 在输出前核对两个已审阅来源目录的固定哈希和恰好 47 个不同作品，防止其他文章被悄悄加入同一录入版本。正文哈希或来源目录变化时应停止并审查新版本，不能静默改写本版本。公开元数据无法恢复未发布的私有缓存；这是复现所需的实际输入边界，不影响本批已完成的本地录入。
