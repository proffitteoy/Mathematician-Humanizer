# 2022 年之前中文真实来源语料扩展计划

核验日期：2026-10-01。目标是约 1280 条训练来源记录，并另留开发与测试；句子、窗口、改写副本和译文不冒充新增作品。

## 结论

扩大十倍有明确的来源容量，但尚未形成 1280 条通过全部资格、去重与泄漏检查的训练记录。优先路线是已核验历史许可的中文维基新闻与维基导游快照，加三位明确授权的博客作者；现有 WikiConv 2017 也有扩大“记录内部序列”抽样框的空间。学术论文与文学散文的严格历史数字版本证据仍有缺口，应单列处理。

所有历史来源都只证明某一版本的存在与可重取性；它们不自动成为已验证的纯人工或无辅助写作。下载和版权核验也不等于模型准入。

### 实际质量审计改变了怎样使用这些页

新闻 6,422 个非重定向页带有头条汇编模板，1,136 页带 VOA 来源模板，667 页带原创报导相关分类或模板标记。这些都是来源自身的标记而非审核后的文类真值。主空间 12,321 页末次编辑账号名称像 bot；这既不能证明文章由 bot 撰写，也不能被忽略，应在正文投影和编辑角色记录中处理。旅行指南 4,249 页带 outline 模板，2,289 页带 listing/see/eat 等列表模板。

未经模板展开的 wikitext 经“至少 200 字符、常用汉字基本区及扩展 A 粗计占字母数字至少一半、无新闻头条汇编模板”这一粗筛后，新闻为 4,868 页、导游为 1,991 页。该条件仅说明容量；URL 和模板参数会改变汉字比，不能当作最终语言或序列合格门。主空间最新修订分别截至 2021-10-20 与 2021-10-19；没有 2022 年及以后的主空间修订。原创标记667按Original模板或原创/原創分类取并集；仅模板为662，分类11页，其中5页在模板集合之外。

跨两包未发现整页 NFKC/空白归一后的相同非重定向正文，但 410 页共享至少一个至少 200 字符的原始空行块，共 128 个共享块哈希家族。没有整页精确重复不表示独立：近复制、同一事件、共用引文、导入和地区层级仍须处理。

## 现有 WikiConv 可以怎样扩展

冻结的窄资格框只有 241 个可用已知分量，已分配 192 个，剩余 49 个。这个上限依赖当前“结构完整会话、8 至 64 单元、长度和脚本门”等条件，并不是整个 2017 年文件的上限。

只读已有结构元数据得到：全年非标题顶层记录中，200 至 20,000 字符的有 117,266 条，落在 66,651 个已知页面/复制分量中；排除旧 192 个分量和所有已知暴露分量后，剩余 **66,298 个元数据容量上界**。它没有验证至少四个可见前缀单元加一个目标，没有检查正文语言、角色、解析支持和新增近重复；绝不是已准入独立样本数。

新研究可以先声明“记录内部序列”估计目标，重新证明最少前缀与目标要求为何足够，再建立新的资格框。不应为了达到 1280 在看到效果后放宽去重或反复改门槛。旧 192 个训练/开发/测试分量及其新增链接全部保持历史角色，尤其旧 32 个测试分量已完成一次性评估，属于已消耗的基准，仍须全分量排除，不能重新包装成训练或新的未见测试数据。其他年份 WikiConv 可能增加来源记录，但相同页面、发言者、模板、跨年修订和恢复仍会重复，年份不能充当独立样本标记。

这次容量核查没有读取旧测试正文、解析目标或拟合结果；既有近重复图只覆盖旧候选与暴露内容，新框必须重新执行全量跨源复制审查。

## 学术与文学来源的空缺

### PMC 中文开放论文

2026-10-01 的官方 ESearch 查询“中文、CC BY、发表日期不晚于 2021-12-31、非禁运”返回 **2074 条当前目录记录**。这是出版年份与许可筛选，不证明当前 XML/PDF 字节在 2021 年已经存在，也不是 2074 条独立可用作品。

本轮没有把这批记录下载为历史学术训练集。PMC 明确说明内容更新可能不增加版本号，库存 LastModifiedDate 也可能仅是元数据处理时间；旧 oa.fcgi 服务已于 2026-08-25 退役，旧 FTP/Cloud 批次文件也已移除。正确下一步是从现行官方元数据逐篇追踪期刊出版版本、历史 PDF 或有版本日期的存档，对比原始哈希；找不到截止前字节证据的记录保持“旧出版年、当前版本”层。

优先方法/综述/聚合实验研究，谨慎处理可识别患者个案；按 DOI、PMCID、稿件与出版版本、勘误/撤稿、中文与英文摘要组成作品家族。合著者、通讯作者、编辑、译者与真正写作角色不能混用。

来源：[PMC 版本与获取说明](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/)、[退役说明](https://pmc.ncbi.nlm.nih.gov/tools/oa-service/)、[现行数据 README](https://pmc-oa-opendata.s3.amazonaws.com/README.txt)

### 文学散文

Project Gutenberg 的《朝花夕拾》25271 和《野草》25242 有作者、语言、发布与更新日期，前者明示美国公有领域；可作为文学补充线索。但当前 cache 格式会定期重建，不能仅凭作品年代或“最近更新 2021”就称当前下载字节为 2021 快照。应找原始版本文件及历史存档，逐书核验适用司法辖区、底本、译者/校勘者。合集中的原先独立发表篇目可在书目证据支持下分作品；章节切片和同一小说的多卷不能虚增独立作品。文学时代、字形、旧标点与编辑习惯应作为单独压力层。

## 下一轮取得 1280 条训练记录的准入步骤

1. 先建立约 1800 至 2000 个**独立作品/页面依赖分量**的合格候选框，再预留开发与新测试。1280 只指训练记录，不包含窗口或同页多版本；最终数量由审查结果决定
2. 冻结来源、许可、时间证据、原作/译作/引述角色、中文正文投影、最短有效序列与断点规则。要么保持本轮 source-view 目标，要么明确改为正文目标，不混用两者
3. 将旧训练/开发/测试与所有暴露材料接入同一个 copy/lineage/exposure 图。新增边连接旧测试时，整个连通分量保留历史测试/已暴露角色并排除于新训练与新测试；不导出旧测试标识
4. 先按原始字节、NFKC/空白归一、长连续文字、5 字符 shingle/近重复、原链接与译文/修订关系分组，再划分。公共模板单独登记；不能因模板连通太大而看完效果后删边
5. 主报告按来源与文类分别给数量、长度、支持率、缺失与损失，另设 source/author/topic/time 压力层。三位技术博客作者不能代表所有中文作者。新开发数据可调参，新的一般化结论必须使用与旧基准隔离的全新holdout；新测试只有冻结后一次开启
6. 当前稳定的扩量材料以讨论、新闻、旅行说明、技术博客和少量随笔为主；严格历史学术与文学层凑不齐时如实报告缺口，不把旅行指南改名为散文，也不拿摘要冒充全文

## 状态与复核入口

配套 catalogue.json 是可机器读取的来源表；wiki-census.aggregate.json 给出实际下载快照的结构审计；wikiconv-metadata-capacity.json 给出宽框容量上界。原始全文、逐页定位与样本细账均保留在项目仓库之外。此交付没有修改实验代码、旧分割或模型，也没有使用个人化阶段材料、付费 API 或新账号。

## 修订与复现

2026-10-01独立复核修正了六个Git根树标识、原创标记并集662→667，以及旧32个已消耗测试的状态说明。REVISION_LOG.json保留受审原文件哈希和本次修订关系；scripts/REPRODUCE.zh.md给出角色统计、容量和catalogue的可复现入口。公开脚本只输出聚合统计，并消隐公开高频分类中的记者身份标签；原文、逐页账本、旧分割身份继续置于仓库之外。角色计数与语言粗筛均不构成纯人工/独立作品认证；1280仍是下一轮准入目标。
