# 既有暴露来源排除指纹 v1

状态：一次离线派生完成，内部只读结构核验通过；不等于10× G2准入。

预先冻结的私有allowlist覆盖第三方39篇博客、6篇PMC、WikiConv2002格式探查，以及旧667个选中/暴露组件并集的5780页。2017全部323777个预定来源/版本视图已对已有只读census哈希核验；包含top_level、original、deletion、modification、restoration。没有读取模型输入、POS、目标、预测或用户个人文字，没有新下载和新语料校准。原始来源字节未更改。

签名类型：UTF8文本原始SHA256；Unicode15.0 NFKC去空白全文SHA256；规范长度至少64的物理空行块和punctuation-lines/1.0.0操作单元哈希；不同字符5-shingle的全SHA256集合。文件原对象哈希、成员和来源角色作为私有bindings。页面成员键采用wikimedia/project/page:规范整数，来源视图身份另存。内容签名的域跨来源相同才能查复制，命名空间在成员/来源关联层而非把source混入内容哈希。

私有SQLite使用共享gram字典与逐文本排序delta-varint+zlib集合，不保存原文或明文gram。哈希和成员关系仍可能透露文本成员性，数据库、allowlist、逐源定位和个别指纹均不能公开。公开仅本目录代码/聚合/哈希。

100541个压缩文本集合及14623976个gram成员已解码核验，323777个旧2017视图再次逐项匹配原元数据，SQLite完整性通过。内审未重开原文；独立审查仍待完成。

限制：这是原source-view/文本槽位指纹，不是经清洁验证的作者正文。旧博客代码/markup、PMC元数据/参考文献也可能进入排除指纹，不能把这些集合当可训练正文。后续新候选须同时匹配raw与投影视图；无法建立兼容投影、发现具体未决复制谱系或缺来源覆盖时，必须隔离而不是宣称无重复。新取得3个pre2022博客诊断代表不在本次具体allowlist内，尚缺指纹。语义改写或其他未观测外部谱系不可能由无匹配证明不存在。

运行代码只许一次标记且拒绝覆盖；不要再次运行fingerprint.py。verify_package.py只读已有包，可由独立审查者重复；不会重读原文或模型目标。当前完整私有目录体积应计入后续总衍生物预算，不能只统计数据库。
