状态：已实现、合成测试及一次性派生自检通过，等待独立审查。此结果不等于 G2 准入通过，不授权新自然正文校准。

## 一次性增量

在首次打开正文之前，冻结了既有收据中的三篇已获许可、第三方、非所有者诊断博客的原文 SHA256、Git blob、字节数、来源角色与许可证据哈希。三篇共 52,679 字节；没有下载新材料，没有打开任何旧源正文，也没有重跑旧派生器。

独立增量仅保存三个 raw Markdown 来源视图的非明文签名，沿用已审查的 Unicode 15.0.0 NFKC/去空白、分域 SHA256、至少 64 字符长块及完整 distinct 5-gram 合同。数据库为 1,658,880 字节，包含 3 个文本、18,637 个不同 gram 摘要和 3 个成员绑定。数据库 SHA256：225d002fa7dc3436cb50075e712bff8d263fbf1bc802823fe43ef76a925c5a08。

旧排除数据库 SHA256 仍为 0ca3ca3eec71b88498ed70990804a7dc72d33dc736a0174edd3fdce5e258c3f5；旧包未改变。

## 已实现接口

- SignaturePackage(path, expected_sha256, name)：校验整库身份，以 SQLite 只读模式加载
- match_record(raw_text, projection, packages=..., expected_raw_sha256=...)：比较完整 raw、每个投影片段、每个连续 raw 来源区间，不跨 barrier 拼接
- match_records(records, packages=...)：每批最多 1,024 个视图、200 万个候选 gram 成员；每个参考库每批只扫描一次，不逐条重扫旧库
- SignatureWriter：创建新的私有签名库，SQLite 完整摘要索引去重，不复制旧字典，不保存明文
- exclusion_edges：把全部命中参考成员转换为带包哈希与来源角色的依赖图边；可去掉同成员自边

包内 gram 整数 ID 仅在该包内有效。新候选通过完整 SHA256 映射到各包，未命中摘要仍计入候选完整分母。近复制使用 shared >= 40 且 5×shared >= 4×min(两侧完整 distinct-gram 数)，不降低阈值。

所有批次应共享 comparison_budget={used:0,cap:300000000} 和资源回调。每个共享 gram 对候选—参考计数器的加一都会在执行前收费；精确命中比较另行收费。长 gram 解码循环、文本扫描、长块扫描及绑定读取均设资源检查点。原始视图上限 2 MiB；超限、缺库、哈希不符、映射不完整等情况进入隔离。

## 实测覆盖，而非覆盖承诺

28 项纯合成测试全部通过，其中包括不同字典插入顺序、未命中 gram 分母、40/0.8 精确边界、单对多 gram 超预算、跨 barrier 不拼接、字节身份变化、缺包/缺映射、绑定传播，以及对抗性旧 markup／新纯正文漏检。

三篇材料均对全部 100,541 个旧文本签名执行比较，再对三篇增量比较；三篇完整原始视图均以 exact raw 命中。另用仅供排除诊断的简单 Markdown 删除投影检查实际灵敏度：

- 149 个投影片段中，92 个命中原始视图签名，57 个未命中
- 149 个连续 raw 来源区间中，109 个命中原始视图签名，40 个未命中

这些比例不是一般召回率。诊断投影不是获批自然正文资格判定器，片段也不是独立评估集。短片段、碎片化/重度转换、没有保留长块边界的摘录及语义改写可能没有足够共同 gram。保留完整新 raw 仍不能保证匹配另一来源的旧 markup：在每个字符间插入 markup 的合成反例中，旧 raw 与新纯正文 raw/projected/span 均可不匹配。

因此接口明确区分 complete_declared_view_comparisons 与 cross_projection_coverage_certified；当前后者始终为 false。完整处理已有视图不能证明跨投影等价。未命中状态为 quarantine_unmatched_cross_projection_coverage，不会自动准入。未来旧投影增量必须另行冻结、运行和独立审查；本包不能代替该证明。
