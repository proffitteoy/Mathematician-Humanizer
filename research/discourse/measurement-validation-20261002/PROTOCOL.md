# Frozen experiment protocol: Chinese multi-scale structural views

## Question and scope
Do an ordered layout view and a native, labelled RS3 graph view retain the supplied gold paragraph and rhetorical structure? How much do a few structural summaries and exact anchored graph features change under the available alternate human annotations? This is a ten-document representation and measurement test, not a learned parser, text-quality predictor, authorship detector, or test of argument truth.

Pin: GCDT `6846a7e21a3a91f29e1376fe4a0f27c4810f2f51`. Use only the five development and five test IDs in the existing manifest. Download XML, gold tokenized sentences, native RS3; for test also double RS3 and both pre/adjudication segmentation files. Do not load Stanza syntax, translations, training documents, or owner text. Keep source bytes in a private temporary cache, under 10 MiB. Export code, synthetic tests, provenance, aggregate/per-document measurements, and failures only; never export source prose, per-sentence hashes, full annotated views or trees. All ten documents become exposed calibration material and are ineligible for future held-out claims.

## Representation and alignment (definitions frozen after development)
- XML body is `''.join(root.itertext())`, excluding all metadata attributes. Paragraph units are nonempty runs separated by a blank line in that body. These include headings/list items where represented as their own blocks; they are source-format paragraphs, not independently inferred prose paragraphs. Record this convention.
- Tokenized files have one sentence per nonempty line; whitespace-separated tokens are the gold tokenization. Character coordinates count Unicode code points after removing Unicode whitespace. Do not normalize punctuation, case, traditional/simplified Chinese, or apply fuzzy matching. The XML, sentence and EDU streams must match exactly before producing cross-layer measurements. Alignment failure is missingness, not a silently repaired score.
- EDUs are native RS3 segments in file order. IDs must increase. Native vertices include both segments and groups. A segment may itself have dependent children: it is not incorrectly treated as a childless leaf. Each vertex retains original ID, kind, group type, parent ID and relation. Nuclearity is N for `span` or a declared `multinuc` relation, S for a declared `rst` relation, ROOT for no parent, unknown otherwise. Header relation definitions are retained. Do not binarize or convert to dependencies.
- A vertex's yield is its own segment (if any) plus recursively all descendant segments. Keep the exact ordered EDU-index set, and report discontinuous yields. A bounding interval must never erase gaps. Native root-to-EDU paths retain every vertex, relation and nuclearity label.
- Layout contains ordered token/sentence/paragraph/EDU character spans. Each paragraph projects to intersecting sentence/EDU IDs and all intersecting native vertex IDs; hierarchy references remain global, preserving cross-paragraph structure. Multiple membership is explicit for boundary-straddling EDUs/sentences. The union of paragraph projections must recover all native vertices, and the shared edge table must recover every labelled parent edge. This verifies an information-preserving representation, not independent structure recovery from raw text.
- Entities, coreference, bridging, argumentative support/attack/truth, human/AI provenance, perceptual rhythm and coherence quality are explicit nulls with `no_gold_layer` reasons. Lexical recurrence would not fill entity identity, and RST evidence/elaboration is not argument support/truth. No imputation, lexical entity proxy, or latent quality score is used.

## Small observable panel
1. Ordered sentence character lengths and per-paragraph sentence/EDU membership counts (internally, plus aggregate counts externally). These are layout proxies, not perceived rhythm.
2. Native mean/max EDU parent-hop depth, normalized max depth by `max(1, n_EDU-1)`; native group count and fraction of groups with more than two direct children. These are explicitly encoding-dependent RS3 depths, not binary-Parseval depths.
3. Fraction of group yields intersecting more than one paragraph, and boundary-LCA depth: for each paragraph boundary, take the nearest EDU on either side and the common ancestor's native root depth. If one EDU spans that boundary, flag that fact separately. No semantic coherence inference.
4. A histogram of incoming non-`span` rhetorical labels, and satellite fraction among nonroot incoming native edges. Labels, nuclearity and their entire nesting are retained in the view, rather than collapsed into these summaries.

## Evaluation and agreement
- Compare an independently read set of native RS3 vertex attributes/header relation definitions against encode→JSON→decode; compare paragraph and sentence spans; recover all native vertices/edges from paragraph projections. Expected exact retention is 100%, reported as software/representation consistency only.
- Alternate segmentation: compare internal normalized-character EDU boundaries (document start/end excluded), precision/recall/F1. Report both primary RS3 versus double RS3 and repository adjudicated-seg-test versus double-seg-test. If their character streams do not match, that pair is missing and no fuzzy repair is attempted. Do not assume the double RS3 uses pre-adjudication segmentation.
- Native graph agreement: multiset overlap F1 on exact character-yield signatures for group vertices; then on each nonroot vertex's child and parent character-yield signatures, kind/group type, incoming nuclearity, and incoming relation. Report separately span-only, nuclearity-labelled and relation+nuclearity-labelled edges. Exact-yield sets preserve discontinuity; no node IDs are used across annotations. These are bespoke native anchored multiset measures, **not RST Parseval**, and are not numerically comparable to the paper's binary benchmark.
- Measurement sensitivity: paired absolute differences for paragraph-crossing group fraction, mean/max native EDU depth, normalized max depth, branch fraction and satellite fraction. Report per-document values, macro mean/range, and document-ranking pair flips (ties separated), with five paired documents. No population CI or human ceiling claim from this tiny heterogeneous panel.
- No model is run: parser accuracy, raw-text structure extraction and argument correctness are `not_evaluated`.

## Perturbation controls
Synthetic four-sentence fixtures compare a balanced and right-branching multinuclear hierarchy with identical text, sentence bag and relation/nuclearity histogram; the full hierarchy view must distinguish them. Sentence-order reversal and moving a paragraph boundary retain the sentence bag; ordered layout and paragraph projection must distinguish the respective change. A relation-only and a nuclearity-changing edit must affect the labelled hierarchy view even when the unlabelled graph is unchanged. A JSON round trip must not change any view. For corpus documents also reverse the ordered sentence sequence and move one paragraph boundary to an unused sentence boundary, reporting inapplicability explicitly. These establish sensitivity/invariance, never degraded or improved perceptual quality.

## Freeze and stopping
Develop only on five dev bodies and synthetic fixtures. Before accessing test bodies, record this protocol, evaluator, downloader and test code SHA-256 hashes with a UTC timestamp. Evaluate all five test documents once under that frozen evaluator; no retuning after outcomes. If a test failure occurs, report it and retain it. Any later corrected run would require a separately versioned protocol and those test documents would remain exposed.

Limit one standard-library Python process, capped at 512 MiB address space, 600 CPU seconds, at most two CPUs (implementation is single-threaded). Record wall/CPU time and peak RSS. No ML training, rewriting, paid APIs, remote writes, or corpus release. Download/source metadata does not resolve the repository Apache versus paper CC-BY discrepancy; retain document source URLs and rights uncertainty, and make no redistribution clearance claim.
