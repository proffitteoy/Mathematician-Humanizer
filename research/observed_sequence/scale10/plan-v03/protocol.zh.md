# 10× 历史来源、多视图观测动力学：待批准协议 v0.3

日期：2026-10-01。状态：**预注册草案；没有新抽样、正文投影、解析、拟合或测试开封。**

## 结论与决定

目标为 **1280 train / 320 development / 320 fresh test，共 1920 条来源记录、1920 个已知依赖分量**。1280 是旧训练记录数 128 的十倍，不是 token 数、独立作者数或统计功效的十倍。旧 192 条所在的全部已知页面/复制分量、475 个旧暴露分量及新语料诊断样本继续排除。旧 32 条测试已消耗，不能再次标为未见测试。

已有本地候选足以提出三来源方案，但尚不能保证完成配额：WikiConv 讨论记录、Wikinews 页面、Wikivoyage 页面。它们是 **三个采集来源/任务框，不是三类纯净体裁**；新闻汇编、翻译、引文、模板和旅行条目列表必须先分角色和投影。三者也都来自 Wikimedia 生态，不能据此宣称跨独立出版制度泛化。

本轮科学推进包括：相同前缀下的全局测量、局部序列、可审计词形复现关系三视图；多头观测目标而非只预测 POS；一个单独的段界恢复与候选排序支线。后者是窄布局干预，不能宣称完成保义改写或个人风格编译器。

## 2. 来源、权利与角色投影

每条记录保留 source/work/page/revision/object IDs、原始 SHA256、版本/许可证据、投影版本与哈希、角色跨度、源到投影字符映射、丢弃原因、已有归属键及其明确角色。私人定位只留本地。

许可沿原对象继承：WikiConv 内容 CC BY-SA 3.0（metadata CC0，Figshare 通用徽章冲突仍记录）；Wikinews 历史文本 CC BY 2.5；Wikivoyage CC BY-SA 3.0。item-level 例外、翻译、引文和第三方材料不得被整站许可覆盖。未知权利的段落不能通过“去掉引号”准入。没有新下载、账户、协议或数据发布。

来源角色先分类，后统计可用正文量：

- 讨论：顶层记录中可投影的论述/请求/协作片段；引用回复、签名、机器人声明、自动通知分别标记。无可靠证据时任务为 unknown，不由语气推断作者或行为真值
- 新闻：保留可追溯的叙述正文；头条汇编、来源条目、已识别 VOA/翻译转载、许可未决的引文块单独隔离。来源的 original 标记只作来源角色字段。不能把 Source 模板参数拼成正文
- 旅行：叙述性指南段落与景点 listing 参数、地址/电话/价格字段、导航、地图、标题、图片说明分开。outline 是编辑状态，不能直接当“无正文”或完整体裁；有合格连续正文仍可候选

投影采用固定、离线、拒绝未知构造的原始标记解析器，不运行 Lua、模板或来源脚本。允许删除经测试的纯语法定界符、解码 XML 实体、保留 wiki 链接的可见标签，须逐字符回指原来源；禁止改写词语、繁简转换和用模板展开补文本。块级模板、代码、表格、列表、标题、引用块、个人联系方式与未决语法均为屏障；不能跨屏障拼接序列。行内删除若可能改变词汇相邻关系，整块不准入，不能插入空格假装原文。引用与作者叙述边界未决时隔离该块。

同一来源记录允许多个有 provenance 的片段，但只选择一个片段进入模型：按预先固定哈希选一个满足 8–64 操作单元、每单元 ≤512 codepoints 的连续片段，最多取其前 32 单元。该片段是投影视图中的连续序列，不声称原始字节是无标记散文。保留原始段/行区分；物理换行不自动等于语篇段落。

## 3. 校准、固定取样、依赖分量与分割

校准抽样框为三来源的既有元数据：显式非标题的顶层讨论记录或主空间非重定向页面，原始200–20000 codepoints；尚不按正文体裁、Han、单位数或投影质量筛选。先排除已有旧/诊断组件，再按旧已知组件选哈希最小代表、按 rank("calibration", [source_frame, component_id]) 取每源32条，共96条。这里的32首先是元数据已知组件数，不是已证明独立作品数。它们用于实现与两个独立助手复核角色和来源映射，及其所有后续连接分量成为已暴露，不进入1920；不是人工金标。若新依赖图把任一来源这32条合并到不足32个最终组件，保留全部检查和合并记录、标 calibration_underfilled 并停止，不静默追加。任何扩充要在新版本清单中先获批准。每来源任何一个未决的权利、角色拼接或字符映射问题都阻止该投影类别准入，修改版本并另存失败收据。报告 96 个分量的逐项差异和未决比例，不能用少量“准确率”证明全部正文清洁。

随后从同一元数据抽样框中，先排除当时已知的旧、诊断和校准组件，再按 rank("candidate-frame", [source_frame, record_key]) 固定最多 **6000 个候选记录**：讨论3000、新闻1500、旅行1500。这个候选清单在任何候选正文资格检查前单独哈希封存，不是滚动取得6000个成功样本。后续投影/Han/单位/边界/新复制边和扩大排除组件造成的损失一律不补；框内记录少于上限则保存真实数。流式解压会经过未选记录字节，但只对冻结候选作正文资格、角色和指纹处理，不记录或解析其余模型目标。各规则在此读取前冻结。6000候选只由已冻结代码自动处理；任何助手/人直接阅读自然正文、或把失败例用于调投影，必须先记 exposure，再排其全部最终连通分量。个别权利/角色必须读正文判定时也遵守此规则，不能回流 fresh test。仅元数据普查不等于阅读正文。

在分割前对全 6000 候选及所有既有暴露/排除指纹建图：

1. 同页面、作品修订、渲染/源文件、明示翻译、转载、来源系列/事件或直接地方章节谱系建立硬边。已发现具体记录对的事件/翻译/连续章节关联若尚未解决，保守 union 或隔离整个相连组，不能只标 unresolved 后跨split。没有具体作品/复制证据的广域地理标签和未知作者身份仅作敏感性，不宣称这些依赖已消失，也不宣称作者留出
2. 继承旧 all_page_component_map 和所有排除分量；旧 192 全部排除，不能只排除 32 测试记录
3. 原文与投影 NFKC 去空白全文精确哈希；64 字符以上的连续投影单元/正文块精确哈希；全候选字符 5-shingle containment ≥0.8 且至少 40 个共同不同 shingle 建近复制边
4. 跨三个来源运行相同复制检测；与旧暴露博客/PMC、旧小格式探查和新三个诊断博客的已知指纹比较。现有旧sampler没有持久化完整NFKC长块/5-shingle指纹，只保存组件与原文哈希；因此G2目前因指纹不足而阻断。Root已单独批准一次有界离线补指纹，但尚未执行：从预先哈希白名单中的已有第三方39博客/6PMC及旧已选/暴露WikiConv组件离线流式生成指纹；没有新下载、解析或目标读取。用户个人文章始终不在白名单。授权不代替执行/审计；无法完整重建就保持G2未通过，不把原文SHA冒充近复制证据
5. 不按高频 shingle 静默删候选边；使用倒排交集计数精确复核，达到资源上限则停止。语义改写复制仍可能漏检，不称完全独立

成员键固定为规范JSON [canonical_origin, project, object_id]。WikiConv/discussion/mediawiki来源别名通过白名单统一成["wikimedia", "zhwiki", "page:<规范十进制ID>"]；新闻/旅行各用zhwikinews/zhwikivoyage，故跨wiki相同整数pageID不相连。来源档案、版本和view role另存，不改变同一页面的成员身份。未注册别名拒绝，不猜映射。旧分量先展开为旧成员/祖先边；曝光沿成员污染传播，任何新候选与旧排除成员合并，整个新组件被排除。最终分量由成员键排序后的规范 JSON 哈希命名，不能用新旧component_id字符串是否相等判断排除。一分量只选一个代表记录；跨来源连接的分量按全局哈希最小记录归属一个来源，不能同时填两个配额。分量归属与记录选择不看目标、支持率或效果。每来源按哈希顺序依次分 train/dev/test，不做模型结果驱动的重新洗牌。

选定后即冻结原对象、角色图、投影、分量、单位/段边界、配额账本和抽样代码。解析失败、0 个有效目标保留覆盖分母，不能替样；主损失仅在有效记录条件上平均。所有目标的共同账本由目标定义构建，与模型成功与否无关。开发集不能反向改筛选规则；发现真实缺陷须产生新版本并作废旧性能对相同问题的“未见”主张。

## 4. 两个不同实验问题

### A. 观测多视图动力学

目标不再仅是 POS，但仍是 **固定解析器/投影的观测输出**：

1. 14 类 lexical UPOS 组成，CE / log(14)
2. 27 个既有 dependency base-relation 加 OTHER 的 28 类组成，只计两个端点都是 lexical token 的合法非 root 弧；CE / log(28)
3. 下一单位 NOUN/PROPN/VERB/ADJ lexical token 中，其 NFKC 精确表面词形是否已见于合法前缀的二类组成；CE / log(2)。大小写不变，不词形还原，不把同形词称为同一实体
4. log1p(下一单位 lexical token 数) 的平方误差，目标仅按 train 记录等权均值/稳定方差标准化；若训练目标严格常量则停止并在 fit 前修订，不能用任意 epsilon

主复合损失是四头损失的等权平均；权重属于预声明的工程选择，不是独立性、联合文本似然或“风格质量”的数学结论。主 ledger 只收四头均有定义的预测点（弧和内容词机会必须 >0）；另报告 POS-only 全覆盖辅助结果，不能用不同模型各自的目标集合。每记录先平均，再按来源框各自记录宏平均，最后三个来源框各 1/3。完整覆盖与各头的条件支持并列报告。若某头在训练中严格常量，停止并在任何 fit 前修订，不静默改目标数。

前缀输入仍需实际观察到闭合证据；模型输入不包含 EOF 片段、目标分母、未来长度、全文归一化、原始偏移、末尾位置或目标有无。目标可为固定投影视图的终端/删失单位，但不是自然完整句或作者真实停止事件。端点诊断在全部预测哈希冻结后计算。

三输入视图：

- global：同一合法前缀的 68 个局部通道各取 7 个排列不变摘要：有值均值、总体标准差、最小、最大、log1p(已知机会之和)、有值比例、机会已知比例，共 476 维；无 value 时前四项填0，第五项独立累计已知机会（全未知则0），后两项区分支持。前五项分别使用 train-only 记录/来源等权的稳定缩放，两个支持比例保留原0–1值；每记录内对合法前缀等权，不让长记录多占变换拟合权重。摘要经 GELU Linear(476,16)。绝不从全文计算；它是同一测量的汇总视图，不是独立测量模态。100-token 局部通道不会因汇总而假装获得支持
- sequence：同一 68 通道的 value/presence/log-opportunity/known 共 272 维局部序列，逐单元 GELU MLP 272→16，随后 DeepSets 或单层 GRU(16)
- relation：单位—精确内容词形二部图，边携带已观察出现次数及 POS 分布，词形 ID 仅用于同形相等与边构造，无词表/作者/专名 embedding。两轮共享参数的单位→词形→单位均值消息，16 维 readout。这是词形复现关系，不是共指、命题、论证或语篇动作图

共同外部情境只有已知来源框 3 类 one-hot；完整文章推得的角色、题材、日期、作者、页面类别等均不作为输入。源/体裁完全混淆仍存在，即便模型不直接看到站名也不能去除。作者支持、对比损失、稳定作者潜变量和人类/AI 标签保持不准入。

固定六组 × 三种子：N 缺失/长度/来源；P pooled raw + global；S DeepSets + global；D GRU + global；SG DeepSets + global + graph；DG GRU + global + graph。所有全局、图编码不携带单位顺序或位置；因此 D 对 S、DG 对 SG 是相同合法前缀、近似参数预算的结构模型比较。它们并不能单独识别纯顺序信息的因果效应：架构和优化也不同。图提供的新信息是词形复现结构而非 parser 通道数量。S 对 P、DG 对 D 是预定辅助对照。固定融合头为 Linear(37,48)→GELU→四输出头；含图则输入53维。37=局部16+global16+两个已见长度+来源3。N 用136个局部flag均值+上述5个外部量，经141→48→四头；P 在原272维先均值再272→16→GELU；S则每单位先非线性再均值。各组实际参数数在实现时打印，≤30k；S/D 与 SG/DG 参数差须≤较大组的10%，否则在读取自然目标前修订架构并重新审核，不能靠结果调宽。

主检验为同记录 seed-mean 的 SG loss − DG loss；S−D 与 D−DG（均为正值有利于后者）为预声明辅助。POS 子头单独报，以便与旧实验联系，但不与旧不同采样的 CE 直接作因果增益比较。本草案只准许 **6×3=18 次主拟合**，没有隐藏搜索臂。顺序打乱是测试后固定权重的扰动诊断，不新增 fit，也不等于重新训练的置乱控制。

拓扑仍是主架构的待完成活动支线，但本次不靠小窗口伪造 PHD 估计。先在上述冻结的 feature-state 点云上计算 H0/MST 的合成/不变性接口和覆盖，明确这不是语境 token 维度；其独立增量需另行预注册 Topo-A0–A4、匹配几何基线及足量点数，不能借本轮三视图通过完整拓扑门。此处没有偷换完整主模型的验收。

### B. 段界恢复与布局候选排序

它使用同一数据分割，但单独命名为 retrospective-layout；目标是恢复来源中经投影确认的段落边界，不是使原作必然优于编辑。必须先从完全去空白的相同字符序列重新建立layout-neutral单位：固定只依标点的切分规则，不依原换行/段落。可复用A冻结权重，不能复用A的原单位切分、features或graph。相同非空白序列的不同原布局，整个unit spans/features/graph/context须相同；原始到neutral的字符映射仅作标签/回指sidecar，不能入输入。去空白可能改变拉丁词间边界，是此窄任务的测量限制，不据此声称语义等价。候选位置也只由neutral序列的冻结规则/哈希产生，不能依原段号、原换行特例或隐藏标签。固定边界标签只作为 target。不能直接拿 A 的严格闭合“已见空白”去预测该同一空白是否为段界。

首步只制作冻结的候选集与泄漏测试：每个合格记录一个哈希选择的位置，候选包含原布局、插入一个段界、移除一个段界及等预算相邻替代；只改经允许的空白，不能断开引语、括号、引用归属或已知保护跨度，原文/no-change 始终可选。目标与副本仍属同一作品分量。

在 A 的 checkpoint 冻结后，如另获批准，可用其冻结表示训练一个独立小型 Bernoulli 段界头（固定 3 种子、≤50 epochs、总 ≤3000 updates/30min，候选及训练账本提前封存）。报告 log loss、校准和恢复能力，不宣称读者偏好。具有真实段落结构的覆盖不足就不训练。

实际排序效用需要另一个独立审核：从 train/dev 哈希固定 48 个记录，按来源各 16，两个互不看模型分数的助手先做意义/作用域/引用/任务资格 pass/fail/uncertain，另一轮只在合格候选上比较具名布局目标，保留平局。助手不是人类评审；这只能建立评审契约和风险清单。**没有人类读者偏好标签，不把 self-supervised 原版恢复分数叫保义或优质改写。** 自动意义检查仅保留 non-whitespace 序列及保护串不变的机械保证，语用强调仍可能变化。真正改写 RCT/独立人工评价另行设计。

## 5. 优化、冻结与评价

主 18 fits：seeds 1729/2718/3141，AdamW lr=.001，weight_decay=.0001，clip=1，无 dropout，batch=32 records，30 epochs。全 train 1280 条给每 epoch 40 updates，最多 21600 updates。训练以统一随机排列遍历所有记录；固定来源权重 N/(3*n_source_eligible) 乘记录损失，最后小批用实际 B，不能按小批来源重新归一化。0 eligible 只计覆盖，不伪造梯度。源内记录和目标等权。

train-only 冻结变换、prior、target normalization、词形图规则；不使用 dev/test 标准化。dev checkpoint 用同一来源等权复合损失，精确并列取更早 epoch。参数量、目标定义、配额、损失权重和学习率不因开发效果改变。固定源 prior、最近单位混合 prior、缺失/长度/来源 N 都要报告。每个来源、每个K类组成的 prior 明确为 (Σ_i record_mean_q_i + [1/K,…,1/K])/(n_source_eligible+1)，均匀pseudocount总量为1，不能误写成已平均向量加1而造成50%缩减；长度 prior 为同权训练均值。最近单位基线的 POS/依赖组成使用0.9最近已见组成+0.1来源prior，缺机会则退回prior；长度用同样混合的最近已见log长度与来源均值；下一单位词形复现头使用来源train prior，不能用不可见未来词形。所有这些目标预测都不把目标分母传入输入。

测试在所有拟合、最终 schema、代码及 18 checkpoints 公布哈希后，取得一次明确 root GO 才开封。同一共用 ledger，一次生成并哈希全部预测，再计算端点、角色/来源/长度支持、paired losses、来源内分层的分量 bootstrap 2000 次（seed 2026100201）和归属键聚类敏感性 2000 次（seed 2026100202）。后者键为来源限定的原归属代理、未知各自singleton，不把相同显示名跨站硬认同一人；每来源整簇重抽并保留成员/抽中倍数，再作来源等权平均，某来源不足2簇则报告undefined。两者规范排序采用SHA256([domain,source,key])，domain固定为observed-multiview-scale10-bootstrap/v1，区间为线性插值2.5/97.5百分位。mean loss across seeds 与 probability ensemble 明确区分；本次只前者。区间是固定模型、已知分量条件的描述性不确定性，不覆盖来源偏差、解析误差和隐藏复制谱系。只在主差值的预声明95%区间下界>0且三个来源点估计均不为负时，称为本冻结框内 DG 相对 SG 的增量证据；否则报告未确立/来源不一致。这个研究判据不构成产品效用或最小有用编辑收益阈值，也不允许按结果更换主对照。

## 6. 资源与独立准入

总预算：新下载 0；CPU intra/inter-op=2，从启动设置；RSS≤3GiB；无 GPU；所有新增私有衍生物≤1GiB。已有压缩档不复制；XML/ZIP 流式读取，不整包再展开。

## 7. 独立审核必须能否决的结果

权利未决、投影跨角色拼接、旧组件碰撞、复制边跨 split、unit source span 不可回指、未来后缀影响前缀任一视图、常量标准化非零、标签从原换行泄漏、资源超限、任一来源主 ledger 零支持，均停止，不用更换路径或输出目录绕过。实施如需改变该草案，保留旧哈希，先修订后运行。

本方案把现有 POS 学习推进为多视图观测动力学与窄布局学习，但仍缺真实语篇动作/实体—命题关系、独立语义测量、跨作者跨题材交叉支持和读者编辑效用。它是走向 Style Compiler 的可否证下一步，不是对整套风格模型已成立的宣告。
