# 冻结序列试点的一次性测试结果

**这份小样本没有建立GRU相对无序模型的可靠优势。** 按来源记录及已知页面/复制分量隔离的真实数据训练和测试流程已跑通；预测的对象仍是固定解析器的可观测POS组成，并不是已验证的作者风格或人类来源。

## 一次性执行与覆盖

测试在计划、代码、独立准入复核及15个checkpoint全部冻结后一次性打开，使用发布锚点bd2e471bb58e3615fdd7b8f167912d85bef7f29a。没有重新拟合、改参数、替换记录或使用测试数据估计标准化/先验。

- 原32条来源记录、485个操作单元全部保留；1个解析失败保留为屏障
- 357个原候选点中，194个输入边界未确认、1个目标解析失败、2个失败后的连续前缀不足，实际160个共同目标来自30条记录
- 另2条记录只保留覆盖，不赋零损失。20个预测系列使用完全相同的目标表
- 17个主比较器为2个固定基线和5学习臂×3冻结种子；另3个普通GRU的测试时顺序打乱系列只作扰动诊断
- 所有预测先持久化并生成摘要，再计算端点、页面类型和分量/账号键重采样汇总

## 主要结果

数值为条件记录宏平均交叉熵，越低越好；学习臂为3个checkpoint分别评分后的均值，没有评价概率集成模型。

| 比较器 | 测试交叉熵 |
|---|---:|
| 冻结训练先验 | 2.252120 |
| 最近状态固定混合 | 3.065877 |
| 缺失掩码和前缀长度MLP | 2.249627 |
| 前缀均值池化MLP | 2.210344 |
| 非线性DeepSets无序模型 | 2.213865 |
| GRU顺序模型 | 2.210855 |
| 打乱顺序训练的GRU | 2.232850 |

预声明主比较DeepSets减GRU为**+0.003009**。逐种子差为−0.007329、+0.014276、+0.002081，方向仍不完全一致。

- 30个有支持的已知作品/复制分量，2,000次重采样：描述性95%百分位区间 **[−0.042072, +0.046481]**
- 22个声明的顶层speaker键，保留每组内全部记录的依赖敏感性分析：**[−0.056618, +0.043808]**

两种区间均包含0，点估计也没有超过简单均值池化MLP。这里不能宣称有序结构改善了泛化，也不能反过来证明顺序没有价值。这些区间固定了已训练模型，只对当前可评分记录及已声明分组重采样；它们不包含解析误差、训练样本/种子选择的不确定性，也不能证明未知复制和共同编辑依赖都已解决。

将普通GRU的可见前缀在测试时打乱，均值交叉熵变为2.288568，比原顺序差约0.077713。这表明该模型对输入顺序敏感；分布破坏造成变差，不等于它优于强无序预测器。该诊断与“训练时已打乱”的GRU是不同条件。

## 端点与测量限制

预测冻结后识别到18个来源末端目标，其中15个可因追加普通字符继续延长；内部目标142个，覆盖28条记录。它们遵守拟合前的显式EOF语义修订：目标是固定来源视图中的下一操作单元，不是完整自然句或作者真实停止事件。端点标志没有输入模型或参与选择。

三个100-token窗口通道在测试的485个单元中都没有有效数值支持，保留缺失和原窗口定义，没有缩窗或删通道。其他局部量仍依赖分词、POS/依存规范与解析器误差；能预测这些输出不等于恢复了潜在真实语言结构。

同一来源记录可能混合正文、签名、模板和引文；speaker键可能是编辑者而非原作者。固定年度视图也不是完整历史对话。这些限制没有因成功运行训练/测试而解除。
