# 固定序列试点：一次性测试结果独立复核

## 结论

**本次结果与冻结证据的一致性审计通过，没有发现需要修改原数值或重跑测试的差异。** GRU 相对非线性无序模型 DeepSets 的条件记录宏平均 CE 改进为 **0.003009468**，逐种子方向不一致；两种预声明的描述性重采样区间都跨过0。这次小样本测试没有建立可靠的时序优势，也没有证明顺序无价值。

本复核只读取已经生成的测试缓存、预测、分数、重采样结果和冻结产物。从已有 logits 重算损失，没有重新调用模型、神经解析器或优化器。原32条测试记录及其页面/复制分量已消耗，后续必须排除出训练，不能再次标成未触碰的测试材料。

## 1. 独立数值核验

逐一核验32份缓存校验和及其冻结选样身份；485个原操作单元全部保留，已有解析token共9,280个，其文本跨度与缓存一致。按声明的词汇规则，从缓存token重新累计14维POS计数，与各单元目标计数一致。这个检查验证内部算术与缓存一致性，不认证词性/依存标注的语言学真值。

独立按原始位置、空白闭合规则和失败屏障重建357行候选ledger，得到：

| 口径 | 数量 |
|---|---:|
| 全部来源记录 / 操作单元 | 32 / 485 |
| 解析失败单元 | 1 |
| 输入边界未确认的候选点 | 194 |
| 当前目标解析失败的候选点 | 1 |
| 失败后连续前缀不足的候选点 | 2 |
| 有效共同目标 / 有目标记录 | 160 / 30 |
| 仅保留覆盖的零目标记录 | 2 |

357=194+1+2+160。20条预测系列均覆盖同一32条记录和160个有效目标；640次记录级ledger比较全部通过。零目标记录的损失保持未定义，没有赋0或悄悄删出覆盖表。

对20系列×160目标的3,200份现有logits/目标，独立重算softmax、CE与14维绝对误差。保持原算术dtype时目标CE最大差为0；另用Python float64稳定log-sum-exp交叉核算，最大差5.40e−7，符合原学习臂float32求值的舍入范围。所有记录内均值、20条条件宏平均、各学习臂三seed均值、endpoint及页面类型分组均吻合。未调用生产模型forward，也未复用生产评分聚合或bootstrap实现。

两个bootstrap分别固定2,000次，独立按已声明哈希次序、RNG及seed抽取cluster，再展开为记录并保留重复次数。4,000个抽样统计量最大差2.78e−17，两个线性百分位区间复现。speaker键只作为已声明的顶层元数据代理，没有把它当作作者真值。

## 2. 主结果及其边界

所有CE均先在记录内对有效目标等权，再对**30条有目标记录**等权；不是除以全部32/192条记录，也不是全体token或目标池加权。学习臂汇总为三个已冻结checkpoint分别评分后的损失均值，并非概率ensemble。

| 比较器 | 测试CE |
|---|---:|
| 固定训练先验 | 2.252120 |
| 最近状态固定混合 | 3.065877 |
| 缺失掩码与前缀长度MLP | 2.249627 |
| 前缀均值池化MLP | 2.210344 |
| DeepSets | 2.213865 |
| GRU | 2.210855 |
| shuffled GRU训练臂 | 2.232850 |

预声明的DeepSets−GRU差为 **+0.003009468**，正值有利于GRU。seed1729/2718/3141分别为 **−0.007328985、+0.014275969、+0.002081420**。

- 30个有目标component的描述性95%百分位区间：**[−0.042072380, +0.046481021]**
- 22个声明speaker键的依赖敏感性区间：**[−0.056617768, +0.043808068]**

两种区间均跨0；GRU的点估计也比简单均值池化MLP高0.000510894。这里没有新增比较检验或据此选择模型。区间固定了本次训练产物，只反映当前有支持记录在已声明分组下的重抽样，不包含训练集/拟合不确定性、解析器误差、未知复制或所有跨组依赖。不能把“不建立可靠优势”解释为等效性证明。

将普通GRU的可见输入前缀打乱，三个冻结模型的平均CE为2.288568，较原顺序高0.077712748。这项预声明诊断表明当前模型对扰动敏感；输入分布破坏产生损失，不能单独证明其优于强无序比较器，也不能与“训练时打乱”的臂混为一谈。

## 3. 端点、覆盖与测量含义

从现有缓存的操作分段重算端点：142个source-interior目标；18个source-terminal目标，其中15个可由追加普通字符扩展，18个可由声明的引号/终止符追加扩展。20条系列的所有端点及页面类型分组均与报告一致。剩余3个非普通字符可扩展的末端目标也不能称为真实完整句子。

目标继续是冻结source view中的下一操作单元，包括EOF结束或截断单元；输入前缀必须已满足闭合条件。整个预测对象和其联合哈希已保存，冻结源码之后才计算endpoint；预测文件不含用于模型选择的端点标志。页面类型、speaker与端点均仅供后置汇总。各分组是其自身有目标记录的条件宏平均，不能直接按组目标数拼回全体CE。

三个100-token窗口通道 `zh:lexical.mattr100`、`zh:lexical.entropy100`、`zh:upos.bigram_entropy100` 在485个单元上均无有效值：484个成功解析单元的分母为零，加1个解析失败。未缩短窗口、改目标或删通道。其他输入仍依赖固定解析器、标注规范、源视图和领域；能预测这些观测量不等于识别潜在真实文风、人类来源或作者身份，也不替代用户对文章的判断。
