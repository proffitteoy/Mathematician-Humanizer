# 真实观测序列试点的训练开发结果

15次固定拟合已完成。模型能比只看缺失与前缀篇幅的控制更好地预测下一来源操作单元的解析器POS组成；有序GRU对无序DeepSets的开发增益很小，且三种子方向不完全一致。**当前结果不足以宣称稳定的动力学优势；测试集仍封存。**

## 固定范围与实际覆盖

- 128条训练、32条开发来源记录，来自预声明页面/复制分量；没有替换样本
- 2,480个操作单元；4个训练单元解析失败，保留为屏障
- 实际可评分目标为训练755个、开发223个，分别覆盖117、31条记录。11条训练和1条开发零目标记录只进入覆盖账目，不赋零损失
- 来源是WikiConv固定年度文本视图。单位可含签名、模板、引文或多个声音；speaker键不是作者真值
- 目标包含来源EOF定义的末尾单元。该语义已在拟合前显式修订并冻结；模型输入仍只含严格闭合的可见前缀

## 主要开发结果

评分是条件记录宏平均的组成交叉熵，越低越好；不是全文似然、词级困惑度、语言质量或人类概率。学习模型数字为三个已冻结种子各自评分的算术平均，不是概率集成模型。

| 比较器 | 开发交叉熵 |
|---|---:|
| 训练组成先验 | 2.194641 |
| 最近状态的固定混合基线 | 2.815171 |
| 仅缺失掩码和前缀长度MLP | 2.187559 |
| 前缀均值MLP | 2.099382 |
| 非线性DeepSets无序模型 | 2.092173 |
| GRU顺序模型 | 2.087016 |
| 打乱前缀顺序训练的GRU | 2.129150 |

主对照DeepSets减GRU的逐种子开发差值为+0.000012、−0.003162、+0.018618，均值约+0.005156。不能只挑效果最大的种子，也不能因为平均略好就称“次序已被证明有用”。开发集参与了预声明的checkpoint选择，独立泛化仍需封存测试。

后置端点诊断中，内部目标的均值差约+0.002895，来源末端目标约+0.025785。两者是不同支持集上的条件记录宏平均，不能相加还原主结果，也不能据此断言末端造成收益。开发端共有18个source-terminal目标，其中16个可被普通字符追加继续延长；训练端对应56与52。终点标志没有进入模型或checkpoint选择。

## 执行与冻结

五个学习臂×三种子×40epochs，共4,800次更新；无额外调参。CPU2线程运行483.7秒，峰值RSS460,436KiB，远低于约定60分钟/3GiB预算。测试32条、最多485单元尚未解析或评估。

15个checkpoint、训练专属变换和先验已冻结并保存在仓库外。读回核验通过17个文件哈希、15次严格state_dict载入与数值有限性检查、全部实现代码哈希，以及34个后置诊断全目标分数与主分数的一致性比较。没有为了改善结果重选样本、更新目标口径或重跑训练。
