# 保存权重驱动的结构编辑 scaffold v0.2

已实现真实全批量梯度优化、训练集拟合的尺度变换、JSON 检查点保存/校验、固定四候选的 edit(text,target,limits)、候选展示顺序不变性、独立语义审查收据校验和 abstain。当前权重只来自手工数值测试夹具，不能用于实证编辑，不计入受控语料或自然语料训练。

当前特征是 12 个字符/句长/主旨位置描述子，作为最小全局线性控制器接口；并非原 68 通道、序列网络或图网络已完成。四个条件是短/混合句长×前置/后置主旨，四种体裁、120–400 CP。主旨必须由调用方给出并在原文与候选中精确出现；这是受限支持，不是自动语义识别。

独立语义审查收据由受信任的上游协调者批准并绑定源/候选哈希。字符串、数字、否定/模态/量词计数只是必要机械检查，不能证明语义。代码包含“甲不支持乙”与“乙不支持甲”计数相同的反例。所有比较臂必须共用这一门，并独立评价门的错误；排序器不能宣称获得门的语义保留贡献。

训练数据和实际标签冻结、独立复核及 root 的 CONTROLLED_STYLE_TRAIN_GO 前不能拟合任何受控正文。当前 fit 中的 GO 对象是工程防误用门，不是安全认证系统；正式训练包装器仍须验证文件绑定、支持家庭数、来源与独立评审收据。合成模式必须显式指定，默认 empirical 模式拒绝合成权重。实证检查点、完整训练契约和独立系统测试均未产生。

运行：PYTHONDONTWRITEBYTECODE=1 python -m unittest -v test_controller.py

同目录测试覆盖实际非零梯度、保存权重被 edit 消费、候选顺序不变、主旨位置空白不变、检查点篡改、合成权重阻止实证执行、无语义收据、不支持的条件/体裁/长度/数学量词、固定候选预算、候选不得携带偏好标签、训练切分隔离、同内容家庭偏好及只写一次的检查点。

本版本与受控成文 v2 的 120–400 CP 支持范围一致，保留 v0.1 原目录不变。增加普通中文段落、至少四句、终止标点与标题/列表/引用等结构的范围检查；这只限制输入形态，仍然不能证明语义。未生成或拟合任何受控正文。
