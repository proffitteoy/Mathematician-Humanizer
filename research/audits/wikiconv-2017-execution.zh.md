## 2. 来源、许可与版本范围

[维护者正文许可说明](https://github.com/conversationai/wikidetox/blob/main/wikiconv/README.md)区分 CC0 元数据和 CC BY-SA 3.0 评论内容；本轮保留该内容专门说明，以及 Figshare 页通用 CC BY 4.0 标签的冲突记录。没有把软件许可证套在正文上，没有接受新的账号协议，也没有发布正文、用户名或可重建话语的标注。

原 WikiConv 行是编辑行动，包含原始/清理正文、行动类型与修订关系；ConvoKit 年度文件则组合了顶层话语版本和嵌套历史。两者不等同。官方原发布的中文条目是 Figshare v1、13个原始分片；本轮只核对其元数据，没有下载分片。当前年度 ZIP 的2026服务器修改时间也不等于文本创作时间。[原发布说明](https://github.com/conversationai/wikidetox/blob/main/wikiconv/README.md#dataset-format)；[ConvoKit 表示说明](https://convokit.cornell.edu/documentation/wikiconv.html)

官方文档明确年度文件划分话语，而同一讨论可能跨年。**这里的观察总体是这个固定年度文件所包含的视图。** 不能仅凭年度名把每条顶层记录说成2017年首发，不能把文件内部引用闭合说成整个历史讨论完整。

## 4. 冻结的抽样设计及实际样本规模

在普查前固定结构条件与随机种子；完整普查后才形成可抽样框。讨论组需满足：

1. 至少2条非空且显式非标题的顶层记录，涉及至少2个不同的非空speaker键
2. 所有序列化视图的标题状态明确
3. 所有非空reply、parent、ancestor引用都能在同讨论的来源视图中找到ID
4. 没有来源ID同时归于多个讨论；讨论根ID与讨论元数据存在

**3,395个组**满足这些条件。这些条件只定义“本年度视图内结构满足规则的讨论组”，未判断中文正文适用性、模板/自动通知、人类生产、自然人身份、语域或完整历史语境；也未验证图无环、时间可见性或逐版本关系。未通过数量不等同低质量/非人类材料数量。

固定种子：`7263081536c7ae633ac6ddb674e210fce187a6f25df3ec31e533508432909bd5`。

按讨论ID字典序遍历，使用 Algorithm R 蓄水池抽样和 Python `random.Random.randrange`，抽取24组。按此伪随机设计，每组纳入概率为 **24/3,395**；种子固定以后结果可重现。不是前24行、最短24条或看过语言现象后挑出的24组。源码保留私人样本键，公开输出只含算法、种子、分母及聚合。

实际入样组包含103条顶层记录，其中79条非标题；非空非标题记录涉及54个不同speaker键。只有4个键跨入样讨论重复，2个键跨已知页面类别重复。**这是一份后续审查样本，不足以据此声称训练集已具备作者×语域交叉结构。** 没有为了凑中文或合格语料不断替补样本。

普查框中的全部非空非标题记录涉及3,454个speaker键，其中1,522跨多个讨论，803跨多个已知页面类别。这说明来源有可调查的重复贡献结构，但页面类别不是语义语域，speaker键也不是已验证自然人。构造同作者/不同题材正对、不同作者/同题材负对之前，仍须解决角色归属与内容/情境标签。

## 5. 对多视图风格模型的直接后果

后续标量、语言序列与实体/命题/语篇图必须绑定同一个不可变分析版本。当前私人索引保存档案哈希、顶层行号/字节偏移、序列化视图序号、角色和正文哈希；在固定扫描器版本下，这些信息能够区别同ID的不同正文视图。跨分支不能只按来源ID连接，也不能将original内容与最终状态的时间/账号无条件拼接。

本轮没有生成句法、共指、命题或语篇金标，未评估序列时间一致性，未建立独立语言学标注，也没有形成自然人身份映射。来源视图的reply/parent连边是待审核的元数据关系，不应直接冒充实体图或论证图。删除历史还需单列可见性与材料用途，不能作为另一篇独立作品。

因此，这个档案已经提供实际较大的材料框，能够继续做分类、取样、版本和关系核验；复杂模型训练所需的多视图对齐、生产者×情境覆盖、测量可靠性和分割方案仍未完成。现有H_G入口继续是旧基线的声明门槛；本轮没有放宽它，也没有将结构计数凑成64项风格测量。

## 6. 复核方法与停止点

[扫描器](wikiconv_annual_census.py)仅用Python标准库、读取已取得的一个本地ZIP；不下载，不执行档案内代码。它检查固定五个平面成员、文件类型、压缩方式、局部头与中央目录的一致性、成员区域不重叠、实际DEFLATE输出大小、CRC、16 MiB单记录上限及1 GiB总展开上限。JSONL和顶层元数据映射均流式处理，结构表存SQLite；出错只给固定错误码并保留未完成状态，不把未知格式猜成已知。

[11项合成测试](test_wikiconv_annual_census.py)覆盖流式UTF-8/重复键、记录上限/非有限数、嵌套历史拒绝、缺失上下文、ZIP白名单/哈希、真实CRC校验、伪造较小展开长度、数据库超限后不可进入抽样、错误输出去敏及非常规输入不阻塞；它们证明软件检查，不证明语料来源或语言构念。

复核命令见[审计入口说明](README.md)。原始ZIP、账号/话语ID、SQLite与私人样本键不入GitHub；公开聚合收据没有原文引句、页面标题、账号或逐讨论画像。本轮停止在来源视图普查及样本键冻结，尚未补取任何原始修订或其他年度，没有招募、调用模型或拟合风格分布。
