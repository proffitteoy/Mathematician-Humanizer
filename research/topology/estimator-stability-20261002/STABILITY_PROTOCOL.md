# Fixed-cohort PHD measurement-reliability protocol

Frozen 2026-10-02 before any new estimator measurements. This is a separately identified continuation of the audited 32-pair pilot, whose outputs are not changed. The pilot and its exposed outcomes motivated this protocol; this is not a preregistration made before observing the pilot.

## Question and scope

How variable is the released-notebook finite-cloud scaling estimator under its random subset schedule, and how large is that computational variability relative to the human-minus-AI contrast and variation among these fixed 32 pairs? Distinguish a stable log-log slope from its potentially ill-conditioned reciprocal transform. This is a reliability study, not another detector benchmark: no AUROC, threshold, training, text rewriting, generation, feature admission, controlled TEST access, or new corpus/model download.

Use exactly the original 16 Wikipedia and 16 Reddit train-split pairs from selection SHA-256 a4b31b5982c5107adab88a2fca25989c19df4e3b193ceedea50ba946cce5f1b5. Use the same original windows and independently re-encoded matched windows L=min(256,human length,AI length). No row/window replacement, exclusion based on outcomes, added seed, or result-driven restart. Read source texts locally only to reproduce these inputs. No raw texts, embeddings, model assets or private source archives in publication artifacts.

## Encoder and deterministic replay

Reuse the already installed runtime and pinned FacebookAI/roberta-base e2da8e2f811d1448a5b465c236feacd80ffbac7b. Verify model/selection/archive identities. Use the pilot's slow RobertaTokenizer, one-pass cleaning, CPU float32/eager eval/inference mode, final token states, boundary removal and deterministic Torch settings. Re-encode the same token IDs and require every resulting float32 cloud SHA-256 to equal its saved pilot hash. If duplicate windows have identical token IDs within a text, encode/estimate once and explicitly reuse the identical cloud result. Hash mismatch is an integrity stop, not grounds to substitute a result.

## Twenty fixed new schedules

Seeds are the consecutive integers 20261010 through 20261029 inclusive. Each seed spawns three NumPy SeedSequence children, one for each rerun, exactly as the pilot's local seeded implementation. Reset the seed per cloud, preserving the pilot's common random index schedules for equal-N clouds. This does not align token meanings. Keep this induced covariance when analyzing aggregate computational variation. These local schedules do not reproduce the unpublished upstream global-RNG/thread interleaving.

Primary is the released notebook grid: step=(N-40)//7; sizes=range(40,N-step,step). Draw 9 subsets without replacement per scale when N>2*size, otherwise 3. Compute Euclidean alpha=1 MST length with the already tested independent Prim implementation. Take the median length per scale. Compute each slope using the upstream explicit OLS formula (q*sum(x*y)-sum(x)*sum(y))/(q*sum(x*x)-sum(x)^2), x=log(size), y=log(median length). Record centered-OLS parity as a numerical audit. Average the three rerun slopes and apply D=1/(1-mean_slope), without the pilot's any-rerun or mean-slope guards. Preserve all raw slopes, energies, seed IDs, subset-plan hashes, individual rerun transforms and aggregate transforms. Record undefined denominators, nonfinite energies, negative or >=1 slopes, D<2 and D>18. These flags never filter rows or seeds. The historical [2,18] range is only an annotation, not a validity criterion.

Do not repeat the paper-prose alternative: the present question concerns repeated measurement of one fixed released-notebook estimator. Switching grids would add a second scientific question and consume the bounded run. All 20 seeds are reported, including adverse values.

## Prespecified analysis

For each of the 128 text-condition cells (and report the number of distinct clouds), summarize the 20 three-rerun mean slopes and their transformed dimensions: count, mean, median, sample SD, min/max, and 2.5/25/75/97.5% empirical quantiles. Give all undefined/out-of-range counts. Empirical seed quantiles are conditional computational ranges, not confidence intervals about people, texts, or population generalization. Summarize within-rerun slopes separately; do not mistake three reruns for three independent source texts.

Report D'(s)=1/(1-s)^2, distance of slopes from 1, and the delta-method prediction SD(D) approximately SD(s)/(1-mean(s))^2. Compare with observed SD(D), retaining discrepancies and pole crossings. Distinguish mean[D(s_seed)] from D(mean[s_seed]); neither is substituted for the original three-rerun estimator. Very large or negative dimensions are algebraic behavior, not evidence of enormous/negative physical intrinsic dimension.

Relate N to observed slope SD, dimension SD and scale span log(max size/min size), using descriptive Spearman correlations for each condition, domain and label. Also summarize prespecified N bins 50-79,80-159,160-255,256-510. Bin boundaries describe these data; no universal minimum-length cutoff is to be selected or claimed. Report paired sign stability across seeds and the number of pairs whose empirical seed range crosses zero.

For slope and dimension separately, form the 32x20 matrix of paired human-minus-AI differences. Report the full per-seed pooled/domain means, computational spread of that cohort contrast, the seed-averaged paired contrasts and between-pair descriptive spread. With C the sample covariance across seeds of the 32-dimensional paired-difference vector, report a'C a for a=1/32 (single-schedule cohort-mean MC variance), a'C a/20 (estimated MC variance of averaging 20 schedules), and sum(diag(C))/32^2 as the hypothetical independent-pair calculation for comparison, never as the primary result. Report variance among seed-mean pair contrasts and its finite-MC correction trace(P C)/(20*(32-1)), P=I-11'/32. The difference is a diagnostic estimate of fixed-pair heterogeneity; retain negative corrections/results without truncation.

To describe empirical pair-composition sensitivity, draw 10,000 bootstrap compositions, preserving 16 pairs within each domain, with fixed analysis seed 20261030. Each composition is applied to each complete 20-seed vector, preserving the common-seed covariance. Decompose the finite 10,000x20 table's variance exactly into pair-composition main effect, seed main effect, and interaction via two-way centering. Give empirical 2.5/97.5% ranges for seed-averaged composition means, fixed-cohort seed means, and joint cells. These resample the exposed 32 pairs and 20 schedules only; none is labeled population generalization, a new held-out result, or a confidence interval for a latent population. If any quantity is undefined, retain its identity and count, report that aggregate as undefined rather than silently perform complete-case analysis.

Finite token-N bias is not identifiable here: there is no known intrinsic-dimension ground truth, token-independence assumption, or additional length sweep. N/stability relationships and original-versus-matched comparisons diagnose finite-cloud sensitivity; matched re-encoding also changes context and cannot isolate pure N causality. Encoder, source-corpus, generator and domain shifts remain unmeasured.

## Bounds, execution and failure handling

One measurement process, affinity restricted to two available CPUs, Torch/BLAS threads<=2, no GPU/network/paid services/remote writes. Wall deadline 1800 seconds for the run including analysis; measured peak RSS<3GiB, soft safety stop at 2.75GiB; new derived disk<500MiB and combined working disk<3GB. Use an external 1800-second timeout and internal checks, stream one complete cloud at a time. New outputs go only to a sibling stability directory. Record run start, code/protocol hashes, status, completed cells/seeds, timing, RSS and disk usage. A crash/budget stop leaves completed records and is reported incomplete; do not rerun to obtain favorable outcomes. Synthetic/replay arithmetic checks may be performed without new corpus measurements. Verify original pilot artifact hashes after completion. Root owns any later publication.
