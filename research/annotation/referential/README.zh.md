# 指称连续性空白标注包

日期：2026-10-01。用途：落实[测量契约](../../../docs/design/referential-continuity-contract-v0.1.zh.md)的输入和分歧记录。只有一项获准的本地自然材料契约练习，没有已通过测量验证的语料池、参与者、独立人工金标、模型调用或总体估计。这里的字段数不是测量项数量。

## 文件与状态

- `packet.schema.json`：JSON Schema 2020-12，当前契约版本0.1.1，定义一个作品/材料包的结构
- `blank-packet.json`：真正空白的可填模板；没有预置“正确”实体、zero标签或话题
- `constructed-template-cards.json`：一套自拟材料的八个版本；只有字串/偏移计算，`empirical_or_gold=false`
- [交叉材料纸面审查](crossed-template-paper-audit-v0.1.zh.md)：为什么原三因素交叉尚不可执行，以及怎样把两个材料块分开
- [自然材料提案及执行记录](natural-pilot-proposal-v0.1.zh.md)：一项具体版本的有界取得计划、实际契约练习与未决项
- `pilot-public-receipt.json`：不含正文/逐条标注的版本、许可、校验与汇总记录；原文、署名收据及实际临时标注都在仓库之外

Schema通过只表示JSON结构符合约定。它不判断中文结构是否成立，不自动批准语料许可，也不生成风格指标。

## 填写顺序

1. 从空白包复制一个材料包；取得许可和版本证据后填`materials`，再将状态改为`draft_in_progress`。原始文本留在独立研究存储；仓库只放不含正文的元数据、空表和自拟诊断
2. 为每种实际显示的语境建`context_views`。记录可见和遮蔽跨度、顺序和视图哈希，不用“同一文本”掩盖不同读者看到的内容
3. 每位分析者建独立`annotator_runs`。先发现全部目标谓述，再标位置、显式提及及候选；不能只给标注者一张机器已找到的zero清单
4. 每个竞争框架/完整分析用一份`analysis_graphs`。共享和控制是结构类型，具体/泛指是指称类型，外指/前文/后文是支持类型，三列不可混为一个标签
5. 同一文本的另一分析引用`rival_analysis_ids`，不要把两图不相容的最小分子、最大分母拼成一个比率，也不擅自给两图各50%权重
6. 读者反应单独进入`reader_responses`，与语言学分析图分开；不得先因自然度低而跳过解释问题。问题未问与已问但无法判断都需要各自状态
7. 裁决写入`adjudications`并指回原始图/反应。可选择保留竞争分析；不能覆盖原判断后重新计算出“完全一致”

## 字段语义与空值

- `[]`在空白包顶层表示尚无记录，不表示材料中不存在该现象
- `null`表示尚无值或未收集；`unresolved`表示分析过仍未决；`no_subject_site`是作出的结构判断，三者不可互换
- zero只有位置锚点，不能把“Ø”插入原文后改变后续偏移。`overt_spans`必须为空；不允许把虚构的一个字符当零形式跨度
- 所有跨度是未经默认简繁/NFC转换的Unicode码点半开区间。HTML/XML剥离若用于规范文本，要保留原字节、变换日志、偏移映射和新哈希；不能把UTF-8字节偏移或JavaScript UTF-16下标混用
- 匿名的校对员仍可有实体ID；不知道现实姓名不等于有两个语篇所指
- 一个首选反应与一组可接受解释不是同一种变量。候选列表要容纳群体、其他对象和语境不足，不能靠二选一制造唯一性
- `naturalness-0-4-provisional`只是当前表单的明确锚点；量表未验证，也不是参照论文接受度百分数的复制
- `assistance_status=unknown_not_used_for_admission`和`population_class=not_assigned_H_G`固定了本包的用途边界；需要别的生产流程研究时另建契约

## JSON Schema以外必须检查的语义不变量

这些不是已实现的解析规则。数据冻结前要人工核对并记录结果：

1. 所有ID唯一；图内实体、提及、位置、谓述和边端点存在；跨图实体对齐要有显式映射，不能仅因用了同一个名字就合并
2. `0 ≤ start < end ≤ 规范文本码点长度`；位置锚点允许位于边界，但不能越界。谓述及其头跨度要覆盖原文证据；不连续跨度保留原次序
3. 每个共享位置只出现一次，可关联多个谓述；`predication_argument_bindings`区分某谓述拥有位置、共享已有位置和受控制位置。共享绑定须指向同图已有位置且有明确拥有者；不能每个动词复制一个“省略机会”
4. 具体指称却未确定是哪一实体时，仍保留位置。主分析的机会集、排除位置与结构未决位置都必须可枚举；分母不由恢复成功与否决定
5. `identity`只连同一实体的提及或明确的同一性主张；楼与屋顶用`part_of`，不并成一个实体。所有边需原文/情境证据，不能依无限常识补齐
6. 前缀视图不能使用后文实体去宣称当时已唯一恢复；全篇回看可以有后文支持，但要保留其方向与语境身份
7. 预测目标实现时，目标形式不得出现在输入；为话题构念提供独立证据的判断不能简单由zero或最近主语标签复制
8. 原始排除范围中断相邻关系；不得把删除引语后相接的两句误当原文相邻。目标过滤不等于删去解释者可见的语境
9. 每个响应量明确实际问过的问题、顺序和缺失原因。多数首选不同不自动等于每人都感到歧义
10. 自拟卡、自然材料和读者反应分池保存；同一模板的八个版本不能记成八个独立自然作品

## 最小冻结关口

先按契约§8做双人独立诊断，暴露表格无法表达的情况；再在获准的自然材料里验证单位发现与错误类型。通过这种检查，只允许计算已固定人工图上的计数。自动提取还要另有未参与修订的材料验证。

本轮做过的检查包括：Schema自身合法，空包合法，若干故意构造的非法记录被拒绝，八个自拟版本的姓名距离算术，以及一篇授权自然材料临时包的结构/偏移/引用检查。该自然材料只有一位助手提出的竞争分析，没有独立人工金标或读者反应，不能将检查通过等同语言学有效性。

### 0.1.1修订

自然材料练习暴露了0.1.0中“共享位置”和“依赖于它的谓述”容易被重复表示的问题，现增加显式绑定表。两个谓述共享一个原有主语时，只有一个位置记录；另一分析若认为第二谓述另有独立zero，则在那张图里另建位置。这是修复记录方式，不是裁定了哪种中文分析正确。另补充`current_overt`支持类型，避免把显式提及错误记成外加情境。
