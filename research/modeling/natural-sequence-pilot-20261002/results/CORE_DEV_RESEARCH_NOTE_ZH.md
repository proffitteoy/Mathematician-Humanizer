# 中文局部语言测量预测实验的双种子结果

本实验已经完成两个预设随机种子的核心模型比较，共14次拟合。当前结果显示，前缀协方差、最近单元和序列模型值得继续检验，但复杂模型的收益并不单调，部分模型对随机种子敏感。这里报告开发集 DEV 上用于选择训练轮次的分数；它们不能替代独立 TEST 评估，也不足以证明已经建立完整的语言风格模型。

## 研究问题与预测任务

研究问题是：观察一篇回答中已经出现的局部测量序列后，哪些信息有助于预测下一个单元的语言测量值？依次考察前缀一阶统计、同一前缀内的二阶共变、无序非线性组合、最近单元和顺序历史。主要预设比较为 F1 与 Fcov、Fcov 与 F2、F2 与 F4；F3用于区分最近单元效应与更长顺序历史的作用。

每个过去单元提供68个局部语言测量值和2个结构长度值，并保留观测掩码、测量机会数及其已知状态。只允许使用当前前缀的信息。来源、人类或AI标签、文档身份、最终文档长度和未来单元不进入预测器。人类或AI标签在预测器外用于成对组织、平衡和分组评价；预测目标是下一个单元的测量向量，不是二元人类或AI标签。

输入归一化仅在 TRAIN 上确定。70个输入坐标中，67个目标坐标满足预设支持条件：在实际共同支持的训练问题组件中，至少50个组件有可观测的后续单元目标。首单元不计入这一目标支持门槛。三个100词窗口指标未达到该门槛，因此不评分；缺失值没有被当作已观测的零。

分数采用预设的平方预测误差：先对可观测目标按语言测量家族平衡，再按单元、回答变体、人类与AI两臂以及问题进行相应平均。数值越低越好。每个模型最多训练100轮，DEV连续10轮不改善时停止，并报告所选轮次的DEV分数。

## 数据与模型

本表使用原始 [M4中文问答发布文件](https://github.com/mbzuai-nlp/M4/blob/628bf0fcb2e8c6b7ffa71fd1af6be413aced8f7d/data/qazh_chatgpt.jsonl)，来源为Baike与Web。TRAIN包含1816篇人类回答和1816篇ChatGPT回答，DEV各591篇。本表使用的数据不是为本实验重新生成的文本。发布标签为chatgpt；现有记录不足以确定精确API模型快照，不能把它写成某个现代GPT型号。

共同支持的训练问题为1686个；DEV评分覆盖559个问题、1120篇回答和10348个后续单元目标。划分与配对以问题及其关联组件为单位，避免把同一问题的回答变体拆到不同集合。本文不包含TEST或davinci模型评估。

| 模型 | 输入信息的增量 |
| --- | --- |
| F0 | TRAIN全局均值的解析基线 |
| F1 | 前缀均值及共同的一阶与观测支持摘要 |
| Fcov | 在F1相同支持摘要上增加逐对共同观测协方差 |
| F2 | 在相同协方差摘要上增加DeepSets无序组合 |
| F3 | 在F2基础上直接加入最近一个单元 |
| F4 | 在相同摘要与无序组合基础上加入GRU顺序表示 |
| F1_wide | 增宽F1，用于检查Fcov与F2比较中的参数容量影响 |
| F2_wide | 增宽F2，用于检查F4比较中的参数容量影响 |

各模型共享同一目标、支持规则和评分总体。协方差使用同一当前前缀内逐对共同观测的单元，以及该共同观测集合上的两侧均值；它不被假定为正定矩阵，也不解释为已经发现的风格轴。参数数目是剪去不可评分目标输出后模型的可训练参数数量。

## 可以与不可以从结果中读出什么

Fcov的两个DEV分数都低于相应F1，但F1_wide的两种子均值与Fcov接近。因此，当前结果不能把F1到Fcov的全部差异归因于协方差信息本身。

F2没有在两个种子上稳定优于Fcov，其DEV分数从1.041596变化到1.089359。这一变化说明，增加无序非线性组合后仍存在明显的初始化与训练抽样敏感性，不能只展示较好的一个种子。

F4在这两个种子上均低于F2；但F3也有较低分数，而且seed1701中F3低于F4。最近单元可能解释一部分收益，更长顺序历史的独立贡献还需要顺序干预和匹配的对照检验。

这些是开发集上的观察，不是显著性结论。DEV承担了训练轮次选择，两个种子也不足以给出可靠的稳定性或不确定性结论。数据仅覆盖这一中文问答场景，测量仪器仍处于实验阶段，不能将这些分数转换成人类或AI概率、作者鉴定结果或完整风格能力。

## 尚待完成的比较

第三个预设种子1703的核心部分仍在进行，本表不混入其局部结果。核心三种子部分之外，预设设计还有51项对照拟合：掩码与机会数9项、纯掩码9项、长度9项、打乱训练顺序3项、语言家族独立模型3项，以及来源专属模型18项。它们用于检验缺失模式、测量机会、长度、顺序、跨家族联合信息和来源差异的影响。

完成相应对照和模型冻结后，才可讨论独立TEST与跨生成器评估。当前材料不宣称完整研究已经结束，也不涉及个人作者风格迁移。
