# 两阶段验收与迭代停止条件

更新：2026-10-01。以下条件来自项目所有者的明确要求，优先于旧计划中按代码、指标或实验数量定义的完成状态。

## 第一阶段：通用 skill

实际使用 skill 输出的句子与文章，在项目所有者看来与人类文章无差异。验收材料必须包含可使用的 skill、实际输入输出与适用边界；研究计划、候选维数、训练损失、检测器分数、数值测试通过均不能代替这一判断。

项目继续研究建模，最终依赖学习型多视图与动力学系统。交付早期候选版本时须说明哪些功能已实现、哪些仍是提案、哪些模型实际训练过；不能把一份提示词或未训练模型包装成最终系统。

## 第二阶段：私人 skill

在通用能力基础上，跨主题模仿项目所有者的杂谈和数学笔记。目标覆盖任意主题；有限测试只能提供支持证据，不能证明所有主题都已达标。数学内容、推导、量词、条件与不确定性不能为了模仿措辞而改变或编造。

原先指定的个人博客是 proffitteoy/nothing-new。当前授权是条件性的：如果研究方有依据确认第一阶段已达到可验收水平，可以直接启动第二阶段，不必再等待一次确认。启动前应记录通用候选版本、实际测试、尚存限制和阶段判断，不能通过改低标准触发个人数据使用。条件未达到时，个人文章仍不进入收集、拟合或样例模仿。

## 谁决定完成

最终由项目所有者测试和评判。研究方的阶段判断可触发第二阶段工作，不能冒称所有者已经接受第一阶段，也不能替所有者宣布最终验收通过。未通过的部分继续迭代。

## 每轮可检查的交付

1. 可运行或可使用的 skill 版本及确切依赖、输入/输出协议
2. 未选择性隐藏失败的实际样例；通用、杂谈、数学笔记的测试分别标注
3. 内容保持、事实/数学错误、风格不自然、拒绝与缺失支持的记录
4. 与上一版本的实质变化、证据、失败路线和下一步，不用文件数量代替进展

盲测、同题样例、模型消融及误差审计可以帮助判断，均不能取代所有者的最终决定。此协议没有授权伪造人类来源、检测器概率或普遍不可区分性证明。
