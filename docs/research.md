# 统计证据与风格总结

本仓库用分析结果改写 Humanizer，使它持续采用参考数学博客的论证风格。复杂模型、潜表示、动力学和拓扑不再是这条路线的前置条件。

## 已有证据怎么保留

`research/manifest.json` 登记本次保留文件的实际字节 SHA 和重建前提交 `62b31458185e20d4ba88a667adbc6b7c0f14b14f`。它们是历史汇总，没有重新收集、解析或拟合语料。作者统一以 one of the mathematicians 代指，来源别名为 `public-mathematics-blog/1`。

冻结输入先从原 Git blob 恢复字节，再按命名要求只匿名化三份博客证据中的作者标识：汇总的来源地址、开发表的解释文字和英文合同的版本名称。清单分别保留 `source_sha256`、当前 `sha256` 与转换字段；含作者标识的历史路径用 `historical_path_sha256` 绑定，来源地址另存指纹。统计数值、划分、解析参数与模型哈希均未改变。

文件内部的旧 profile、原分析数据哈希和运行时身份保持原记录；英文合同的 `contract_sha256` 是匿名化前的历史仪器身份，当前文件字节由清单的 `sha256` 绑定。`.gitattributes` 防止 checkout 转换这些 JSON 的换行。`historical-runtime.json` 内的旧 vendor 路径用于追溯，不是当前安装配置。匿名化是交付转换，不是新实验，也没有通过换哈希抬高旧证据的状态。

## 中文：有差异，不能收敛成一个“人类平均值”

`general/paired-surface.json` 来自已有 M4 中文 TRAIN/DEV 的 HUMAN/CHATGPT 配对汇总。来源按 Baike、Web 分开，版本/衍生分量控制见文件内 provenance。DEV 已被检查，所以现在的规则属于开发侧适配；不是新留出验证。

- 句长中位数、IQR、90 分位数、相邻变化、秩相关在现有 TRAIN 筛查与 DEV 检查中方向一致。它们支持检查单调句长和机械节奏，不能证明“句子越长越好”。
- 段落密度在 Baike 和 Web 方向相反；不生成统一段落数处方。F002、F003、F016 没有通过现有通用检查门。
- 这些量基于内容字符和操作句/物理行；不能冒称语义段落与有效句法。

`general/joint-reference.json` 的十项参考来自 TRAIN 的 joint-valid HUMAN 文档，Baike 为 899 文档/868 分量，Web 为 903 文档/890 分量；与配对样本量不同。先在分量内合并再等权，保留内部条件带、分位数及协方差。标签不是独立验证的无辅助作者来源。

两份既有原创虚构示例显示了限制：名词、动词、副词方向部分符合来源差异；较口语版的单汉字词元占比反而下降、平均词元码点长上升。记录见 `examples/general/`。因此短语选择是编辑假设，不能承诺控制解析器坐标。

##参考数学家：从博客提炼贯穿全文的风格

历史官方公开快照覆盖 2007—2026 年，1234 个唯一公开记录（1130 文章、104 页面）；1114 份进入测量，包含 2,381,354 个英语词项。客座/其他作者、混合索引/勘误页、过短目录和嵌入页先分流。剩余文章仍可能含合作叙述或引文。

开发侧 1040 份；74 份为年份/文章级留出，包括 2020、2023 年份及静态建议页。留出已有冻结规则的描述性边际覆盖检查；summary.json 保留完整覆盖计数和不理想结果，不能把 coverage 冒称写作质量。development-profiles.json 的 `holdout_articles_uninspected` 是生成开发表时的历史字段，当前留出状态以 summary.json 为准。

测量按体裁、长度和时期保留条件分布，以文章与重叠家族控制权重。英语仪器排除公式占位等，短正文块筛选影响段长。没有全语料人工语言学金标，没有对照作者实验，也没有参考数学家亲笔中文语料。

最终风格分两层：

1. **稳定底色**：问题明确、步骤有动机、从例子或弱结论逐步推进、术语一致、语气克制、条件和边界明确。这来自可查博客阅读与组织分析，不是假称语言学统计自动识别了数学论证。
2. **体裁展开**：数学说明聚焦机制，讲义展开证明与练习，札记保留可检查的疑问。文章节奏和英文提示词统计帮助选择展开方式，不强制所有文章套一个模板。

中文转移这套推演习惯；一般中文统计只补充表达检查，不冠名为参考博客中文声纹。

## 如何继续研究

现有结果已经足以形成一个有明确来源和边界的候选 skill，不要求每次写作重新完成整个统计研究。接下来优先收集实际改稿反馈：同一原稿的前后版本、内容保持、论证是否更容易跟随，以及风格是否稳定。数学错误、失真和没有改善的例子同样保留。

如需扩充统计，固定来源、权利依据、原文版本、测量profile、分量身份和 TRAIN/DEV 划分，再对已有本地材料测量并导出 `style-observation/1`。只发布必要的汇总，不把博客全文或解析缓存加入仓库。新语言或新体裁单独检查适用性。

真人偏好、模仿保真度和跨主题表现仍待实测；不能用单元测试、分布距离或检测器分数宣布通过。[验收条件](ACCEPTANCE.zh.md)以实际成品和用户判断为准。
