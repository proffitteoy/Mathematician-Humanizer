# Style Compiler 建模研究札记 v0.1：语言选择、关系结构与可识别性

日期：2026-10-01。状态：**第一轮问题重构与竞争模型草案，未形成定论，不是完成的理论、预注册或实证结果。** 本文不增加特征提取器，不宣称已实现64项，不启动语料采集。已有8项字级指标和代码仅是测量工具。最终操作性表征至少64项的要求保留，但测量项必须由语言学问题、可识别模型与验证证据支持，不能拿数量代替建模。

阅读范围：已核对下列原论文的相关模型、语料与标注章节；未声称通读所有引用著作。结构主义、语域和立场研究还需独立深化。文中的数学结构是**本项目提出的竞争性工作假设**，除明确说明外，不是文献已经为本项目证明的模型。

## 1. 先改变研究对象：不是给文章找一个“风格坐标真值”

目前较有解释力的对象是：**作者/生成系统在特定交际情境、任务所声明的意义约束与篇章进程中，对可选表达方式及其组合顺序形成的条件分布。** 它包含有意选择、习惯、编辑制度与媒介限制；从成品文本无法直接区分它们，更不能把全部剩余差异叫作作者意图。

至少分开五个对象：

1. **情境与功能要求**：谁向谁、通过什么媒介、在何种互动关系中、为完成什么事而写。它不能由待解释的文本指标循环定义。
2. **内容与承诺**：讨论的实体、命题、证据、条件、量词、否定、确定程度及承担的言语行为。它们不是可任意移动的风格噪声。
3. **实现选择**：在上述约束下采用哪些词汇、构式、指称形式、布局和组织方式。
4. **组合过程**：这些选择怎样依次出现，如何承接实体、回答问题、展开论据、转折与结束。
5. **接受与效果**：特定读者能否理解、信任、完成任务，以及作者是否认可。效果受读者与任务影响，不能用一个语言统计距离替代。

这里不能偷渡一个普适的“内容固定、风格可分离”前提。相似的命题摘要可以掩盖承诺、预设、礼貌关系或言语行为的变化。“可能如此”“就是如此”，“你能否处理”“请处理”，以及不同匿名/指称形式，未必是同一意义的无损外壳。任务允许改变语气时，本身可能允许某种语用变化；把所有语用作用都锁死也可能使该任务无解。

因此，所谓“内容控制”仅是针对某估计目标声明的局部约束，须列出保留什么、允许改变什么、尚不能判定什么。它不是已经识别出的内容因子与风格因子之独立分解。相同事实包也只控制部分事实输入，未必控制立场、选择、解释与关系建构。

研究“典型性”“可辨认性”“可理解性”“个人偏好”是不同问题。可以统计某表达在某语域少见；不能因此断言它差、假、应当删除。

结构主义关于关系与组合的启发，最多先支持我们不把单位当成孤立物的建模立场。**它不自动导出某个神经向量空间、潜变量个数、协方差矩阵或因果机制。** 把“差异关系”直接译成向量距离，还缺少操作定义和验证桥梁。

## 2. 文献对建模施加的具体约束

### 2.1 局部衔接与全局组织不能合并成“连贯度”

Centering理论关注话语片段内注意焦点、指称形式与理解衔接的关系，并允许解释随后文逐步明确。它不是“代词越少越清楚”的原则，也不是全篇质量模型。[Grosz、Joshi与Weinstein 1995，§§3–8](https://aclanthology.org/J95-2003.pdf)

Entity-grid以句序、共指实体与语法角色转移构成表征。原研究中，共指解析对排序与生成摘要评价的影响不同；较复杂的解析会因领域和输入质量变化而伤害下游任务。因此，提取器的误差方向也可能随条件而变。[Barzilay与Lapata 2008，§§3、4.1、4.2](https://aclanthology.org/J08-1001.pdf)

**本项目推论**：至少区分实体延续、命题/修辞关系、全篇组织和读者效果。局部变量可为全局解释提供证据，但不能用实体重合率直接命名“连贯”。

### 2.2 中文语篇的单位与关系本身存在理论选择

CDTB使用连接驱动的篇章表示，区分显式/隐式关系与连接表达，并记录某些删除/插入判断；其新闻语料中隐式关系占多数。连接词出现次数与关系实例数不是同一对象。[Li等 2014，§§3–4](https://aclanthology.org/D14-1224.pdf)

GCDT采用不同的句法/命题导向EDU切分，包括中文前置关系从句与不连续单位。它覆盖50篇、5种体裁，但多种体裁与来源站点耦合；可用于标注研究，不足以单独识别纯体裁效应。其分段一致性与关系树一致性明显不同，不能共享一个笼统可靠度。[Peng等 2022，§3、Table 1](https://aclanthology.org/2022.aacl-short.47.pdf)

GCDT的标注手册进一步显示：相近意义的表达可能因句法分析不同而采用不同EDU边界；话题化名词短语、补语与引述等不能按逗号机械切开。[Chinese Discourse Annotation Reference Manual，§§1.1–1.2](https://arxiv.org/pdf/2212.06037)

**本项目推论**：必须把“采取哪种分析框架”写进测量身份。不同框架的EDU密度、树深、关系熵不能无映射地拼表。关系树也不是文本客观本体的唯一恢复结果。

### 2.3 标注不一致不全是标注者粗心

同一隐式关系可以有多个可接受理解，提问式和连接词插入式任务会改变标注分布。该实验证明的范围是所研究的任务与领域，不是所有中文标注；它足以要求我们验证自己的任务诱导偏差。[Pyatkin等 2023，§§3–7](https://aclanthology.org/2023.tacl-1.57.pdf)

**本项目推论**：记录原始多标注、方法与上下文；不要把所有分歧压成一个裁决标签后，将其假装成无误差真值。需要区别错误、范围不清、框架不同、语境不足及真实歧义。

### 2.4 篇章状态不天然就是风格状态

早期内容HMM显式建模领域内信息类型与呈现顺序；潜在状态是领域内容主题，不能只因它们形成序列就改名为“作者风格状态”。[Barzilay与Lee 2004，§3](https://aclanthology.org/N04-1015.pdf)

QUD模型把句子看作回应先前语境引出的问题，其依赖结构与RST树不同；这是一个可比较的组织解释，不应预设两种框架必能一一对应。[Ko等 2023，§§2–3](https://aclanthology.org/2023.findings-acl.710.pdf)

**本项目推论**：动态模型至少要与“仅内容进程”“仅位置惯例”“仅修辞角色”竞争；否则它很可能把教程步骤或论文段落任务误认成风格动力学。

## 3. 显变量、潜变量与研究单位

| 记号 | 对象 | 如何获得 | 主要限制 |
|---|---|---|---|
| X_i | 原始完整作品及修订关系 | 授权来源与固定版本 | 页面日期不等于版本日期；转引/翻译不可混合 |
| C_i | 情境：受众、关系、媒介、交互方式、目的、任务、正式度等 | 来源信息、任务设计或独立人工编码 | 不能从同一待解释指标反推，再当外生原因 |
| B_i | 题材/内容卡及任务所需的事实集合 | 人工分类、预定事实包 | 自动主题表示也是测量，不是无误差控制项 |
| W_i | 作者、渠道、时期、编辑、翻译、生成配置、谱系 | 元数据与证据 | 多轴可嵌套或混淆，未知须保留 |
| U_it | 实体、命题、EDU、作用域、关系、修辞动作等分析对象 | 盲标或经验证的解析 | 有边界、角色、连边及真实歧义误差 |
| Y_itj | 给定分析框架下的真实/约定测量对象 | 明确操作定义 | 并非每项都有单一客观真值 |
| Ỹ_itj | 某工具/标注方法给出的观测 | 固定版本与原始输出 | 不应直接等同Y；误差可能按语域/生成组变化 |
| η_i | 作品层低维共变倾向（候选） | 模型推断 | 旋转/尺度不唯一，不自动具有功能名称 |
| z_it | 局部组织/修辞状态（候选） | 人工角色或隐状态模型 | 标签交换、内容混淆、稀疏转移 |
| R_ir | 读者r的理解、任务完成、偏好等 | 独立评价设计 | 不同读者可有不同目标，不宜强行一维化 |

i是作品，t是该作品中的有序单元，j是测量通道。作者、内容卡和来源是不同聚类轴。句子多只能改善该作品某些内部估计，不能增加独立作者数。

需要区分两类“潜变量”：η可以是有语言学主张的构念，也可以只是压缩异质性的随机效应。后一种不因为数学上不可直接观察就获得心理实体或语言功能的解释。[Muthén 2002，§§2、2.1–2.2](https://www.statmodel.com/download/muthen1.pdf)

## 4. 语料分类应服务识别，而不是只建文件夹

语料应是多轴记录与覆盖张量，不是“互联网/论文/博客”三个互斥箱子。至少独立记：

- 渠道/站点/刊物与界面约束；作者/协作者/机构；完整作品与其版本谱系
- 情境与语域；传统体裁名称；实际修辞任务；预期受众、互动关系与传播媒介
- 题材与事实包；原创/译文及源语言；作者定稿/编辑改稿/合著/代笔或未知
- 发表时期、版本时间与采集时间；要求篇幅与实际篇幅
- 人类/生成/混合/来源未定；辅助情况及证据等级；模型家族/快照/提示/解码设置

例：博客渠道可承载教程、日记、论争或学术说明；论文摘要和讨论段也不是同一任务。同一“有读者互动”的情境可能跨博客与网络答疑。**分类是否有效，要看独立编码能否稳定、是否提高解释/迁移，以及替代分类能否推翻结论。**

层次可部分重叠，不能强行全笛卡尔积。真实不可能存在或不允许比较的格子明确标结构性空缺；未采到的格子标覆盖缺口；不可把两者都当随机缺失。

### 三种数据池，资格不能互换

1. **理论/测量验证池**：验证中文构式、边界与标注方法。来源可能是历史人类倾向但辅助状态未知；只要权利、隐私及具体任务合适，就可能用于这一池。
2. **条件分布研究池**：识别规定总体中的共变与条件差异，需要已定义的抽样机制、跨轴覆盖和来源不确定性处理。未定来源须单列，不自动标H_G。
3. **干预验证池**：能够保留原作、记录合法操作并独立评价语义/任务效果的文本。属于测量池不等于获准改写、分享或作因果实验。

没有理由把历史语料强迫通过当前代码的verified-unassisted H_G门槛；应限制其用途或修改研究问题，而不是编造资格。统计来源不确定性时也不能先用待研究的风格指标推断“人类”，再拿这些标签证明风格差异。

## 5. 先证明想估计的东西可识别

### 5.1 作者、来源、题材的最小反例

若作者A只在网站S1写科技，作者B只在S2写旅行，则三种差异产生相同分组。加入三个回归项或三个随机效应，不会凭空分离它们。

需要的是交叉连接：部分作者跨题材、同题材有多作者；部分渠道容纳同类任务，或相同作者/可比内容跨渠道；模型组在相同内容卡和任务中重复。实际设计矩阵要检查秩、连接分量和近共线性，并对拟合的方差归属做先验/删除格子敏感性分析。

在简单两因素加性固定效应模型中，连接性可帮助主效应识别至常数约束；但它不保证复杂多轴交互、方差成分或外推可识别。循环覆盖、重复单元和外部支撑用于检查加性假设与估计误差。不能把这一技术条件简化成“每类找几篇就行”。

Topic Confusion研究通过改变作者—题材配对，暴露对题材捷径的依赖；它支持把这种反例式检验纳入设计，不支持“某类特征永远与题材无关”的结论。[Altakrori等 2021，§§3–4](https://aclanthology.org/2021.findings-emnlp.359.pdf)

### 5.2 估计量先写出来

- **条件描述差异**：在共同支持的情境、任务和实际篇幅下，两个来源组的测量分布差异。它是关联，不是把人替换为模型的因果效应。
- **提示条件总效应**：同一事实包、模型和预设篇幅预算中，随机提示条件对结果的整体影响。实际篇幅可能是中介，不能默认在主要分析里调整掉。
- **作者稳定选择**：一般作者在相同/可比条件下跨作品保留的差异。必须有跨条件作品，否则只是作者—题材复合标签。当前不涉及用户个人画像。
- **局部编辑效果**：在事先定义的可编辑位置与语义约束下，某操作相对不操作/普通编辑的任务效果。观察性偏差方向不能替代这个实验。

一个模型可以回答第一种问题，不代表它回答了后面三种。

## 6. 竞争模型：不能一开始就选定“潜在风格”

### M0：没有共同风格因子的条件描述模型

对各测量使用合适的分布与暴露量，建情境/题材/任务/长度/渠道等效应及必要聚类，不假定一个低维共同原因。残余相关可有，但先标成未解释依赖。

用途：检验复杂模型是否真的带来解释/预测增量。失败信号：跨情境稳定残差结构与独立功能评价说明单独边缘模型遗漏了共同组织。M0若足够，不能为“高级”而强加潜变量。

### M1：探索性多维共现模型

从足够广且抽样明确的文本测量中探索稳定共现维度；先考虑分布、组合数据约束、重复派生指标及测量误差，再决定相关矩阵/潜变量方法。因子数由可重复结构、重采样稳定性、留出预测和可解释性共同决定，不等于目录中的7或8个特征家族。

事后功能命名必须回查原文、独立情境变量与反例，并在新材料中验证。禁止用来源分类准确率为潜维度的语言学名称背书。

### M2：可证伪的多层测量模型

只对已有独立语言学理由和可区分观测的候选构念建确认模型。一般形式为：

`g_j(E[Y_itj | η_i,z_it,C_i,B_i]) = α_jr + λ_jrᵀη_i + β_jᵀC_i + f_j(B_i, length_i, position_it) + δ_j(z_it)`

r表示有依据的语域/测量分组；不同j可用计数、比例、有序或连续分布。共同因子是解释之一，不是由此方程自动存在。η的结构层可分解为情境成分、一般作者偏移、内容卡、渠道、生成配置及作品残差；只有设计支持的项才进入。

必须声明：潜尺度/符号约束、允许的交叉载荷、残差相关、锚定指标及其证据。旋转等价的多个解释不能由好听的名称消除。若所谓“立场”指标同时承担证据来源、礼貌和读者动员功能，应允许竞争载荷/分离构念，而不是只为简单结构强迫归类。

这里还要比较另一可能：某个目标是由多种写作选择**共同组成**的设计性复合量，而非一个共同原因的反映。若如此，不能用内部一致性高低来决定哪些维度“有效”，也不能把任意加权和宣布成潜在真实风格。两种解释需由定义、外部关系和干预测量区分；当前未选定。

### M3：条件组织状态与时序模型

把主题进程、修辞动作与表面节奏分开建模。先以可审计的标注状态作监督/半监督描述，再考虑隐状态：

`P(z_it | z_i,t−1, C_i, B_it, document_position, η_i)`

在数据支持时，比较马尔可夫、显式持续时间的半马尔可夫，以及只按位置/内容变化的模型。局部连续测量可另有低阶残差动态；不要让隐状态、随机斜率与自回归同时解释同一批波动却不受约束。

隐状态命名要通过独立标注和反例验证，防止标签交换。若状态仅重现“背景—方法—结果”或某题材流程，应按内容/任务模型报告；这仍然有用，但不是稳定作者声音。

### M4：关系网络模型作为竞争解释

保留实体/命题/修辞关系图，研究共现依赖或转移网络是否比少量共同因子更合适。边、方向、核性与作用域需要原文和不确定性。偏相关网络不等于因果网络；共同语境、测量方法和代数约束均能产生边。

M0–M4不是按复杂度依次升级的必经阶梯。它们可能服务不同问题，也可能多数被数据否定。

## 7. 测量模型必须位于统计模型之前和内部

### 7.1 至少五层误差

- 文本版本/版式抽取误差：导航、引用、公式或换行被混入正文
- 分词/句法/EDU边界误差：分母与节点集合发生变化
- 分类与作用域误差：标签对但范围错，或同一形式承担不同功能
- 关系/共指误差：端点、方向、核性及跨句回指错
- 方法/解释差异：不同标注任务或合理读者导致不同可接受解释

“提取器准确率90%”不足以传播这些误差。边界错误可能同时影响句长、密度、依存深度和关系熵，形成虚假的共同因子。双标或替代解析不是只算一个一致率，而是用于判断误差相关结构。

### 7.2 一个可检查的观测模型例子

设某类事件真实出现K次、存在M个可判机会，工具观测到K̃次。最简敏感性模型可写成真阳性与假阳性两部分，依赖域内灵敏度/特异度；若事件/错误有聚类，应扩展而非假装独立二项。M本身若由命题切分产生，也需要不确定性，不能只给分子加误差条。

这只是可证伪的模型候选；不是已知提取器的真实噪声过程。Gold子集必须覆盖不同语域、长短、引语/省略、生成条件等，才能检验误差是否差异化。不能把英文或单一新闻域的公开benchmark值当作中文本项目的误差参数。

### 7.3 测量不变性

同样的η在不同组里是否有相近的指标含义、载荷、截距/阈值？若不同，测量差异与结构均值差异可能互相替代。配置、尺度与位置比较需要分层检查；部分锚定也要有证据和敏感性分析，不能为得到组差异而事后挑锚。[Muthén 2002，§2的多组测量讨论](https://www.statmodel.com/download/muthen1.pdf)

比如第一人称在博客叙述、多人论文和答疑中可能是不同的功能选择；没有共同测量尺度时，可以报告各域的原单位条件模式，不必强行统一潜均值。

### 7.4 缺失机制

无机会分母、文本太短、解析失败、未知角色及没有安装模型是不同缺失。复杂或省略多的文本更容易解析失败时，缺失不一定随机。报告覆盖及选择偏差，做可识别的敏感性界限；把null补0或仅留“解析容易”的文本都可能改写总体。

## 8. 协方差与文内动态的研究假设

**H-C1 条件共同变化**：在内容、情境及误差结构充分处理后，仍存在可跨作者/来源复现的特征共变；与独立边缘模型比较。如果共变被分母共享或解析错误解释掉，放弃其功能因子解释。

**H-C2 层次不同**：作品间、同作者作品间、同作品句间的共变结构不同。总体长句文章更多某构式，不代表同一篇里变长的句子也更多该构式。分层估计，不用pooled相关矩阵替代全部层次。

**H-D1 组合信息有增量**：在保持边缘分布、篇幅与内容支持后，实体/关系/修辞状态的顺序能解释独立读者任务或功能标注。对照包括只保留袋式分布、位置模型及内容序列模型。顺序置乱若破坏了标注器，应分别做“固定标注后的序列置乱”和“原文置乱后重标”来分离两类影响。

**H-D2 变动有功能条件**：局部节奏变化与修辞转折/信息组织相关，而不是均匀增加噪声就更好。条件可为解释段、对话转折、证据列表等。规整、重复、平行结构可能是恰当的人类写作；不预设高熵=自然。

**H-D3 跨层联动不是全局配额**：某些局部操作同时改变节奏、指称与组织；其方向/大小依赖适用条件。需要受控编辑来估计，观察协方差不能直接给出操作效应矩阵。

协方差估计必须处理共享分母、POS成分约束、恒等派生量和样本量。正则化可稳定计算，不能令不可识别的潜结构变为证实的语言事实。

## 9. 至少64项表征如何由模型支持

要求保留，但首先区分三个数：**操作性测量通道数p、可辨认潜维数K、独立作品/作者/内容卡支持量n。** p≥64不意味着K=64，也不意味着64个独立检验或64个独立编辑旋钮。

现有100项注册表只是候选来源。下一轮应逐项建立证据链：语言现象/功能问题 → 分析单位与竞争定义 → 观测方式与机会分母 → 误差与不变性 → 模型中承担的角色 → 原文反例 → 是否允许干预。只实现一个regex函数，不算完成这条链。

### 现有注册表现在就暴露的难题

- F063的主句无显式主语与F071的指称欠明确不能同义：中文省略可在语境中完全可恢复。
- F069认识不确定、F073证据显化、F079礼貌缓和可能交叉，不能按单词划成互斥袋子。
- F083–F089只测显式标记的一面，需要关系实例与作用域旁证，不能替代隐式关系。
- F091实体重合/F093新实体需有共指与文本外语境边界；片段截断会制造“新实体”。
- F096来源链接覆盖不是事实真值或证据支持充分性。
- F097/F098向量相似/离散需与题材、复述和对比组织分离；不能默认高相似更连贯。
- F013–F016是同一长度分布的多种摘要，不应当作四个独立反映指标证明一个因子。
- F041–F049共享组成与分母；统计相关须排除代数依赖。

这些是建模问题，不是再增加计数器就能解决的工程缺口。

## 10. 从语言学阅读到测量试验，而不是先定篇数

### 阶段A：概念/标注比较

选择能区分竞争定义的现象，而非任选文章。先写中文最小对与反例，包括省略但可恢复、引语内立场、认识/能力/义务歧义、同词不同语篇功能、前置关系从句、不连续单元。自制例子只验证定义和程序，不构成自然分布证据。

用同一材料比较候选切分/关系方案，保留相同与冲突的单位映射。问题是“哪些判断在目标用途下可重复、哪些差异改变结论”，不是寻找最高的一致率然后宣布真值。

### 阶段B：真实材料的测量验证

只从逐项权利与用途已审查的资料中选择能检验边界的作品，保留完整上下文。按情境、来源、作者/编辑方式、长短、引用/省略等建立覆盖矩阵。标注者先独立、盲于来源组与模型目标，后讨论；保留原始分歧和裁决理由。

分别评估分段边界、结构、角色、作用域与关系，分析错误如何传播到候选测量和排序。某些关系应保留分布/多标签；机械强制共识未必减少构念偏差。

具体工作量由未解决现象、覆盖缺口、标注学习曲线与资源决定。**目前不把18、64或100篇写成既定充分样本量。** 冻结确认性实验规模前，需要噪声/聚类/效应界限与模型可恢复性的模拟；先导本身只用于学习这些参数和设计，不回流成确认性结果。

### 阶段C：可识别性与模型恢复模拟

给定拟议交叉结构、缺失机制、测量错误与合理效应范围，比较M0–M4能否恢复指定参数、区分竞争模型、给出正确覆盖的区间。模拟用于检验设计和算法，不证明中文世界遵循被模拟的模型。若两个模型在可负担设计下不可区分，应缩小主张或寻找更具区分力的观测，而非换复杂优化器。

### 阶段D：确认性分布与后续干预

锁定语域定义、抽样/排除、单位、测量身份、主要比较、误差处理、模型选择和停止规则后，才收集/冻结确认数据。局部改写实验另立协议；先检查本任务声明的意义/语用不变项与允许变化边界，再讨论任务收益。当前未启动任何阶段的真实数据采集。

## 11. 估计、验证与否证的共同要求

- **训练与评价分离**：任何词表、主题模型、标准化、因子旋转/选择、锚点、规则阈值与编译提示只在训练/内层开发确定。跨作者、渠道、题材、生成器、时间分别说明检验的问题。
- **误差与模型比较**：报告原单位效果、预测分布检验、残差/零质量/尾部、标注不确定性敏感性，而不只报分类准确率或拟合优度。
- **外部锚定**：独立情境编码、功能标注和读者任务可支持解释；不能一套标注既定义构念又作为唯一验证目标。
- **负对照**：替代分词/EDU标准、仅版式变化、词序/句序操作、重复与无意义规整结构应帮助定位捷径；它们不能全都当作“低质量”的统一标签。
- **层次不确定性**：作者/作品/内容卡的相关性要按实际设计传播；多向聚类与层次模型有各自假设，不能机械指定一种bootstrap。
- **停止与降级**：框架间结论翻转、无共同支持、来源/作者无法分离、锚点不变性失败、动态增量被内容顺序解释，均是限制或放弃主张的结果。
- **编辑失败标准**：统计更接近目标但语义、读者任务或作者认可变差，判为失败。不可用检测分数下降替代。

## 12. 编译器应编译“条件策略”，不是潜分数的梯度

候选目标是：`语境与任务 + 声明的不变项/允许变化 + 可编辑位置证据 + 被支持的语言选择模式 → 条件编辑程序`。

每程序需说明选择集合、适用条件、语言分析依赖、可能连带效应、不可改变项、是否有实证效果、怎样复核及撤回。观察一篇文本与某分布有距离，只能提出诊断；它没有告诉我们哪个语义等价替代存在，也未识别采取替代的结果。

例如，“显化某一隐式关系”需先确认关系解读以及显化是否改变力度/预设；“还原指称”需先确认可唯一恢复、隐私与匿名边界；“调整段界”需检查命题与论证作用域。它们不是看到频率低就执行的指令。

从观察性模型到策略效应，需要额外的操作数据或受控干预设计。这正是Style Compiler的研究难点，而不是在分析报告后拼接一段写作提示。

## 14. 两个需要正面解决的代数不可识别性

以下是本项目对候选线性模型的直接推导，用于澄清限制，不是研究结果。

### 14.1 旋转/重参数化：拟合一样不等于解释一样

对简化模型`Y = ν + Λη + ε`，任取可逆矩阵R，有：

`Λη = (ΛR)(R⁻¹η)`。

因而只靠Y的拟合，不能区分这些潜坐标。固定单位方差或三角载荷等约束可选定参数化，却不会自动证明某一轴就是“信息密度”或“亲近感”。功能解释需要独立约束、原文证据、外部关系及反例；而不是把旋转后的最大载荷词翻译成一个名字。

另外，若均值结构为`E[Y|g] = ν_g + Λ_g μ_g`，组间截距差与潜均值差可能互相吸收。允许所有组的ν、Λ和μ任意变化时，跨组潜均值缺少共同标尺。确认锚定、声明部分不变性、或放弃潜均值比较，都是合理选项；默认把所有工具输出标准化不能解决它。

### 14.2 作者与渠道：加项无法拆开完全重合的列

若每位作者只对应唯一渠道，作者指示列的某些线性组合就等于渠道指示列。对这部分效应，在观测分布不变的情况下，可以把一段系数从作者移到渠道。岭惩罚或先验可能给出一个唯一数值解，但那个分摊来自惩罚/先验，而非数据新提供的识别信息。

交叉数据和外部知识可缩小此问题；没有它们时应明确研究对象是作者—渠道复合差异。模拟中不仅要看预测好不好，还要检查作者/渠道分量的后验相关、对先验与分组改变的敏感性、设计矩阵的弱方向，以及样本外连接断裂时的表现。

### 14.3 总体相关不等于作品内部关系

条件协方差可以分解成“给定文档/状态后的内部协方差期望”与“不同文档/状态均值的协方差”。因此，混合多语域形成的狭长点云，未必说明每种语域或每位作者具有同一联动。相同理由也适用于把早段/晚段、引语/正文混起来的文内统计。

如果目标是解释一个局部编辑的影响，应当寻找该编辑适用状态内部的可识别变化，而不能直接用混合总体的相关方向作操作指令。这也是保留层级、序列和边界对象的建模理由。

## 15. “可选表达集合”是另一个尚未解决的观测问题

把风格理解为选择，并不意味着我们已经观察到了作者的备选项。只有一个成品句子时，往往不知道：有哪些表达在当时的内容、证据、受众、篇幅与作者意图下真的可行；哪种由编辑或平台强制；以及作者是否考虑过另一种。

因此，条件分布模型首先描述**实现的选择**。要估计选择机制，可考虑未来分别使用作者修订轨迹、同一事实包的多版本表达、已验证语义等价的最小改写、以及任务条件随机变化。但它们测到的机制不同：事后改写不等于自然首稿选择，提示实验不等于作者习惯，公开版本差异也未必记录了全部编辑过程。

选择集本身需要建模和审查。若把否定改肯定、把认识不确定改确定、把匿名指称补成人名，也未经任务授权就放进“同义替代集合”，后续优化即使计算正确，仍然会编译出错误程序。另一方面，用户明确要求更礼貌、缓和冲突或更直接时，部分语用改变可能正是目的；它们应被显式规定，而不是伪称没有意义变化。

### 任务特定的可接受改写关系

对原文x与候选x′，研究的是`Acceptable(x,x′ | context, invariants, permitted_changes, audience)`，而非声称存在一个普适、无损、可计算的“同义”等价类。判断允许为通过、拒绝、未定；容差与读者分歧下也不应默认其满足数学等价关系的传递性。

- **命题/指称层**：事实、实体范围、数值、时空、真值条件；哪些信息可以摘要、删除或重排需由任务说明
- **承诺层**：认识把握、证据地位、义务/建议强度、否定与量词作用域
- **语用/关系层**：预设、语境依赖的含意、请求/命令/建议等言语行为、礼貌/面子、匿名边界与权力关系
- **篇章层**：主张—证据—反驳关系、信息前景/背景、归属与引述范围
- **允许变化层**：本任务授权的显隐化、语气、读者距离、布局或其他改变，及其界限

“更礼貌”并不自动授权新增承诺；“更简洁”不自动授权删掉唯一的条件；“更有把握”不自动授权把没有证据的结论升级为事实。相同命题摘要或双向NLI通过，都可能漏掉这些改变。

### 拟议的识别试验，而非现成答案

可设计匹配诱导：同一事实包、不同交际关系/目的下，收集表达及选择理由；再用独立读者/作者判断哪些不变项保留、哪些语用作用变化。另一组材料由人工提供最小改写，包含刻意的失败案例与不能找到可接受替代的原文。不同方法分别测自然产出、反事实可接受性和任务影响，不能合并成同一种“作者真实选择”。

这些试验尚未进行，也不能保证每篇文章都存在满足约束的风格替代。若合法候选集合为空或关键判断未定，编译器应保留原文并解释冲突。

目前的策略研究应保留三层边界：

1. 有证据的条件描述，可支持诊断
2. 有意义守恒证据的候选替代，可进入审查
3. 在指定任务和人群中有受控效果证据的操作，才可升级为推荐策略

这三层不能通过同一个总体距离分数自动跨越。
