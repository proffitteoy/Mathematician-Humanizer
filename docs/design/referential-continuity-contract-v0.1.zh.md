# 中文指称连续性测量契约 v0.1

日期：2026-10-01。状态：**构念与测量设计，未做独立标注、语料估计或解析器验证。** 本文只推进无显式主语、指称实现与话题连续性这一组问题；不新增提取器，不把本模块中的表格字段或条件分层计入“已完成64项”。个人文本继续排除。阅读的是研究论文和标注规范，没有获取原始语料。

**本轮决定：不能把“没有主语依存边”直接转换为“选择省略了一个本来可以说出的主语”。** 应先判定是否存在待测的论元位置，再分别保存实现形式、指称证据与关于性分析。恢复实体、话题链和读者理解是三个不同的输出。先以非引语陈述中的独立指称主语为窄域建立契约；控制、共享论元、指令和会话外指保留记录，另域研究。

## 1 原研究实际约束了什么

### 1.1 空成分的位置与类型必须先于计数

Huang 1984 在§1.3（印刷页537–539）区分主语与宾语空成分的解释条件，在§2.1（549–551页）讨论空话题；注16也没有把所有零形式都归结为指向话题。注18明确留下话题链形成机制的未决问题。因此，本文不能用一个“最近名词”规则同时填主语、宾语、话题与控制位置。这是采用其问题区分，不是宣布其理论已无争议。[原文](https://ctjhuang.scholars.harvard.edu/sites/g/files/omnuum5106/files/ctjhuang/files/1984_empty_pronouns.pdf)

### 1.2 显性局部话题理论有实验支持 也有明确的测量边界

Frascarelli与Casentini 2019 全文现已取得。§2.2（6–7页）报告417份问卷中97份完成；只有可接受性评为3或4时才询问解释，候选分别评分。§§3.1–3.5（7–16页）及§5讨论显性、局部话题的偏好。**这些解释百分数既有接受度门控，也不是互斥选择概率。** §4.1注19–20（18–19页）讨论“工作结束”是话题加空主语还是另一论元结构，并提出相关位置的PRO分析。本文据此要求保留竞争结构、将接受度和解释分开；不移植其效应值作为中文总体参数。[全文](https://sciendo.com/2/v2/download/article/10.2478/scl-2019-0001.pdf)

### 1.3 链边界与指称方向含有分析约定

Wendan Li 2004 的“Chain-Initial Cataphoric Links”（29–33页）与“Zero Anaphora in Sentence-Initial Position”（33–34页）讨论先现零形式、后现显式名词及跨句延续。30–31页将句号纳入顺指链判定；有些例子的实体在更早处也已出现。故链内“顺指”标签不能直接当作读者必须等到后文才识别的证据。35页Table 1的分布来自《骆驼祥子》14–19章的限定选例，不能外推为所有主语机会的比例。[作者上传全文](https://www.researchgate.net/publication/242721508_Topic_Chains_in_Chinese_Discourse)

### 1.4 事件连续性可以竞争 但条件化对象必须说清

Zhang、Li与Hale 2022，§§3.1–3.3以一部中文译本、人工核对的语义角色和32个角色身份研究省略；§§3.5–3.7与4.2用历史谓词、距离和**已知正确角色**的显著度预测是否省略。这个设定可以研究给定实体的实现方式；不能当成从未知零形式恢复实体的同一个任务。单部译作内的训练/测试也不验证跨作者、原创文本或语域迁移。[原文，3–7页](https://aclanthology.org/2022.crac-1.1.pdf)

### 1.5 公共标注体系不能直接提供本模块全部分母

Chinese OntoNotes Coreference Guidelines v2.0，§§1.1–1.2允许名词短语及已给定的空论元参与共指，并区分IDENT与APPOS；§2限制IDENT范围，§2.1.1对泛指链接另有规则。**未进入其链不等于不指称，也不等于本项目F071为阴性。** 其任务不是穷尽所有待测机会、桥接关系和可接受读法；普通名词短语也不能因不是NER命名实体而丢掉。[官方规范，印刷页2–5](https://catalog.ldc.upenn.edu/docs/LDC2009T24/coreference/chinese-coref.pdf)

Rao等2015，§§2–3区分会话参与者外指与前文名词回指，并显式记录发话者转换；§4.2另做人工检查。它支持把“我/你”的交际角色另列，而不是给找不到前文姓名的零形式判错。其人称层级预测不等于识别全部第三人称实体。[原文，495–499页](https://aclanthology.org/N15-1052.pdf)

## 2 观测单位与范围

### 2.1 一份文本要保留三种范围

1. **完整来源范围**：固定版本的整篇文本、原始字符偏移、段落、标题、引语与发话者身份。人工记号不写回原文。
2. **目标范围**：哪些位置贡献测量分子分母。本轮主分析是现代书面中文、非直接引语、陈述性、根小句中的独立指称主语。形容词性谓词可以进入；不是只选UPOS=VERB。
3. **可用语境范围**：解释者实际看到了什么。分别标明仅前缀、含完整目标小句、全文回看、额外任务说明；引语虽不作目标，仍可能是可见语境。隐藏某块不得制造新的相邻关系。

这不能直接沿用把引语删除后的B文本计算全部关系。**目标过滤与语境删减是两种操作。** 若采用“B目标、完整原文语境”，应另立profile，不能与旧B投影的参考分布合并。

本轮边界只是可防守的起点，不是“中文主语”定义。叙事、事务报告至少分层；对话、说明步骤、标题、列表、直接引语和嵌入补语先保留为外推/边界材料。发表渠道、目标读者、任务、是否翻译、编辑过程、引语层级分别记录；不从零形式多少反推语域，再用语域解释零形式。

### 2.2 一条基本记录是谓述与主语位置的组合

令`u`为一个带锚点、允许不连续跨度的谓述；`o=(u, subject_site)`为某明确分析框架`g`中的主语位置。一个句子可含多个u，一个共享主语结构可让多个谓词依赖同一个位置。u不是标点片段，也不预先等同GCDT的EDU。

必须先为**所有**目标谓述登记位置状态，不能只找“显眼的零形式”或“已经恢复成功”的例子：

| 字段 | 值或约束 |
|---|---|
| `predication_id / anchor / spans` | 原文可复核的谓述头和范围；分词版本单列 |
| `site_structure` | `independent / structurally_shared / controlled / no_subject_site / unresolved`；框架有争议时保存多个完整分析 |
| `reference_type` | `specific_entity / generic / nonreferential / unresolved`；另以`support`记录文本或外部语境来源，不能把共享、泛指、外指混成互斥的一列 |
| `realization` | 主分析的独立具体指称位置取`lexical_np / overt_pronoun / zero`；不能由无nsubj边直接填zero |
| `syntax_role / semantic_role` | 主语位置与施事、受事、体验者等分开；“被”字句不把受事主语改成施事 |
| `referent_candidates` | 实体ID集合，或`unresolved`；实体可以无姓名。群体、个体与事件节点不能任意合并 |
| `support` | 先前显式提及、先前零位置、后文提及、交际角色、给定场景、桥接或未定；可以多来源共存 |
| `framework / annotator / evidence` | 框架和版本、独立原始判断、证据跨度、理由；裁决单独保存 |

2026-10-01自然材料纸面练习补充：谓述与论元位置另用绑定表相连，区分`owns_site / shares_existing_site / controlled_site`。共享谓述指向已有位置，不再造一条长得像新位置的“共享占位”记录。[空白包0.1.1](../../research/annotation/referential/README.zh.md)只修正这种表示风险，未裁决独立zero与共享主语的理论竞争。

“未确定是哪一人”仍可确定有一个独立具体指称位置，不能将其删出分母。相反，“下雨了”若在该框架中不投射被测的指称主语位置，不应因没有人物提及而添加一个。`unresolved`也不等于`no_subject_site`。交际角色外指在会话边界材料中单列，暂不并入主分析；具体实体可以没有姓名，也不必是人。

每个“可选实现”主张另有`alternative_license`记录：在此结构和语境中，零形式、代词、完整NP哪些保持了规定的指称、命题和言语行为？**位置属于独立指称结构，不保证三种实现都可接受。** 暂未验证选择集时只能报告实现分布，不能叫自由选择概率，更不能自动删补。

### 2.3 三张图有不同的节点与边

- **指称图**：提及/位置节点指向实体节点；`identity`只表示同一所指。实体链可以跨句；链不等于某个读者在当时已经完成识别。
- **桥接图**：`part_of / possessed_by / member_of`等有类型、有方向的关系。屋顶与楼不是同一实体；没有证据时宁保留未知，不以常识无限补边。
- **关于性图**：谓述连接到其论述归属的实体/命题/问题候选。允许并行或未定话题。先独立记录“这段在回答什么、在谈谁/什么”的判断；若再映射为A-Topic位置，该映射是另一个理论层。

零话题不等于零主语；关于某栋楼的谓述可以有“屋顶”这样的显式主语。把三张图压成同一条“共指链”会产生假同一性。

### 2.4 直接观察与理论推断分开

字符、版式、已提供的元数据和每一次读者反应是直接记录；主语位置、实体同一性、桥接及关于性都是在规则下形成的分析，不能因人工完成便叫无误差观测。个体可及性、作者意图及稳定作者倾向则是另需识别的潜在主张。某字段在数据库中有值，不会因此把第三层降成第一层；模型随机效应也不自动等于心理可及性。

## 3 四份可执行的测量契约

以下是**将来有合格标注后**可以执行的计算约定；现在没有数值结果。每份输出都必须携带`document_version, target_profile, context_policy, framework_version, annotation_version, population/weights, counts, unresolved_reasons`。没有语境/框架身份的标量不准入参考拟合。

### 3.1 实现分布

给定完整分析g，`O_g`是符合§2主分析范围、`site_structure=independent`且`reference_type=specific_entity`的位置集，不以能否成功恢复具体所指筛选。泛指/具体或独立/共享尚有争议时，不静默排除，而按后述合法图范围传播。对`f∈{lexical_np, overt_pronoun, zero}`：

`θ_f(g,c) = Σ_{o∈O_g,c} 1[F_o=f] / |O_g,c|`

这是所声明条件c下的**位置加权实现分布**。另一个合法目标是先算每篇θ，再按作品抽样权重取平均；两者分别给长文/多机会文不同权重，不可混称。群体比较必须声明目标作品总体和共同情境权重。

三个概率和为1，最多两个自由度；零比例、显式比例和它们的比值不能算成三个独立的风格证据。`|O|=0`返回`no_eligible_site`；有O但无zero才返回0。未知形式不填0。

同一文本有多个尚未排除的结构分析`G(X)`时，报告`{θ_f(g):g∈G(X)}`或其最小/最大值。**界限应遍历合法的完整图**，不能把互不兼容分析的最小分子与最大分母随意拼接。没有支持分析权重的数据时，不平均成“50%可能是空主语”。

给定独立确认的目标实体e和前文h，可再研究`P(F=f | e,h,c,licensed_set)`。这与`P(e | F=zero,h,c)`是实现选择与理解的两个方向。选择集中有两项以上，才有相关局部选择对比；不得仅因文本中出现了一项就假定其余项被作者有意识拒绝。

### 3.2 同一实体的局部延续

在原始连续目标范围内，对**相邻且各有一个主分析位置**的谓述对构造状态：`same_entity / different_entity / unresolved`。若中间有排除谓述，不能跨过去造一对。

`K_{ab}(g,c)=P(F_t=b | F_{t-1}=a, E_t=E_{t-1}, adjacent,c,g)`。

输出原始转移计数、行分母和未定对数；零行分母返回null。有未定实体链接时，沿合法图传播K的范围；若只能算已确定链接子集，结果必须标为该子集的条件描述，不能顶替全部相邻对。此矩阵问“同一所指延续时如何实现”，不问文本整体连贯性。先前实现与当前实现可能共同受事件、段位和语域驱动，不能将K解释成前项对后项的因果作用。

另存最近**先前显式同一实体提及**的距离：按所有已划分谓述的序号差计，句内可为0；`no_prior_overt`、语境左截断和未知分开。无先前提及不设为任意大数。后文能确定实体时可以做全文描述，但它不能冒充前缀理解的已知候选。距离分布与K不是由多个任意窗口复制出的独立测量族。

### 3.3 关于性延续

对独立标注得出的单一关于性目标B，定义相邻谓述`A_t=1[B_t=B_{t-1}]`；多目标、问题与实体无法同类型比较时保存集合/关系，标为不适用单一身份判据。输出四格计数：关于性相同/不同 × 主语实体相同/不同，另报未定与多目标。

核心检验是两层是否可以分离：是否存在可靠的“同一关于性、不同主语实体”，以及“同一实体复现、不同论述归属”。若B只靠主语实体和zero标出来，这份契约没有独立信息，不能用于支持话题理论。

这里暂不输出“平均话题链长”。连续游程、允许中断的实体链和A-Topic结构链有不同边界；先证明哪类边可重复，才有资格选择其持续时间模型。

### 3.4 给定语境的解释反应

对读者r和目标位置o分别记录：自然程度、最可能实体、可接受实体集合、`none / insufficient_context / cannot_judge`、是否知道现实姓名。可接受集合不要求只选一人；最可能实体不能靠“先评为自然”门控后才问。响应顺序另作方法因子。

首要描述量是`q_e(o,c,m)=P_r(best=e | shown_context=c, elicitation=m)`与`a(o,c,m)=P_r(|acceptable_set|≥2 | c,m)`，以及不足语境/无法判断率。它们分别是跨读者首选分布和任务诱导的多读法报告，不是作者意图或心理概率的金标准。可选多读法和无法判断也不能合并。

例如q一半指甲、一半指乙，可能是两群读者各自十分确定；不能据总体熵高就宣布每位读者都困惑。若真有每位读者的反应分布q_r，才有`H(E)=E_r H(E|r)+I(E;r)`这一分解；只有每人一次首选时，个体内熵不可识别。多选集合提供另一种证据，也不自动估出这个熵。

**F071只在测量对象和任务冻结后映射到这里，不能再用“匿名/泛指/空形式/多解”一个布尔值通吃。** 实际姓名不明但语篇实体唯一，可以同一地回指；泛指类别也不等于两个竞争个体。是否影响理解、任务完成或礼貌，需独立结果变量。

### 一个只靠定义就能发生的协变

构造文本A：`林澄回来了。随后，笑了。`

构造文本B：`林澄回来了。随后，林澄笑了。`

在一个将两句各分析为独立陈述、第二句A有指向林澄的零主语的**指定分析**下：

- §3.1的zero比例：A为1/2，B为0/2
- F091若只纳显式提及：A的两句集合是`{林澄}, {}`，Jaccard为0；B为`{林澄}, {林澄}`，为1
- F091若计已恢复zero：A、B都为1
- F093若只纳显式提及：A为1/1，B为1/2；若计zero：两者都是1/2

**这是手算的逻辑反例，不是解析器输出、母语者结果或语言总体证据。** 不断言两版本在强调、节奏等语用上完全相同。它证明：仅实现形式与提及视图的选择，就能同时改变“新实体”“实体重合”“主语省略”三个数字；不能把它们的相关性先验当作三个潜在特质共同变化。这不否定各量的描述用途，也不证明自然材料中所有协变都由这一机制产生；需要与独立注释、替代视图及共同误差模型比较。

## 6 可竞争的分析与判别测试

### 6.1 三个模型在预测什么

所有模型在相同位置集、可用语境、读者任务和留出设计下比较。先分别拟合实现F和解释E；不拿一个方向的预测优劣证明另一个方向。

**R0 局部角色与最近性基线。** 用候选的最近提及距离、前次提及的实现形式、语法角色、候选数量及当前谓词类型，条件于任务和语域。解释E的任务另条件于目标形式；预测实现F时不得把目标形式或包含它的编码当预测变量。不设话题隐节点。它能提出可审计预测，也可能遗漏结构域与事件历史。

**RT 话题结构分析。** 在R0之外，加入独立确定的当前关于性/A-Topic候选、根/嵌入位置、结构可及性、链的延续/转换，及它们与zero/代词实现的交互。其具体统计形式是本项目近似，不是Frascarelli理论的等价翻译。关键预测是：控制线性距离和事件支持后，某些结构/话题差异仍改变解释或实现。

**RE 事件可及性分析。** 在R0之外加入候选此前参与的事件与当前谓词的相容性、独立任务线索和竞争候选的支持度，不设额外A-Topic节点。先用有证据的事件标签及人工相容性判断；将来若换向量相似度，需重新验证测量。关键预测是：结构相同的条件下，事件支持可改变选择，并改善对RT失败例的预测。

三者可都不充分，或需要RT+RE。RT若每遇反例就追认一个不可观测的“沉默话题”，RE若把所有残差都定义成“语境相关性”，都失去可证伪性。必须在读取目标解释反应前冻结相应注释和特征；对从前文推定的话题，另以遮住目标实现的条件检查其可辨识性。R0、RT、RE都不能仅凭拟合改进证明心理机制，更不自动证明作者风格。

### 6.2 下一项测试分成两个尚待验证的材料块

**2026-10-01纸面审查更正：撤回本节原先可以直接展开结构可及性×事件支持×最近性的三因素网格建议。** 当结构条件在目标内重说候选姓名时，移动前文背景不会改变该姓名的最近提及距离；把“林澄说”换成“林澄的说明显示”又同时改变报告谓词、来源类型与可能的引语分析。填满网格不解决这些混淆。原建议发布于提交`ac58385aea124de28c191ce2df82bc7b57213a54`；更正针对可执行设计，不改变前述构念区分。

**材料块B先检查事件支持与相对距离的可操纵性。** 固定目标为“随后，发现了三处错字。”或带“他”的版本，不在目标重新点名。前文分别让两名同事校对文稿、整理书目，交换任务承担者作为事件支持条件。将完全相同的两句无人物背景移到林澄的最新提及前、或林澄与周牧的最新提及之间；在该构造中，周牧的最新提及距离不变，林澄的距离发生变化。逐字卡及字符位置检查见[纸面审查](../../research/annotation/referential/crossed-template-paper-audit-v0.1.zh.md)。

这是一组材料块、八个版本，**不是八篇独立作品或已经通过的心理实验**。背景次序还会改变篇章组织；zero可能允许群体读法，而单数“他”不保证同义。只把经实际核验的字面距离变化称作距离变化，不据此证明纯记忆衰减，也不预填唯一先行项。姓名顺序、谓词和任务仍须在后续模板中反转，独立检查自然度和支持强度。

**材料块S单独审查结构边界。** 把“林澄说，……”与“林澄的说明显示，……”之类候选放入竞争分析表，明确记录报告/证据来源、根或嵌入目标、是否可恢复、是否可能受控制等；它们目前只能暴露边界，不能估计纯结构可及性效应。若不能在保持有关谓词和命题关系的条件下构造可比材料，就保留复合对比或缩窄研究问题，不把RT的增益直接归因给结构。嵌入边界材料不并入根小句实现率。

两块都不以自然度评分门控解释题。标注者先独立保留结构与关于性候选；解释者分别提供开放释义、首选、可接受集合和自然度。首选可以是两人、其他对象、语境不足或无法判断，不能只让选择林澄/周牧。先取得独立判断，再问：同一可用框架下事件支持及字面距离的条件变化能否重复，以及结构边界能否得到不循环的注释。材料方法改变就翻转时，先修测量。

R0、RT、RE仍保留为竞争模型，但这两块当前均不授权拟合、自动提取或宣称机制胜出。样本规模须根据想区分的效应、读者/模板聚类和所需精度另定；八个构造版本不是统计充分性证明。立即下一步只做空白标注包与纸面审查；未招募、未发问卷、未调用生成模型。

### 6.3 两个配套反证检查

**边界敏感性检查**：对RC06型材料在不变实体及事件条件下改变句号/逗号，分别记录链标签、实体身份与前缀理解。若只有按定义的链方向翻转，不宣称读者处理方向翻转。实际改变标点仍可能改变韵律/结构，须保留这一解释。

## 7 一致性 测量误差与可识别性

### 7.1 不用一个一致率掩盖四个不同问题

Artstein与Poesio 2008，§2.1区分一致性与有效性；§§2–3分析机会校正和系数假设，§4讨论不同标注任务。本文沿用“共享规则不保证构念正确”的约束，不借某个κ阈值宣布通过。[原文](https://aclanthology.org/J08-4004.pdf)

拟议报告顺序是：

1. **单位发现**：各标注者独立寻找谓述/位置，报告锚点精确匹配、跨度重合和漏出位置；另用合并候选表分析分歧。合并表仍不能揭示所有人共同漏掉的位置
2. **结构判类**：在对齐位置上报告完整混淆表、类别频率、逐类一致性及明确假设的机会校正系数；`unresolved`不并入阴性。共享/控制/独立位置之间的错分重点检查
3. **实体和边**：分开检查实体同一性、桥接类型、边端点和支持语境；不要只在“所有标注者都成功链接”的容易子集上评共指
4. **解释反应**：保留读者间差异、允许多读法、判断不出及任务顺序效应。它们不全属于待裁决的标注错误

同一规范内不一致、两个理论框架不同和真实解释多样性要有不同错误码。裁决可形成约定分析，不能擦掉原始分歧再当可靠度为1。报告作品/模板和标注者双层不确定性；自然作品稀少时，给出原始分歧，不用单篇内大量位置制造很窄的总体区间。

### 7.2 单靠观察率无法分离误差

即使合法位置集已固定，二分类zero检测也满足一个最简测量模型：

`p_observed = sensitivity·p_true + (1−specificity)·(1−p_true)`。

没有域内误差证据，三项未知量不能从一个观察比例恢复。多个受同一解析器影响的指标也不会自动多提供独立方程。这个模型只适用于约定了可裁决二分类真值的那一层，不用于抹平真实多读法。

分母筛选另有问题：若zero和非zero位置被成功保留的概率分别为`r1,r0`，则已保留位置中的比例是

`p_retained = r1·p / (r1·p + r0·(1−p))`。

恢复困难的零位置更易丢失时，coverage之外还可能有方向性偏差。只报告coverage不能校正它。结构分母未定时，优先给合法图敏感性界限；不要用固定分母误差模型假装解决全部问题。

### 7.3 当前明确不可识别的东西

- **作者心中的可及性/意图**：成品zero与共指图不能区分习惯、语法约束、编辑及读者设计
- **独立的作者倾向**：作者、任务、渠道绑定且无跨条件重复时不能识别；位置多不会增加作者数
- **“零形式导致歧义”的效果**：只看自然文本中的相关性不够；允许选择的位置与事实/语用保持条件需先建立
- **话题结构对纯最近性的增量**：如果标注把最近主语必定叫话题，二者完全重合
- **读者个体内不确定性**：每人一次不同首选，只识别跨读者反应差异
- **全体中文的省略率**：窄域机会集、单部小说、译作或只含可链接提及的资源都不提供这个总体

本模块暂不引入一个“指称连续性潜因子”。若将来有跨任务、方法分离的可靠共变，可以竞争性地提出潜变量；现阶段四份契约是不同观测关系，不是已证明由一个心理实体反映出来的题项。

## 8 实现前的最小验证关口

这里先让一种窄域测量有可复核的输入，不等待全中文理论完成，也不让一次小试验替代总体有效性。

**第一关是契约可用性，不是语料效果。** 两名独立中文分析者按§2表格分别处理RC01–RC07，不预填zero或唯一实体答案；保留分歧图。复核能否表达共享/控制、无位置、匿名实体、桥接、双向支持和多读法，不要求争议例一致。若表格强迫把其中任何两类错误合并，先改契约。这一关通过只说明可以继续做人工测量，不认证指标。

**第二关是一个经过权利和用途审查的非个人自然材料小试验。** 选连续上下文，独立寻找所有目标谓述；至少覆盖拟启用范围中的显式/零实现、形容词谓词，以及共享/控制和非目标位置的排除边界。材料可以只获准用于测量研究，不要求先标成H_G。按现象有意选取的试验只检验规则与错误类型，不估自然发生率。两人盲标、独立第三方复核严重分歧；记录双方共同可能漏掉的位置，不能只检验提供好的候选列表。

**第三关才是冻结可计算子集。** 同一标注版本的手算与将来的计算器必须逐项一致，包括空分母、未知所指、相邻关系中断与多图界限；计算器不得自行补实体、补话题或补位置。若准备启用自动提取，另须在没有用于修订手册的材料上验证位置发现、分类与连边，及其对最终率/转移量的联合影响。通过人工计算关口不自动通过自动提取关口。

最低报告是：机会分母的双标差异、逐类混淆、有效/未定覆盖、每份契约在合法分析下的数值范围、按目标语域的错误类型。是否足以比较某个风格差异，应在看组别结果前规定可容忍的测量偏差和区间宽度，不能拿通用κ阈值代替。**目前未有这套独立标注，也未有用途容差，所以所有契约仍是待验证状态。** 不因RC01手算正确就启用F071或安装解析器。

## 9 本轮可以冻结与不能冻结的内容

**可冻结为下一轮研究输入**：位置、实现、指称、桥接和关于性的分层；目标范围与语境范围分离；原始分歧及合法图保存；F091/F093的zero视图身份；解释问卷不以接受度门控；R0/RT/RE的区分任务；RC01的代数反例。

阅读缺口：Li与Thompson 1979、Y.-H. Audrey Li 2014《Born empty》、后续控制/论元省略争论尚未完成全文核对；不会把搜索摘要或他人引述冒充原文证据。Frascarelli与Casentini 2019的全文缺口已关闭，但其数据和本项目任务并不同构，未据此宣称理论已定。

这份模块给最终64项以上的表征提供的是**测量身份、共同错误来源、可用对比及淘汰条件**。条件分层、同一概率的补数、多种窗口或一张图的派生统计，不应被用来填充数量。最终可保留几项，由它们是否测到了可辨别、可重复且与任务有关的对象决定。
