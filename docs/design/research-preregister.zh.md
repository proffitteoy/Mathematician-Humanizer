# 先假设、后测量：中文 Style Compiler 研究协议草案

状态：预注册模板，不是已注册协议；没有采样、拟合或结果。当前阶段只研究一般中文风格。个人化是冻结的末期接口；只有用户明确要求开始收尾后才可启动，当前不读取、搜索、采集或分析用户个人作品。

## 0. 工作顺序与停止规则

构念/可证伪假设 → 混淆图与估计目标 → 标注规范/测量验证 → 最小识别性数据设计 → 冻结预注册 → 描述性/配对统计 → 外部压力测试 → 局部干预验证。特征数、爬取量与分类准确率均不能代替研究进展。

《feature-schema-100.zh.json》是候选测量注册表，不是首轮全部提取计划。每项只能在回答明确问题时升级为 active。首轮主指标建议控制在 8–12 项，依先导测量验证决定；其余 exploratory/deferred。未进入预注册的分析只能标探索性。

如果关键构念无法被标注者稳定区分、来源与作者完全混淆、缺少同任务的可比支持，停止相应来源归因，先修复设计；不能靠更多同分布网页或更复杂分类器补救。

## 1. 研究对象与条件轴

三个研究域：中文互联网表达、论文文本、博客。域不是风格本体；域内须分任务/修辞功能。

- 互联网：提问、解释回答、讨论/争论、经验叙述等；短聊天与长回答不能因同在互联网而混合。
- 论文：摘要、引言、方法、结果、讨论分别建层；学科与中文原创/翻译另记。先排除公式/表格/参考文献的机械影响，再保留版式侧测量。
- 博客：解释、评论、教程、个人叙述等；机构编辑稿与个人定稿、平台模板分别记。

保留 author_id、source_id（站点/刊物/出版渠道）、work_id、lineage_id、topic_id、genre、rhetorical_task、requested_length_band、observed_length、time、editorial_status、translation_status、provenance_confidence；模型组另记 generation_config 与 prompt_family。用户个人化不在本阶段。

只在共同支持的体裁×任务×长度带内做直接比较。不存在共同支持时报告 coverage gap，不外推强行配对。跨域结果用分层模型并分别展示，不给“全中文 AI 写作特征”总榜。

## 2. 构念与测量区分

可直接观察的是标点、句段边界和表层串；“节奏”“承诺强度”“连贯”“信息推进”是构念。代理得分是否有效，需要金标、上下文和干预验证。

- 节奏：句/段长度及其顺序结构。平均句长不代表节奏；随机抖动也不自动更自然。
- 结构组织：命题间的关系和修辞功能。连接词频不等于真实逻辑关系密度。
- 立场：作者对命题的承诺、证据来源和义务/建议力度。认识情态与礼貌缓和不得合并。
- 信息推进：在既有语境中引入或更新实体与命题。向量距离不是新信息的真值。
- 三类模糊：认识不确定、指称不明确、数量近似。三个不同分母、不同作用域，不能以同一“模糊词计数”代理。

每构念先写边界案例与反例；盲于来源组进行人工标注。报告原始一致率、按标签的混淆矩阵、分歧类型以及适合标签结构的一致性统计；不要仅凭总体 κ 或某个阈值宣布构念成立。自动标签的误差必须按域评估，包含阴性例与歧义例。

## 3. 可证伪假设与主比较候选

H1 条件异质性：H_G 与 A_G 的风格差异依赖体裁/修辞任务，不应由一个固定方向的全域偏差充分表示。
- 候选主指标：句长离散 F014、显式因果 F083、第一人称 F050，各自原单位；预先规定 generation_group（人类/AI生成条件）×genre/任务交互；平台source_id是不同变量。
- 可否证：在跨来源留出域中，交互效应区间落入预定可忽略区间，统一模型与条件模型的外部表现等效。
- 非证据：仅一个域显著另一个不显著，不等于域间效应显著不同。

H2 动态不等于均值：在匹配任务和要求篇幅后，顺序统计为一般风格差异提供独立于均值/分散度的信息；不预设 AI 必然更均匀。
- 主指标：相邻句长差 F024、lag-1 F025，配合句长 F013/F014；足够长文本才进入本项。
- 检验：来源×动态差异的方向/区间；同文本保持句长集合不变的顺序置换仅作诊断零模型，不生成自然文本。
- 可否证：动态效应在预定义实用区间内近零，或留出数据中没有超出长度与体裁基线的增量。

H3 humanize 主要改变表层而非所有层面：A_H 相对 A_G 的改变在经过测量可靠度匹配的表层指标上大于结构/信息层。
- 对照：同内容卡、模型、要求篇幅和预算；提示条件随机化；禁止预选“成功 humanize”样本。
- 主比较：事先冻结的少量表层与结构指标，分别按 H_G 训练区间标准化；比较配对改变量的预注册聚合，而非事后找最能支持结论的词。
- 可否证：结构改变同等或更大；所有层均未变；或效应只由篇幅/内容改变解释。此结果不构成“更像人”的价值判断。

H4 模糊性可区分：认识、指称、近似三构念在人工标注中可区分，且对定向最小修改表现出差异敏感性。
- 主指标：F069/F071/F072，报告分母与作用域；先人工、后自动代理。
- 测量实验：如“可能有100人”“某些人到场”“约100人到场”分别定位不同不确定；使用语境化最小对，避免靠词表捷径。
- 可否证：标注持续混淆，或测量对只改变其他构念的修改同样敏感。失败则不允许把这些代理作为编辑目标。
- 干预守恒：本实验允许用受控测试句改变含义来检验测量；真实用户改写不得把这种意义变化当作风格改进。

H5 局部结构操作可预测且保真：在明确适用条件内，拆句/合句/边界移动的目标特征改变可以复现，同时不损害命题、作用域与论证。
- 随机对照：无编辑、任务适配普通编辑、词汇禁令基线、结构操作策略；编辑预算和生成器一致。
- 终点：目标变化、非目标连带变化、硬语义锁通过率、盲标意义等价/信息问答、读者任务适合度。
- 可否证：特征改变不稳定；保真未达到预注册非劣效界限；收益只在训练域；检测分数变化而读者收益不变。
- 重要：未验证 H1–H4 的指标不进入 H5 的主要目标。

所有“等效/非劣效/可忽略”界限在先导测量误差与读者任务锚定后、确认性数据揭盲前冻结。不能根据 p>0.05 直接宣称没有差异。先导数据不得回流为确认性证据。

## 4. 混淆结构与不同估计目标

作者/编辑者/来源、体裁、题材、任务、时间与篇幅都影响表征；模型家族/版本、提示、采样参数和筛选过程也影响表征。平台格式和模板可能被错误学为“AI风格”。同一作者跨题材、同一题材多作者、同一域多渠道的交叉覆盖比同一个网站的更多文本更重要。

区分三个问题：
1. 描述问题：在同样实际篇幅/任务/体裁下两组有什么差异？可条件化 observed_length。
2. 提示总效应：humanize 提示造成什么整体改变？匹配 requested_length_band；observed_length 可能是中介，不能在主要效应中不加区分地控制掉。
3. 固定篇幅的直接效应：属于单列分析，需要明确额外识别假设，不是总效应的同义词。

同理，“引用更多”可能是任务导致，不能自动视为文风。作者与来源一一对应时，无法区分二者效应；生成器与体裁绑定时，无法解释组别效应。来源标签的可预测性不保证来源本身因果改变了风格。

### 4.1 提示随机实验的DAG与估计量

记Z=随机分配的humanize提示，C_pre=题材/体裁/任务/受众/要求长度，M=模型快照与采样配置，L=实际篇幅，Y=真实但不一定直接可测的写作属性，Y_hat=测量值，E=解析/标注误差，S=被选入分析的状态。协议假设的有向边：

- C_pre→L，C_pre→Y；M→L，M→Y
- Z→L→Y，Z→Y
- Y→Y_hat，E→Y_hat；体裁/脚本/模型依赖→E
- 若人挑“成功输出”：Z→S，Y→S；因此按S筛选会产生选择偏差

提示总效应目标为同一预处理条件分布下的E[Y(Z=1)-Y(Z=0)]。随机化单元是内容卡内生成条件，独立性与重复生成的聚类须按设计建模。识别假设包括：随机分配与执行一致；无条件间串流污染；各条件均有正概率；所有合格/失败输出按预注册规则保留；测量误差按组审计；对生成随机性做重复而不挑结果。实际篇幅L不进总效应的主要调整集。

固定实际篇幅的对比可作为条件描述；若要解释为受控直接效应，还需可实施的长度干预与中介—结果混淆假设，不能只把L加进回归就声称因果。

H_G/A_G历史语料对比不是这一随机实验：author_id、source_id（平台/出版渠道）、编辑/翻译/选择过程与generation_group均可能耦合。它默认是共同支持条件下的描述性差异；不宣称把同一个人“替换成AI”的因果效应。作者/来源缺元数据时降低证据等级或限制任务，不能靠检测器补造标签。

## 5. 先导研究的退出产物

不是先积累大库，而是：
- 每构念的标注手册、歧义清单、金标审计与代理误差
- 数据矩阵的重叠/不可识别单元，以及修复采样设计
- 按独立作者、独立内容卡/提示、作品估计的有效样本与层级相关；不按文本窗口计独立样本
- 功效/区间宽度模拟和最低有用差异的锚定
- 冻结的 8–12 个主指标、有限主要对比、缺失/剔除规则和全部失败标准

首轮可优先使用低依赖的节奏/结构表层指标及人工三类模糊标注，暂不部署信息新颖性、主张定位、自动共指等高误差代理。先导无法使代理有效就保留人工测量或撤销该指标，不以大模型标签“补齐”全部100项。

## 6. 与后续个人层的接口

仅保存接口类型：已验证核心测量 + 条件参考分布 + 作者授权参考语料 + 用户批准的写作目标 → 有证据的个人操作规则。

当前不得实例化作者画像、A_U个人模仿、H_U个人采样、个人参考百分位或个人风格 skill。用户明确发出“开始收尾/进入个人化”的指令后，另确认资料范围并启动独立协议。一般层研究期间可以用匿名一般作者分组控制混淆，但不能把这转换成用户个人化项目。

## 7. 拓扑支线：独立的增量价值假设

H6：在测量有效且长度/题材/编码器等干扰受控后，拓扑或几何量对盲评连贯性/任务适合度提供超出可解释特征的留出增量。它是研究假设，不是“提高拓扑维数=写得更好”。

注意力图拓扑与token embedding点云内在维数是不同对象；后者不直接保留点的顺序。仅打乱已算出的向量行应不改变点云几何，而先打乱句序再编码是另一实验。前者是实现一致性负对照，后者测试对文本顺序的响应。[注意力图原论文](https://aclanthology.org/2021.emnlp-main.50/)；[内在维数原论文](https://proceedings.neurips.cc/paper_files/paper/2023/hash/7baa48bc166aa2013d78cbdc15010530-Abstract-Conference.html)

预注册编码器/层、距离、点数与抽样种子、中文分词/脚本、长度窗口、简单表层基线、相同容量/预算、作者/来源留出。负对照包含重复句、格式变换、无意义随机词与仅向量行置换；这些可能改变数值但不应获写作奖励。若增量消失、方向跨编码器翻转或与读者质量脱节，停止将它用于编译器目标。先做复现与测量验证，再决定是否增加拓扑特征，不为凑100维填任意H1/H2持久同调指标。

拓扑的详尽主文献审计、具体估计对象与数据权利限制以本项目独立研究审计文档为准；不复制论文的“invariant”措辞当作已验证中文普适定律。
