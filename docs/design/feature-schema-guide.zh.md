# 中文候选特征注册表：定义与实现前置条件

配套：feature-schema-100.zh.json。100是候选注册规模，不是首轮模型维数、必提取清单或已验证测量数。第一轮须由假设选择少量主指标；注册表只防止名称漂移和隐藏自由度。每项都可以因构念失效、可靠性不足或无干预价值而撤销。

## 文本视图与符号

保留原文与完整字符偏移。C是所声明文本视图内Unicode general category以L或N开头的码点数；不计空白、标点、符号或组合标记。这不是字节、token或认知“字数”。纯中文子分析可另用Han字数，但必须另立测量profile。

当前确定性内核冻结为all_input_unicode_LN/1.0.0：原始输入，不规范化，不推断作者性、引语或标题归属，不自动排除任何块；这8项F002/F003/F013/F014/F015/F016/F024/F025按全部输入计数，布局和引用会影响结果，必须披露。后文的L/B作者性视图是另一个尚未实现的authorial_prose_unicode_LN/1.0.0候选profile；不得用相同feature_id跨profile混算参考分布。未来若做NFC/简繁转换，另立profile并保留偏移映射。

两视图：L是可见文本/布局结构，剔除代码、公式、表格及参考文献清单，保留标题、引文与列表的可见内容；C_all为L的上述Unicode L/N码点数。B是作者性正文，进一步去掉标题文字、整块引用、直接引语内容和引用标记字符串，保留列表项目正文与非引语正文；C、分句、分词与标注默认在B进行。所有剔除保留区间和原因，无法判断引语时标不确定并做包含/排除敏感性分析，不静默删掉。相邻关系不得跨越被排除的块，原段落/句位置不重排。

布局块=解析得到的heading/paragraph/list-item/blockquote四类叶级可见文本块；嵌套列表容器不额外计块。在作者性profile中，P=至少含1个C码点的作者性正文段落/列表项目数；在all_input profile中，P按内核冻结的原始段落规则计数。S=所选profile句数。句边界在句号/问号/叹号终止串及作者性块结尾，配对引号/括号内的终止符与小数点/缩写由版本化规则处理；分号不是句边界。无句末标点的块结尾也算句，终止类型为none。标点单位U是在句内再按逗号/分号/冒号分割的非空连续片段；不得称它为真实子句。

T=冻结中文分词器给出的非标点、非空白token数；token位置指该序列的秩。没有分词器时T相关项为null，不以单字或regex假装词。UPOS采用冻结模型/树库规范。每句token数n_s。所有lexicon匹配采用冻结版本、最长非重叠字符span，先识别多字表达，再做上下文角色消歧；词例不是封闭定义，缺资源即缺失。

Q=人工或经过本领域验证的命题切分中可判定的原子命题数。命题包括谓词、论元、否定、条件、数量/情态作用域；一个句子可有多个，不能用逗号数量代替。Q_claim=有可判断认识承诺的陈述性命题，不包括真正疑问/纯指令；R=可判定的指称提及数；Q_num=数量表达数，含点值/区间/近似/数量级表达。不可判定标注从特定分析分母排除，并额外报告coverage，不能静默当阴性。命题、提及和数量表达的ID/边界/标签/不确定状态必须保存。

经验分位数统一为Hyndman–Fan type 7线性插值。MAD=median(|x−median(x)|)，不乘常数；IQR=q75−q25。若分母为0或数学定义无意义则value=null，绝不用epsilon掩盖不可识别。比率按表述的倍率报告；0–1与每100/1000单位不能混用。

## 支持与缺失

每项有raw_minimum（数学可计算门槛）和comparison_minimum（暂定的比较门槛）。后者是工程保护，不是文献认证的充分样本量；通过门槛也不能宣称精确。保留raw但达不到comparison门槛时，value可用于观察，eligible_for_comparison=false。总体拟合的独立样本量按作品/作者/内容卡，不由一个文本内的分母替代。

统一缺失原因：zero_denominator、insufficient_raw_support、dependency_unavailable、parse_failed、annotation_unresolved、ineligible_structure、constant_series。观察到有机会数但零次事件为0，不是null。每项计数有分母，比例区间与层次估计在统计模型中完成，不凭一个文本发明置信度。

依赖代码：LAY布局/引用识别，SEG版本化分句与字符投影，TOK中文分词，POS词性，DEP依存，LEX_*冻结词表/频率资源，ANN_SYN构式标注，ANN_PROP命题/作用域，ANN_STANCE立场，ANN_REF指称与共指，ANN_NUM数量表达，ANN_DISC语篇关系/修辞角色，ANN_INFO信息关系，NER实体链接，EMB冻结句向量。ANN可以是人工；自动代理在中文各域的金标验证前不得冒充真实标签。probability-weighted counts只有经领域校准才允许，否则使用硬标注并报告不确定与混淆。

可靠性：A=确定性/规则（仍受预处理影响），B=分词/解析/固定词表代理，C=语义/语篇/统计模型代理。层级不是已实证的准确率；每层都要人工审计。

## 模糊性标注细则

F069以命题为单位判断说话者对真值/证据是否保留；“可能、似乎”等只是候选线索。“他有能力完成”的可能性/能力与认识不确定不能混标。

F071以指称提及为单位判断当前给定语境下对象/集合是否被刻意或实质性欠指明；正常代词且有唯一先行词不算。匿名、泛称、未知身份、歧义分别附subtype，不能根据没有人名直接判模糊。

F072以数量表达为单位判断数值容差/近似/数量级未精确设定；精确范围“10至12”与近似“十来个”区分。“大概明天会下雨”标F069而非F072；多义兼有时按作用域可多标签但必须留证据。

所有相关干预都保护原有含义；提高/降低这些率本身不是目标。F082同一命题至少两个不同认识限定span才算堆叠，同一个span的多标签不重复计数。

## 干预限制

注册表的intervention字段表示可能的操作，不是自动触发/预期方向保证。改变句子结构不许改变因果、时序、量词、否定或情态作用域。词性、引用、数字、实体等可能由内容决定，只能在语义等价且任务允许时调整；否则diagnostic_only。信息/语义代理不能单独授权删事实或添事实。

## 序列与拓扑侧对象

100项标量之外，保留句/段序列与实体/命题/论证图：节点类型、边类型、原文证据、置信状态、标注器版本。任何自动图都是待验证测量。图大小、密度、平均度受命题分割和文本长度强烈影响，不宜先塞进100维凑数；先验证节点/边构念，再预注册拓扑研究。不要把图结构统计直接叫“思维方式”。

## 实现测量与候选测量不可混淆

初始内核和语义候选允许共享统计公式，但测量身份必须是(feature_id, schema_version, projection_id, extractor_versions)。内核只实现8项，不因为其余92项在表中存在就填默认0。当前阶段没有模型词表、解析器或语义标注时，相关项为dependency_unavailable。原始profile中引语/标题/引用是输入的一部分，它不是已经完成作者性净化的文本。

语篇标记计数约定：一个连续、经上下文确认的连接表达算一个event；“因为…所以”两个分离表达计2个event，长复合标记采用冻结标注表的最长非重叠span。关系图另按实际关系实例计边，不把标记数量等同关系边数。
