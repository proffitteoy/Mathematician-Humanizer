# 历史归属语料怎样成为可用参考：用途、证据与部分识别

日期：2026-10-01。状态：**准入与估计对象的决策草案，未准入新的人类参考、未拟合模型、未验证任何来源检测器。** 本文承接[来源可行性札记](provenance-feasibility-v0.1.zh.md)，专门处理 `model.py` 的 H_G 门槛，不重列语料目录。初稿只做设计；随后按有界授权取得一个固定2017年度档案，完成来源视图结构普查及样本键冻结，见§7的修正说明。未招募或调用生成模型。

**决策：保留现有 H_G 的执行条件；另行设计“明确来源的观察参考”契约。历史人类归属材料可以支持有范围的语言分布研究，无须追溯证明所有写作阶段绝对无辅助；但不得因此把未知生产史改填为 `unassisted`。** 来源归属、原始措辞的生产者、后续编辑、自然人身份与取样单位是不同主张。严格流程锚点也只证明已观察协议内的事，不能成为一切自然写作的普遍金标。

## 1. 当前门槛究竟检查了什么

[现有代码](../../src/style_compiler/model.py) 的条件是：H_G 有非空 `author_id`，且 `assistance_status == "unassisted"`；另检查全局的权利与来源声明。`contracts.py` 对 ID 做字符串检查，**没有身份认证、生产过程核验或阶段级证据核验**。因此有两个不同问题：

- 把它作为唯一总体研究入口，条件过强：某来源文本的句段分布并不要求知道作者实名，更不要求排除所有编辑、词典、拼写检查或翻译活动
- 把通过它解释成已验证的纯人类真值，条件又不足：非空 ID、布尔声明和一个标签不能认证自然人或完整的辅助史

作者键仍有实际用途。[泄漏分组](../../src/style_compiler/leakage.py) 通过它连接作品，缺失值会跳过该连接。不能只删掉门槛便宣布未知作者之间独立，也不能给每篇未知文本编一个不同作者来凑支持量。代码目前拟合的是总体残差基线，本身不估计作者效应。

本轮协调修改已经只澄清报错与 README，条件未变。最小报错措辞为：

> H_G requires a nonempty caller-supplied author ID and assistance_status='unassisted'; these declarations do not authenticate a person or verify assistance history

对应文档措辞为：

> The H_G gate checks declared metadata, including a nonempty author ID and an unassisted label. Rights/provenance flags record an external review claim; the code does not independently verify identity, production history, or the absence of assistance.

后续设计不应把 H_G 从“声明无辅助”悄悄改成“历史上大概人写”。若迁移，需新版本契约、明确旧字段含义及用途隔离；本文没有新增程序枚举或放宽拟合接口。

## 2. 将“人类来源”拆成可核对的主张

### 2.1 版本、角色、过程分别记录

每个分析对象是一个固定版本及其分析投影，证据记录最少包含：

| 对象 | 最小字段与允许状态 | 支持的主张 |
|---|---|---|
| 内容身份 | 原始与分析字节哈希、修订 ID、转换步骤、引语/模板范围 | 正在测量哪个版本；哈希不证明日期或作者 |
| 时间见证 | 作品所称日期、版本所称日期、最早外部见证及证据、取得时间 | 这些字节至迟何时存在；见证可信度单列 |
| 责任归属 | 归属键、键类型、角色、证据范围 | 出版署名、初始发言账号、修订提交者、编辑、译者、集体分别记录 |
| 生产阶段 | 构思、资料检索、措辞初稿、翻译、改写、文字校订、事实核查、发表处理 | 每阶段的 `documented / self_reported / inferred / unknown`；已知使用与已知未使用另存 |
| 自动化机制 | 模板/规则生成、早期统计或神经生成、指定 LLM 家族/版本、机器翻译、工具辅助 | 知道发生了什么，或只知道排除了哪个有日期的机制 |
| 证据覆盖 | 所涵盖的阶段、时间、文本范围、观察方法、协议允许/禁止项与偏离 | 已核验范围之外保留未知；不同证据不能被一个置信分覆盖 |
| 用途决定 | 测量诊断、来源内描述、历史归属参考、协议参考、账号重复性、自然人作者推断 | 每个用途单独通过/未决/排除及理由 |

W3C PROV 将实体、活动、代理、角色与修订分开；这里借用其记录方式，而不把 PROV 记录当成真实性认证。[PROV Primer，§§2.1–2.6](https://www.w3.org/TR/2013/NOTE-prov-primer-20130430/)

“人类作者”至少可能指：对作品负责任的署名人、构成初稿措辞的人、最终定稿人，或当前版本的贡献者。编辑过的小说仍可研究某署名下发表的文本；这不等于恢复了作者未经编辑的潜在原稿。译文可属于“人类生产的已发表中文”，却不属于“原生中文初稿”目标。**是否为污染取决于所声明的目标，不取决于材料是否不够纯。**

### 2.2 证据分层是多轴，不是一条“纯度等级”

建议保留三个证据轴，再由用途规则交叉筛选：

| 轴 | 层次 | 可支持与不可支持的范围 |
|---|---|---|
| 时间 T | T0 当前取得；T1 发布者声称历史派生；T2 特定内容与可信历史保管/捕获记录对应 | T2 可排除见证之后才存在的指定生成过程；T0/T1 不自动具备这一排除力 |
| 归属 A | A0 提交/账号记录；A1 明确角色的出版署名或初始发言归属；A2 由额外记录交叉核对的同一归属 | A1/A2 不是每个词由该自然人独写的证明；A0 不能自动升级为措辞作者 |
| 过程 P | P0 未知；P1 具体版本/阶段的自报；P2 独立记录的协议内过程 | P2 须说明观察盲区和允许工具；P1 与 T2 可以同时存在，彼此不替代 |

这些层次只是拟议证据语义，不是新增的自动评分标准。T2 的可接受见证包括可回溯的出版机构保管记录或内容对应的档案捕获；不要求所有历史文本补办密码学证明。RFC 3161 的准确对象是数据的存在时间，正好说明“何时已存在”和“谁怎样写成”不同。[RFC 3161，§§1–2](https://www.rfc-editor.org/rfc/rfc3161.html)

按上述轴可形成三类参考，而不必把所有未知清零：

1. **来源内观察参考 R_SRC**：权利与固定版本可用，单位和抽样框明确。来源与辅助史可以未知；估计的是这个来源及筛选规则定义的文本分布
2. **历史人类归属参考 R_HA**：T2，加与目标生产角色匹配、明确归属于人类生产者的 A1/A2，且不存在未处理的相反证据。机构对人类作者/集体的署名归属可以是这种证据；单独的操作账号不是。辅助阶段仍可 P0；报告为“按该归属规则纳入的历史文本”，不称独立验证的无辅助文本
3. **记录流程参考 R_PROC**：具体任务、参与者/系统、允许工具、过程记录和输出版本绑定。估计的是这个协议下的生产分布；它与自然发表文本之间仍有参与者、任务和观察效应的迁移问题

R_SRC、R_HA、R_PROC 是本札记的研究用途名称，目前都不是可传入 `fit` 的 cohort。账号归属适合 R_SRC 的贡献记录；若缺少人类生产角色的证据，不因“没列为机器人”便进入 R_HA。

### 2.3 历史证据能缓解一种污染，不能消除全部辅助

“2022 年之前”不是无生成模型的通用边界。GPT-3 的原始研究发表于 2020 年；更早的应用式自然语言生成也已存在。[Brown 等 2020，§§1–2](https://proceedings.neurips.cc/paper/2020/file/1457c0d6bfcb4967418bfb8ac142f64a-Paper.pdf)；[Reiter 与 Dale 1997，原始出版记录与摘要](https://www.cambridge.org/core/journals/natural-language-engineering/article/abs/building-applied-natural-language-generation-systems/FEB374A3FF652F06D8567A6FAB2EF36E)

有效主张应写成：“在信任该保管记录、内容对应及系统存在时间的前提下，版本 V 不可能由指定的后来系统 M 首次生成。”它不排除当时已有的自动化、人工代笔、翻译、套话、复制或编辑；也不鉴定今天另一个完全相同副本的生成过程。一个今天下载的旧年号文件尚不具备内容对应的历史见证。

另有相反方向的污染：历史文字可能进入后来模型的训练数据。排除模型参与历史原稿，并不保证生成对照未见过历史文本。两种污染分开记录，不能由同一个时间标签解决。

翻译/编辑应是生产情境变量或另设目标群，不是统一排除项。Koppel 与 Ordan 研究的英语译文显示翻译过程及源语言与文本统计有关；其 §2.1、§4.1 的语料与切块限制不能照搬为中文作者识别验证。[Koppel 与 Ordan 2011，§§2–4](https://aclanthology.org/P11-1132.pdf)

## 3. 明确估计对象以后，才决定缺少哪种证据会阻断研究

令 S 为固定来源/版本/取样框，C 为任务、语域、时期等独立编码的情境，E 为外部证据记录，Y 为冻结定义下的一个测量。以下不同目标不得合用一个“人类均值”：

| 估计对象 | 精确定义 | 最少证据；关键限制 |
|---|---|---|
| 固定材料上的测量诊断 | 同一 X 上的边界、标注、关系图及误差/分歧 | 合法 X 与完整必要语境；不要求来源真值，也不产生总体频率 |
| 来源内分布 | `Q_S,c,w(Y)`，由 S、C 与预先给定权重 w 定义 | 可追踪抽样/纳入、测量与版本；未知作者不阻断点描述，但阻断某些独立性与外推主张 |
| 历史归属分布 | `Q_HA,c,w(Y)=Q(Y | E 满足声明的历史归属规则,C=c)` | 成员资格是可审查的证据规则，不等于所有归属都在事实层面无误 |
| 协议内流程分布 | `P(Y | 按协议 p 产出,C=c)` | 有记录的 p、允许工具与偏离；与自然写作的差异不是纯来源效应 |
| 实际目标生产过程分布 | `H_c,w(Y)=P(Y | Z=1,C=c)` | Z 例如“人类措辞初稿且未经历指定自动改写”；若 Z 不全知，只能在额外假设下部分识别 |
| 作者/账号条件规律 | `E(Y | 归属键 u,C=c,S)` 或其重复性 | 重复作品、角色一致、情境重叠；账号键默认只解释为账号，不等同已核验自然人 |

人类参与并不是天然互斥的二元类。若研究问题允许编辑与翻译，就不应将其任意编码为 Z=0；若目标排除这些过程，未知保留为集合标签 `{0,1}`。已知混合作品可以是 Z=0 的一种，但这仅说明它不属于当前目标；不声称该篇所有语句都由机器生成。

在有限语料框内，均值为 `θ_Q=Σ_i w_iY_i / Σ_i w_i`。预先选择 w 的含义：

- 文档均权：每个独立作品/首发话语一个权重。长文不会仅因句子多而代表更多作者
- 机会均权：对比例用 `Σ_i w_i A_i / Σ_i w_i N_i`，A 为目标次数、N 为真实合格机会；这与平均每篇比例不同
- 账号均权：先在账号内按声明规则汇总，再对账号均权。若要自然人均权，必须另有账号与自然人映射的假设
- 讨论均权：先在讨论内汇总，再对讨论均权。适合说明该取样框的讨论，不能冒充发言/作者均权

现有基线的“每个泄漏连通分量总权重为 1”是其实现政策。一个分量可含多个作者及内容关系，**不能一般解释为作者均权**。分割单位、拟合权重、污染比例的分母、重采样单位必须分别声明。

## 4. 部分标签与污染：可算的界，而不是虚构来源概率

本节是从明确混合式及有限集合直接推导的识别结果；数值例均为**构造算例**，没有使用自然语料测量。识别区间、抽样置信区间和测量误差区间是三个不同对象。

### 4.1 有界测量的加权污染界

在固定情境 c 和固定目标权重 w 下，设 `Q_w=(1−ε_w)H_w+ε_w B_w`，其中 B 是任意非目标分布，`0≤ε_w≤ε̄_w<1`。先要求 `Y∈[L,U]` 是定义或外部范围约束，不是看完样本后取其最小/最大值。

由 `μ_Q=(1−ε)μ_H+εμ_B`，`μ_B∈[L,U]`，得：

\[
\ell_H=\max\left(L,\frac{\mu_Q-\bar\epsilon_w U}{1-\bar\epsilon_w}\right),\qquad
u_H=\min\left(U,\frac{\mu_Q-\bar\epsilon_w L}{1-\bar\epsilon_w}\right).
\]

下界随 ε 变大不升，上界不降，所以未知 `ε≤ε̄` 的联合范围在 ε̄ 处取得。这是只用均值与范围的保守界；若 Q 的完整分布已知，还可收紧。这里的 ε 是**按 w 定义的非目标质量比例**，不是检测器分数，也不是文本中“AI 字数占比”。

例：有界比例 `μ_Q=.30`，假设 `ε̄=.10`，则 `μ_H∈[.2222,.3333]`。这是关于 10% 上界的条件计算；它没有证明污染率是 10%。若再有另一个组 `.40` 且同样假设，则其界 `[.3333,.4444]`，组间差异界 `[0,.2222]`；原观察差 `.10` 不足以在这些假设下保证严格正差异。

对两组 j=0,1，保守差异界为 `[ℓ_1−u_0,u_1−ℓ_0]`。只有当其下界仍超过预先声明的实质阈值，且抽样/测量误差传播后仍成立，才支持相应稳健比较。两组若受共同标签约束，应联合优化，不能把独立边界当成可同时达到的尖锐界。

### 4.2 完整分布提供更紧的删减界

若确知总体 `Q_w`，允许任意污染子群且已知最大质量 ε̄，则 H 是从 Q 保留至少 `1−ε̄` 质量后重新归一化的分布。对可积 Y，以 `q_Q(t)` 表示广义分位数，均值的尖锐界为：

\[
\frac{1}{1-\bar\epsilon}\int_0^{1-\bar\epsilon}q_Q(t)dt
\ \le\mu_H\le\
\frac{1}{1-\bar\epsilon}\int_{\bar\epsilon}^{1}q_Q(t)dt.
\]

理由：最小值保留最低的 `1−ε̄` 质量，最大值保留最高的相同质量；原子边界可分配部分概率质量。这一总体概率分解允许分数质量，不是把一篇真实文档物理拆成两种来源。若研究对象是固定有限文档的二元归属，使用下一节的整数分配，不能无说明地套连续尖锐性。

抽样经验分布的删减结果只是样本界的估计，不是已知总体 Q；必须另报抽样误差。若已确认的目标项不能被删，或错误沿作者/模板整簇发生，以上任意删减界仍可保守，但通常不是利用全部证据的最紧界。

### 4.3 每篇只有部分标签时，直接对合法归属集合求界

给每个版本允许的目标成员集合 `Z_i⊆{0,1}`。如证据能在**声明的可信假设下**确认其属于当前目标，`Z_i={1}`；确认不属于则 `{0}`；否则 `{0,1}`。设全体约束组成集合 `𝒵`，包括：各篇允许值、每层污染质量上界、共享生产批次/模板约束，以及归属标签可能错误的容许量。则有限框内的均值识别集为：

\[
\Theta=\left\{\frac{\sum_i w_i z_iY_i}{\sum_i w_i z_i}:z\in\mathcal Z,\ \sum_i w_i z_i>0\right\}.
\]

报告其最小/最大值。所有未知项不能自动给 .5；不存在的来源后验不能通过“概率加权”制造。允许 `z_i∈[0,1]` 是总体质量解释或计算松弛，须与固定文档的二元结果区分。若 𝒵 允许目标集合为空，先报告目标存在性未保证，不能默默删除空解后声称有人类均值。

构造例：两个确认目标项的 Y 为 `.2,.6`，两个未知项为 `0,1`，均权且无额外人数约束。四种纳入结果的均值为 `.4,.2667,.6,.45`，所以界为 `[.2667,.6]`。两个未知均填 .5 会得到单一点 `.4333`，该点没有由证据识别。若“确认”仅是署名归属而目标是实际无自动改写，不得把前两项强制为 1。

只有正例和未标记例也不是免费恢复标签的办法。Elkan–Noto 的关键比例关系依赖正例被完全随机选作已标记，即 `P(S=1|Y_class=1,X)=常数`；有生产日志的材料通常来自特定机构、时期、任务与愿意配合的作者，这一假设不能默认成立。[Elkan 与 Noto 2008，§2，式(1)–(2)、Lemma 1，印刷页214](https://cseweb.ucsd.edu/~elkan/posonly.pdf)

### 4.4 文档污染比例不能直接传给词项、指称机会或作者

设文档均权下非目标比例 ε_D；目标与非目标文档平均机会数为 `n_H,n_B`。机会层混合比例是：

\[
\epsilon_O=\frac{\epsilon_D n_B}{(1-\epsilon_D)n_H+\epsilon_D n_B}.
\]

构造例：19 篇目标文档各有10个机会，1篇非目标文档有1,000个机会。非目标只占文档的5%，却占机会的 `1000/1190=84.03%`。因而“文档可能错5%”不能给零主语机会率套上 ε=.05。

若事先有所有目标文档 `N≥m>0`、非目标文档 `N≤M` 且 `ε_D≤ε̄_D`，才可推出：

\[
\epsilon_O\le\frac{\bar\epsilon_D M}{(1-\bar\epsilon_D)m+\bar\epsilon_D M}.
\]

没有正的机会下限或有限上限，此界可接近1。以字数限制替代指称机会限制还需另证。合格机会数本身若随语法分析变化，须在每个合法分析图上重算；不能先用自动树固定分母，再只对来源标签做敏感性。

账号均权同样不同：一个目标账号有99篇、一个非目标账号有1篇时，非目标占文档1%，占账号50%。文档 ε 不能直接用于账号均值。若自然人映射也不确定，作者权重随映射和标签改变，应对两者联合求界。

### 4.5 条件分层与审查选择不能被总污染率掩盖

对每个任务/语域层 c，分别使用 `ε̄_c` 和该层范围。预先指定标准化权重 `ω_c` 时，总均值界可取 `Σ_c ω_cℓ_c` 与 `Σ_c ω_cu_c`。它估计的是人为声明的共同情境混合，不是未经说明的全体人类构成。只有全库 ε 上界时，污染可能集中于某个小层；须按 `Σ_c p_cε_c≤ε̄` 联合分配，而不是每层都套同一个 ε。

另一类缺失是只保留来源容易确认的作品。若原目标框中审查通过质量为 r，通过部分均值为 μ_pass，而未通过部分 Y 完全未知、只知 `[L,U]`，原框均值仅有 `[rμ_pass+(1−r)L, rμ_pass+(1−r)U]`。该式是**选择缺失界**，不是来源污染界。声称在已通过子集上描述则不需要补回未通过者，但必须改写目标总体。来源审查并非从历史人类写作中随机抽样，不能把通过者直接当作所有作者。

### 4.6 什么审计才支持 ε 上界

可观察的“证据缺失率/角色冲突率”可以审计；隐蔽的私下辅助并不因为未被发现就成为零。把非目标已确认、目标已确认、未决三个质量记为 b,h,u，在标签正确假设下，非目标比例只被限制于 `[b,b+u]`。如果审查本身会错，还需给这些确认标签留出错误容许量。

理想构造：按目标均权分布独立随机抽 n 个单位，审查对目标违规完美识别，发现0次；单侧 `1−α` 二项上界为 `1−α^(1/n)`。在 α=.05 时，n=24 仍给11.73%，n=59 才约4.95%。这只是公式校验，**不是拟议审阅规模的充分性证明**。若检测灵敏度只有已知 s、无假阳性，上界变成 `min(1,[1−α^(1/n)]/s)`；s 未知时不能从“0次发现”推出非平凡上界。聚类、有限总体抽样与不等权也必须使用对应设计，不能把24个讨论中的几百句话当作几百个独立审计单位。

若暂时没有可支持的 ε̄，应给一条明确标为假设的敏感性曲线，包含接近无约束的情形；不要选一个让结果漂亮的污染率。大样本能缩小抽样误差，不能自动缩小未识别的辅助史范围。

## 5. 无界长度、协方差与“去污染”为什么仍有硬限制

现有 F003 在有分母时属于 `[0,1]`，F025 在可定义时属于 `[-1,1]`；可按其数学范围分析。句长及其若干统计量（如 F013、F014、F015、F024）没有由当前定义给出的共同有限上界。**ε 上界本身不保证任意无界测量的总体均值、方差存在或可被样本有限值约束。**

需要区分三个容易混淆的事实：

1. 对已经完全观察的有限框，所有 Y_i 有限时，重分配标签得到的有限框均值界当然有限；它不控制未观察总体的尾部
2. 若确知总体 `E_Q|Y|^r<∞`，混合支配关系给出 `E_H|Y|^r≤E_Q|Y|^r/(1−ε̄)`；非负 Y 的已知有限总体均值也给 `μ_H≤μ_Q/(1−ε̄)`。因此不能笼统说“无界变量永远没有有限界”
3. 有限样本的最大句长与经验方差不是上述总体矩条件的证明。可以预先截尾/缩尾，但那会改成截断测量的估计对象，不能冒充原始长度总体

对向量 Y，协方差满足：

\[
\Sigma_Q=(1-\epsilon)\Sigma_H+\epsilon\Sigma_B+
\epsilon(1-\epsilon)(\mu_H-\mu_B)(\mu_H-\mu_B)^\top.
\]

最后一项说明，污染组与目标组均值不同即可改变观察相关结构，不能只除以 `1−ε`。若任一方向缺少范围或矩约束，极少质量在任意远处也可使方差任意大；若每轴有已知有限范围 R_j，则 `Var(Y_j)≤R_j²/4`、`|Cov(Y_j,Y_k)|≤R_jR_k/4` 给有限包络，但不唯一恢复人类协方差。相关矩阵、因子轴和马氏距离都受此限制。

混合分解本身也不因数据多而唯一。构造反例：`0.5 Bernoulli(.2)+0.5 Bernoulli(.8)` 与 `0.5 Bernoulli(.4)+0.5 Bernoulli(.6)` 都是 `Bernoulli(.5)`；即使混合比例已知，也不能从 Q 在两种不同 H 之间选择。这里混合的是每次先选择一个组再抽取的二元观测，不是把两篇文字逐字相加。

即使一个生成分布 A 有干净锚点，`Q=(1−π)H+πA` 在未知 π 时一般仍有多种解；最大可分离的 A 质量不是自动等于真实生产比例。Scott 等 §4 明确给出这一非识别与额外不可约假设；Katz-Samuels 等 §3 的 Proposition 1、Definition 3 和条件 B2/B3 进一步说明多群分解需要共同基分布、秩与标签结构条件。[Scott 等 2013，§4，PDF页8](https://proceedings.mlr.press/v30/Scott13.pdf)；[Katz-Samuels 等 2019，§3，印刷页7–8](https://jmlr.org/papers/volume20/17-576/17-576.pdf)

现实的“先有人类草稿，后自动改写”是一个变换过程。将其整体列为非目标文档，可用于上述子群均值问题；却不能由混合权重还原每篇未经改写的反事实原稿。要估计编辑效果，需要配对版本及更强的设计，不能用一张来源概率表代替。

**至少64项最终可执行测量，不意味着64个独立潜因子。** 测量可能共享机会分母、属于和为1的组成、测量同一构念的不同层级，或只是彼此相关的操作通道。来源证据字段也不应拿来充当额外风格轴。维度数量、矩阵秩、可识别潜结构、有效独立样本数各自决定。

## 6. 作者与语域推断需要哪些额外结构

### 6.1 不要求实名，但要求归属键的研究含义成立

历史研究可采用稳定、带命名空间的化名/账号/出版归属键，无须收集身份证明。需要回答的是：它绑定什么生产角色？同一键是否可能多人共用？多个键是否可能同一人？跨版编辑后它还代表同一种贡献吗？

缺少这些证据时，允许报告同一账号的重复性或同一署名下发表文本的差异，并显式承认其可能包含编辑制度；不报告已核验自然人的稳定心理风格。已知别名/合著/编辑关系形成依赖边，未决关系保留为多种合法分组方案。对分组集合 𝒫，重复估计或取识别集合的并；“全部未知各自独立”没有证据，全部合成一个人又是另一种未经证明的身份主张。

### 6.2 交叉覆盖与设计秩比“有 author_id”更重要

简化加性模型 `E(Y|u,r)=α_u+β_r` 的账号—语域二分图中，每条边代表一个有数据的组合。连通时，在一个位置约束下可识别其加性均值参数；不连通时，跨连通块的账号与语域差异无法分开。这只是加性假设下的代数识别，**不保证残差精度、外推或因果性**。加入主题、时期、编辑等变量后，二分图连通不再足够，须检查完整设计矩阵的秩和共同支持。

语域交互 `α_ur` 需要相应单元格的重复作品与覆盖；空单元格的预测来自模型假设/先验。层次收缩能改善方差，不能创造同一作者跨语域的未观察证据。Altakrori 等将作者—主题关联在训练与测试间交换，以分离某些主题混淆错误；该设计为压力测试提供依据，但不证明任何指标自动免疫中文题材变化。[Altakrori 等 2021，§§3.1–3.2](https://aclanthology.org/2021.findings-emnlp.359.pdf)

不同推断任务需不同留出设计：已见账号的新话语重复性，保持账号可见但留出作品/讨论/时间；未见账号总体迁移，才按账号留出。不能将同一个严格账号留出结果称为已学到该账号的个人分布。衍生文本、同一讨论、引语/复制关系则始终防止跨边界泄漏。

### 6.3 语域不是网站名；时期不是可随意控制掉的项

情境分类应根据受众、交互关系、目的和任务另行编码，允许多功能与未决；不得用待研究特征的高低定义类别。Bender–Friedman 的 §5.1 明确区分选材理由、言语情境、文本特征和来源附录，§5.3 允许信息缺失但要求说明外推范围。[Bender 与 Friedman 2018，§§5.1、5.3](https://aclanthology.org/Q18-1041.pdf)

历史人类归属材料与当前生成材料若完全错开时期、任务或平台，“把年份放进回归”不能消除完全混淆。可报告这些具体样本/流程之间的条件差异；若无共同支持，不能另命名为脱离时期的“人类性效应”。

## 7. 一个具体下一研究：WikiConv 2017 年度视图的准入与交叉覆盖

**研究问题：在一个固定历史源内，能否建立可审查的话语版本—账号—交际情境关系，并分清可支持的来源内参考、历史归属参考与未决材料？** 目标先是形成分类语料的可行入口及可识别对照，不是训练人类/AI分类器。首轮候选框限定为官方 ConvoKit 中文2017年度文件内的视图；不并入其他年份或当前网页。

**2026-10-01 来源核对修正：** 本节初稿提出“2017年首发话语与完整讨论”框，但官方说明明确年度文件按话语分开、同一讨论可以跨年；文件还保存最终话语状态及嵌套修改史。年度标签不足以证明首发年份、原作者或完整历史上下文。现将先行研究改为年度视图的结构普查，原始首发及特定观察时点的完整语境作为须另外核验的后续对象。[ConvoKit WikiConv，Summary、Utterance-level Information、Combining different years](https://convokit.cornell.edu/documentation/wikiconv.html)

选择理由具体而有限：原论文给出2018-07-01转储来源及五类编辑行动，§3 明确行动归于提交修订的用户，§4 审查的是行动/边界/回复/父链接；这些准确率不等于自然人身份或无辅助准确率。§5 的英语实例要求同一批账号跨场所出现，支持先检查交叉覆盖的思路，不能替中文提供可行性结果。[Hua 等 2018，§§3–5，印刷页2820–2823](https://aclanthology.org/D18-1305.pdf)

### 7.1 现有材料不能被这个计划自动升级

- 已取得的2002派生包只有0条通过当前连续中文语篇用途，账号与版本角色也有未决；其日期目前只是包内/发布者记录，不能自动标为 T2/A2
- 已取得的维基百科修订87588184是2025版本，来源及辅助未知；它只支持当前获准的测量契约压力检查，不属于本历史参考计划，也不进入 H_G
- `source-registry.json` 与空的 `pilot-manifest.json` 没有总体拟合准入。前述本地探查及公开收据不是批量来源准入记录

这三个状态分别由[已执行的可行性审计](provenance-feasibility-v0.1.zh.md#8-有界执行结果与实际准入决定)、[单修订测量收据](../../research/annotation/referential/pilot-public-receipt.json)及现有登记支持。旧登记中“从未取得语料”的概括需要后续协调更新；不能因此抹掉实际局部探查，也不能反向宣称已有人类参考库。

### 7.2 冻结一个可失败的小规模设计

| 项目 | 预定规则 |
|---|---|
| 取样框 | 官方2017年度视图中非标题、至少两次非空话语贡献的候选讨论；先完成结构普查。中文适用性及来源用途另审，不要求先认定人类 |
| 版本对象 | 文件中的顶层版本与嵌套历史分别记录；首发年份和具体版本归属尚待映射，最终状态不冒充首发状态 |
| 第一轮审查单位 | 完成普查后冻结24个讨论源视图组的随机样本，最多审查每组40个顶层非标题话语版本；这是工作量上限，不是充分性门槛 |
| 抽样约束 | 需先有完整框及抽取概率。若只获得便利子集，则目标缩为该子集，不能称2017代表样本。超出完整上下文/体积预算的讨论记未决，不截出好看的局部 |
| 分类轴 | 顶层/所附原始视图/修改/恢复角色；时间证据；账号归属；自动通知/模板/引语/翻译/编辑；受众与功能；话语/讨论/账号的重复结构 |
| 情境比较候选 | 条目内容/证据协商与编辑操作/协作安排；根据功能编码而非页面命名空间，混合和未决单列 |
| 主要结果 | 各用途的通过/排除/未决质量、角色冲突、年度文件内引用闭合与版本对应比例，账号—功能二分图及加入主题/时期后的设计秩；包内闭合不称完整历史语境 |
| 首个语言终点 | 待指称测量独立验证后，主句指称机会上的词汇NP/显式代词/零形式三项组成；文档均权与机会均权分别定义，暂不计算未验证解析器频率 |
| 当前允许产物 | 本方法、空白准入表的字段定义、后续公开的去标识聚合；原始文本、可重建话语的标注及账号映射留在数据区 |

如果采用每讨论前40条，则估计对象必须明说是“入样讨论的前40条目标话语”，不称全部话语；如果希望全讨论频率，超长讨论只能完整另审或作为整体未决。每个样本的取样状态和审查状态分别保留，不能不公开失败率地不断替补到24条合格讨论。

该设计中“24”只保证有明确审查预算，不支持5%污染承诺，也不保证两个功能跨账号覆盖。第一轮只检查这些结构是否存在；若图不连通或缺乏独立重复，结果就是当前框不支持相应账号/语域参数，保留来源内描述用途。

### 7.3 准入成功以后也只回答限定问题

来源内 R_SRC 的首个可声明估计对象是：在上述年度文件取样框与已核对的版本定义下，固定情境内的测量分布及缺失分布。需要完整语境的测量仍要另过上下文门槛。点描述不依赖全体账号都是自然人；不确定性仍要尊重讨论、账号、复制及版本依赖。R_HA 子集只纳入时间与角色证据达到预设规则者，并连同未决项进行 §4 的敏感性分析。其结论仍是历史归属材料在该语境下的分布。

若同一批账号在两种功能均有多次独立贡献，可研究这些账号的条件重复性。将其提升为自然人作者规律，需要额外映射假设和误归属分析；将其提升为人类一般写作，需要来源外复制设计。**无需先解决“绝对纯人类证明”，也不能借此跳过测量验证、归属角色和覆盖问题。**

### 7.4 当前真实阻塞与止点

随后的只读核对确认，官方2017目录仅列一个80,074,478字节的 ZIP，未发现公开的逐讨论取样/字节索引；440字节的 ZIP 目录探查已确认五个成员及各自大小。整个年度话语成员需要顺序解压扫描才能建立可靠框，便利地读取前几行不能成为概率样本。此后在既有大型语料研究范围内完成该单一固定文件的有界取得及结构普查，并从3,395个符合预定结构条件的年度视图组中冻结24组。详细身份、实际检查及全部限制见[执行记录](../../research/audits/wikiconv-2017-execution.zh.md)和[公开聚合收据](../../research/audits/wikiconv-2017-public-receipt.json)。这不证明历史语境完整，也未准入H_G。

这一批准不涉及其他年度或补取原始修订。结构普查后，若需要特定时点的完整页面/讨论语境，应先报告确切缺口与所需版本。现有工作区容量足以容纳该年度文件；“历史语料无法证明绝对纯人类”不再作为阻止这一来源内研究的理由。

独立来源复核和指称标注也尚未安排。助手单人先行编码可暴露字段/角色问题，不能命名为独立人类金标、估计一致性或验证标签误差率。若第一轮不能建立可用 R_HA，R_SRC 的准入/结构审查仍有研究价值，但不拟合 H_G。

## 8. 后续实现前的最小决策契约

未来任何来源内参考接口，至少要显式接收以下六项，缺一项便不能把结果称为所申请的总体参考：

1. `estimand_id`：R_SRC / R_HA / R_PROC / 特定潜在生产目标，并给完整自然语言定义
2. `sampling_frame_and_weights`：作品/话语/讨论/账号/机会中的哪一种，以及分层、纳入和缺失处理
3. `claim_evidence`：版本、时间、角色、阶段、见证来源、覆盖范围及未决；不能只给总布尔值
4. `measurement_contracts`：已验证用途、投影/上下文、机会定义、误差与合法分析集合
5. `dependence_and_support`：版本/作者或账号/讨论/内容关系、合法分组方案、共同情境与设计秩
6. `sensitivity_spec`：各目标权重下的污染/部分标签假设、选择机制、取值或矩约束、失败时允许的降级主张

实施前最小审核案例应包括：合法但未知来源的测量材料；有稳定署名和历史保管但辅助未知的 R_HA 候选；有账号而没有措辞角色的记录；有明确协议的生产锚点；已知翻译/编辑/自动通知；以及完全混淆的账号—语域设计。每例应出现用途特定结果，而不是一个统一“人类通过/不通过”。这些是待制定的契约案例，不是新增的特征或已完成的程序测试。

现有 H_G 行为保持不变；本札记提供的是一个可审核的新研究入口定义。扩大分类语料规模的依据应是明确的目标、可核对角色与来源、可计算的未决边界以及交叉覆盖。
